Installer vor dem Ausführen prüfen

Vergleichen Sie den Fingerabdruck des Installers mit dem SHA-256-Wert oben. In PowerShell, im Ordner, in den Sie ihn heruntergeladen haben:

Get-FileHash .\LocalGateKeys-Setup-Personal.exe -Algorithm SHA256

Stimmen die Werte nicht überein, führen Sie die Datei nicht aus. Laden Sie sie von dieser Seite erneut herunter und schreiben Sie uns an security@localgatekeys.app.

Was Sie brauchen

  • Windows 10 oder Windows 11, 64 Bit
  • Eine aktuelle Version von Google Chrome oder Microsoft Edge für das Ausfüllen im Browser
  • Windows-Hello-Hardware (Fingerabdruckleser, Hello-Kamera oder eine PIN) zum Entsperren mit Windows Hello
  • Für die Synchronisierung: Pro und zwei oder mehr PCs im selben Netzwerk oder eine auf jedem PC installierte Cloud-Speicher-App

Nach der Installation

Die Anleitung zum Einstieg führt Sie mit Screenshots durch jeden Schritt.

  1. Öffnen Sie LocalGateKeys und wählen Sie ein Master-Passwort mit mindestens 12 Zeichen. Schreiben Sie es an einem sicheren Ort auf; wir können es nicht zurücksetzen.
  2. Erstellen Sie in den Einstellungen eine Wiederherstellungsphrase und bewahren Sie sie offline auf.
  3. Schalten Sie in den Einstellungen geplante Backups ein.
  4. Fügen Sie die Browser-Erweiterung hinzu für Edge und heften Sie sie an die Symbolleiste. Die Erweiterung funktioniert nur mit installierter App.
  5. Pro gekauft? Geben Sie Ihren Lizenzschlüssel unter Werkzeuge > Lizenz ein. Siehe Ihre Pro-Lizenz.
