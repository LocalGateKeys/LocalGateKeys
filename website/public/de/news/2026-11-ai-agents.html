KI-Agenten melden sich an, Ihre Passwörter bleiben auf Ihrem PC

KI-Agenten können jetzt Aufgaben in Ihrem Browser erledigen, die eine Anmeldung brauchen, ohne Ihr Passwort zu bekommen. Der Agent bittet um die Anmeldung bei einer Website, Sie bestätigen in LocalGateKeys, und die Browsererweiterung füllt das Anmeldeformular aus. Der Agent erfährt nur, ob das Formular ausgefüllt wurde.

Jede Bestätigung gilt einmal, fünf Minuten lang, nur für diese Website. Anmeldungen, die jedes Mal das Master-Passwort verlangen, werden nie verwendet. Ein Agent kann nur wenige Male pro Minute fragen, und jede Anfrage landet in einem Zugriffsprotokoll, das Änderungen erkennen lässt.

Die Funktion ist standardmäßig aus und erfordert Pro. Schalten Sie sie unter Einstellungen › Entwickler ein. Sie läuft unter Windows über das Befehlszeilenwerkzeug lgk; in der Microsoft-Store-Version läuft es als LocalGateKeysNativeHost.exe lgk.

LocalGateKeys

Ein Passwortmanager für Windows, Mac und iPhone, der Ihren Tresor auf Ihren eigenen Geräten behält.

Diese Website zählt Seitenaufrufe mit Cloudflare Web Analytics, das ohne Cookies arbeitet. Sie verwendet keine Werbe-Tracker und setzt keine Cookies.
