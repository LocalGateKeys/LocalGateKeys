Gut zu wissen, auf jedem Gerät

  • Ihr Tresor bleibt auf Ihren Geräten. Es gibt kein Konto und keinen LocalGateKeys-Server, der Ihre Passwörter speichert.
  • Niemand kann Ihr Master-Passwort oder App-Passwort zurücksetzen. Richten Sie eine Wiederherstellungsphrase ein und bewahren Sie sie auf Papier auf.
  • Free fasst bis zu 7 Einträge. Pro (US$29.99, einmalig bezahlt) bietet unbegrenzte Einträge, Zwei-Faktor-Codes, Dateien und Synchronisierung. Bearbeiten, Löschen und Ausfüllen vorhandener Einträge wird nie gesperrt.

Themen zur Erweiterung

Füllt Anmeldungen auf Websites aus und speichert sie. Sie spricht nur mit der LocalGateKeys-App auf demselben PC, installieren Sie also zuerst die Windows-App. Sie nutzen Safari? Hier ist nichts herunterzuladen: Die Mac- und iPhone-Apps füllen in Safari über das automatische Ausfüllen aus und bringen eine Safari-Erweiterung mit. Siehe Automatisches Ausfüllen und Safari auf dem Mac oder auf dem iPhone.

Installieren und verbinden

  1. Installieren und richten Sie die Windows-App ein.
  2. Fügen Sie die Erweiterung hinzu: Edge über Edge-Add-ons (wählen Sie Abrufen). Chrome über den Chrome Web Store (wählen Sie Zu Chrome hinzufügen). Firefox über Firefox-Add-ons (wählen Sie Zu Firefox hinzufügen).
  3. Klicken Sie in der Symbolleiste auf das Puzzleteil-Symbol und heften Sie LocalGateKeys an.
  4. Klicken Sie auf das LocalGateKeys-Symbol. Die Verbindungskarte sollte Verbunden oder Gesperrt anzeigen.

Es muss nichts gekoppelt werden: Die Erweiterung findet die App von selbst. Die Einrichtungsanleitung der App hat einen Schritt Verbindung testen zur Kontrolle.

Das Erweiterungsfenster

Verbindung
Verbunden (bereit), Gesperrt (die App bittet ums Entsperren, wenn Sie eine Aktion wählen), Einrichtung erforderlich oder Offline. ↻ aktualisiert die Anzeige, ohne etwas zu entsperren.
Aktuelle Website
Die Website, auf der Sie sind. Angeboten werden nur Anmeldungen, die für genau diese Website gespeichert sind.
Schnellaktionen
Anmeldung ausfüllen, Identität ausfüllen, Karte ausfüllen…, Anmeldung speichern, Passwort generieren.
Speicherabfragen
Ein Schalter, um Speicherabfragen für diese Website aus- oder einzuschalten.

Absichtlich füllt sich nichts von selbst aus. Jedes Ausfüllen beginnt mit Ihrem Klick, und die Erweiterung fragt nie nach Ihrem Master-Passwort: Entsperrt wird immer im LocalGateKeys-Fenster.

Eine Anmeldung ausfüllen

  1. Öffnen Sie die Anmeldeseite der Website.
  2. Klicken Sie auf das LocalGateKeys-Symbol im Feld für Benutzername oder Passwort (Mit LocalGateKeys ausfüllen), oder öffnen Sie die Erweiterung und wählen Sie Anmeldung ausfüllen.
  3. Haben Sie mehrere Konten für die Website, wählen Sie eines unter Konto wählen.
  4. Ist der Tresor gesperrt, entsperren Sie ihn im LocalGateKeys-Fenster, sobald es erscheint.

Ist bei der Anmeldung Nach dem Ausfüllen anmelden eingeschaltet, wird das Formular für Sie abgeschickt. Bei ungewöhnlichen Formularen sehen Sie Automatische Anmeldung übersprungen: Klicken Sie einfach auf die Anmeldeschaltfläche der Website.

Eine neue oder geänderte Anmeldung speichern

  1. Melden Sie sich wie gewohnt auf einer Website an.
  2. Die Erweiterung fragt Diese Anmeldung speichern? (oder bietet an, ein geändertes Passwort zu aktualisieren).
  3. Wählen Sie Im Tresor speichern und bestätigen Sie im LocalGateKeys-Fenster. Oder Nicht jetzt bzw. Nie auf dieser Website.

Um von Hand zu speichern, füllen Sie das Formular aus und wählen Sie im Erweiterungsfenster Anmeldung speichern. Um Abfragen für eine Website wieder einzuschalten, verwenden Sie den Schalter im Erweiterungsfenster.

2FA-Codes ausfüllen

Fragt eine Website nach einem 6-stelligen Code, klicken Sie auf das LocalGateKeys-Symbol im Codefeld (2FA-Code mit LocalGateKeys ausfüllen). Nur der aktuelle Code erreicht die Seite, nie der Einrichtungsschlüssel. Läuft der Code gleich ab, wartet die Erweiterung kurz auf einen neuen.

Für die Anmeldung muss in der App ein 2FA-Einrichtungsschlüssel gespeichert sein (siehe Zwei-Faktor-Codes). Ist Einstellungen › Sperren › Vor dem Freigeben von 2FA-Codes fragen an, bestätigen Sie jedes Mal in der App.

Karten und Identitäten

  1. Klicken Sie in einem Bestell- oder Adressformular auf das Symbol in einem Feld oder wählen Sie Karte ausfüllen… / Identität ausfüllen.
  2. Wählen Sie die Karte oder Identität.
  3. Haken Sie die auszufüllenden Felder an. Der Sicherheitscode (CVV) ist standardmäßig nicht angehakt: Haken Sie ihn nur bei Bedarf an.
  4. Wählen Sie Prüfen und freigeben und geben Sie dann im LocalGateKeys-Fenster frei.

Ein Passwort auf einer Registrierungsseite erstellen

Wählen Sie in einem Registrierungs- oder Passwortänderungsformular Passwort generieren. Das neue Passwort kommt in die Felder für das neue Passwort. Speichern Sie es (über die Speicherabfrage oder Anmeldung speichern), bevor Sie die Seite verlassen.

Passkeys

Bietet eine Website an, einen Passkey zu erstellen oder zu verwenden, kann LocalGateKeys das übernehmen und den Passkey in Ihrem Tresor aufbewahren. Ein- oder ausschalten in der App: Einstellungen › Automatisches Ausfüllen › LocalGateKeys für Passkeys anbieten. Wenn es nicht helfen kann, übernimmt das Passkey-Fenster des Browsers.
