Erste Schritte

Installieren Sie die Windows-App, erstellen Sie Ihren Tresor und fügen Sie dann die Browser-Erweiterung hinzu. Das dauert etwa fünf Minuten, und Sie brauchen nie ein Konto. Fügen Sie die iPhone-App hinzu, wann immer Sie möchten.

1 Windows-App installieren

LocalGateKeys läuft unter Windows 10 (ab Version 2004) und Windows 11, 64 Bit, und kommt aus dem Microsoft Store:

  • Microsoft Store. Der Store installiert die App und hält sie aktuell. LocalGateKeys im Microsoft Store öffnen, Abrufen wählen, dann Öffnen.
  • Den alten Installer verwendet? Deinstallieren Sie ihn unter Windows-Einstellungen › Apps (Installierte Apps unter Windows 11, Apps & Features unter Windows 10) und installieren Sie dann aus dem Microsoft Store. Ihr Tresor bleibt, wo er ist, und die Store-App öffnet ihn mit demselben Master-Passwort.

Im Microsoft Store herunterladen Weitere Downloads

2 Tresor erstellen

  1. Öffnen Sie LocalGateKeys. Beim ersten Start werden Sie aufgefordert, einen Tresor zu erstellen, danach bietet eine kurze Einrichtung Windows Hello, Import, eine Wiederherstellungsphrase und die Browser-Erweiterung an. Überspringen Sie jeden Schritt und schließen Sie ihn später über die Karte Einrichtung abschließen ab.
  2. Wählen Sie ein Master-Passwort mit mindestens 12 Zeichen. Schreiben Sie es auf und bewahren Sie es sicher auf. Wir haben es nie, daher kann es niemand für Sie zurücksetzen.
  3. Öffnen Sie in der Seitenleiste das Sicherheitscenter und richten Sie eine Wiederherstellungsphrase ein. Bewahren Sie sie offline auf, zum Beispiel auf Papier. Sie öffnet den Tresor, falls Sie das Master-Passwort vergessen.
  4. Schalten Sie am selben Ort Windows Hello ein, wenn Ihr PC einen Fingerabdruckleser, eine Hello-Kamera oder eine PIN hat, damit das tägliche Entsperren schnell geht.
  5. Schalten Sie in den Einstellungen geplante Backups ein und wählen Sie, wohin die verschlüsselten Backup-Dateien gehen, zum Beispiel auf einen USB-Stick oder in einen Ordner, den Sie ohnehin sichern.

3 Browser-Erweiterung hinzufügen

Die Erweiterung füllt Anmeldungen in Ihrem Browser aus. Sie spricht nur mit der LocalGateKeys-App auf demselben PC, installieren Sie also zuerst die App.

  1. Erweiterung hinzufügen:
    • Microsoft Edge: in Edge-Add-ons öffnen und Abrufen wählen.
    • Google Chrome: im Chrome Web Store öffnen und Zu Chrome hinzufügen wählen.
    • Mozilla Firefox (Windows): in Firefox Add-ons öffnen und Zu Firefox hinzufügen wählen.
  2. Anheften: Öffnen Sie das Erweiterungsmenü des Browsers (das Puzzleteil-Symbol) und heften Sie LocalGateKeys an die Symbolleiste.
  3. Lassen Sie die App laufen und entsperrt. Öffnen Sie eine Anmeldeseite, für die Sie einen Login gespeichert haben: Die Erweiterung bietet nur die Logins an, die für genau diese Website gespeichert sind. Nichts wird ausgefüllt, bevor Sie klicken.
  4. Melden Sie sich irgendwo neu an, und die Erweiterung bietet an, den Login zu speichern.

Die Erweiterung meldet, dass sie die App nicht erreicht? Öffnen Sie in der App Geräte und Verbindungen, wählen Sie Bridge reparieren und starten Sie dann den Browser neu.

4 Passwörter übernehmen

Wählen Sie in der Seitenleiste Import und Export und wählen Sie eine Exportdatei von 1Password, Bitwarden, LastPass, Dashlane, Proton Pass, KeePass oder KeePassXC, Chrome, Edge, Brave, Firefox oder Safari oder eine beliebige CSV-Datei. Sie prüfen jeden Eintrag, bevor etwas gespeichert wird, und nichts geht online. Löschen Sie die Exportdatei anschließend, denn die meisten Exporte enthalten Passwörter im Klartext.

Die kostenlose Edition fasst bis zu 7 Einträge. Pro hebt das Limit auf.

5 Windows-Apps ausfüllen

Öffnen Sie bei Programmen wie Spiele-Launchern einen Desktop-Login in der App und wählen Sie App-Zuordnung…, um ihn einmal mit dem Anmeldefenster des Programms zu verknüpfen. Danach erscheint neben dem Passwortfeld eine Ausfüllschaltfläche, oder Sie drücken Strg+Umschalt+Leertaste. LocalGateKeys lehnt das Ausfüllen ab, wenn sich das Programm oder Fenster seit der Verknüpfung geändert hat.

6 Pro aktivieren

Pro ist eine einmalige Zahlung, die unbegrenzte Einträge, Synchronisierung zwischen Ihren Geräten, Zwei-Faktor-Codes und Dokumente ergänzt. Wählen Sie nach dem Kauf auf Ihrer Lizenzseite In LocalGateKeys installieren, oder fügen Sie Ihren Lizenzschlüssel unter Einstellungen › Tarif und Synchronisierung › Lizenz ein. Siehe Ihre Pro-Lizenz.

7 iPhone hinzufügen

Die iPhone-App führt einen eigenen verschlüsselten Tresor und synchronisiert mit Ihrem PC. Die Synchronisierung gehört zu Pro.

  1. Installieren Sie LocalGateKeys aus dem App Store und öffnen Sie es.
  2. Tippen Sie auf Entsperren. Der Tresor öffnet sich mit Face ID, Touch ID oder dem Code Ihres iPhone, also müssen Sie kein Passwort erstellen. Eine kurze Einrichtung bietet Import, ein optionales App-Passwort und AutoFill an.
  3. AutoFill einschalten: Wählen Sie in LocalGateKeys Einstellungen › AutoFill › AutoFill-Einstellungen öffnen und schalten Sie dann LocalGateKeys unter Allgemein › AutoFill & Passwörter ein.
  4. Mit dem PC koppeln: Öffnen Sie am PC Sync & Geräte, schalten Sie die WLAN-Synchronisierung ein und wählen Sie QR-Code anzeigen. Öffnen Sie auf dem iPhone den Tab Synchronisierung und tippen Sie auf QR-Code scannen. Prüfen Sie, dass beide Bildschirme denselben Code zeigen, und wählen Sie dann am PC Akzeptieren.
  5. Apple Watch (Pro): Installieren Sie LocalGateKeys in der Watch-App des iPhone, öffnen Sie dann einen Login mit Zwei-Faktor-Code und tippen Sie auf Auf Apple Watch anzeigen.

Pro auf dem iPhone gekauft? Nach dem Koppeln übernimmt ein kostenloser PC die Lizenz per Synchronisierung und wird zu Pro. Hilfe zu jedem iPhone-Bildschirm finden Sie im Benutzerhandbuch.

Mac: Laden Sie die App aus dem Mac App Store. Android: Die App ist in Arbeit. Sie ist noch nicht verfügbar.
