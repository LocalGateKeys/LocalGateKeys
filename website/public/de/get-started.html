Erste Schritte

Installieren Sie die Windows-App, erstellen Sie Ihren Tresor und fügen Sie dann die Browser-Erweiterung hinzu. Das dauert etwa fünf Minuten, und Sie brauchen nie ein Konto.

1. App installieren 2. Tresor erstellen 3. Browser-Erweiterung hinzufügen 4. Passwörter übernehmen 5. Windows-Apps ausfüllen 6. Pro aktivieren iPhone und Android

1 Windows-App installieren

LocalGateKeys läuft unter Windows 10 und Windows 11, 64 Bit. Wählen Sie einen Weg zur Installation:

  • Microsoft Store (empfohlen). Der Store installiert die App und hält sie aktuell. LocalGateKeys im Microsoft Store öffnen, Abrufen wählen, dann Öffnen.
  • Installer. Laden Sie ihn von der Download-Seite herunter, prüfen Sie seinen SHA-256-Wert wie dort beschrieben und führen Sie ihn aus. Windows SmartScreen warnt möglicherweise, weil der Installer noch nicht codesigniert ist: Stimmt der Fingerabdruck überein, wählen Sie Weitere Informationen und dann Trotzdem ausführen.

Verwenden Sie auf einem PC nur eine der beiden Varianten.

Im Microsoft Store herunterladen Weitere Downloads

2 Tresor erstellen

  1. Öffnen Sie LocalGateKeys. Beim ersten Start werden Sie aufgefordert, einen Tresor zu erstellen.
  2. Wählen Sie ein Master-Passwort mit mindestens 12 Zeichen. Schreiben Sie es auf und bewahren Sie es sicher auf. Wir haben es nie, daher kann es niemand für Sie zurücksetzen.
  3. Öffnen Sie in der Seitenleiste das Sicherheitscenter und richten Sie eine Wiederherstellungsphrase ein. Bewahren Sie sie offline auf, zum Beispiel auf Papier. Sie öffnet den Tresor, falls Sie das Master-Passwort vergessen.
  4. Schalten Sie am selben Ort Windows Hello ein, wenn Ihr PC einen Fingerabdruckleser, eine Hello-Kamera oder eine PIN hat, damit das tägliche Entsperren schnell geht.
  5. Schalten Sie in den Einstellungen geplante Backups ein und wählen Sie, wohin die verschlüsselten Backup-Dateien gehen, zum Beispiel auf einen USB-Stick oder in einen Ordner, den Sie ohnehin sichern.

3 Browser-Erweiterung hinzufügen

Die Erweiterung füllt Anmeldungen in Ihrem Browser aus. Sie spricht nur mit der LocalGateKeys-App auf demselben PC, installieren Sie also zuerst die App.

  1. Erweiterung hinzufügen:
    • Microsoft Edge: in Edge-Add-ons öffnen und Abrufen wählen.
    • Google Chrome: demnächst im Chrome Web Store.
  2. Anheften: Öffnen Sie das Erweiterungsmenü des Browsers (das Puzzleteil-Symbol) und heften Sie LocalGateKeys an die Symbolleiste.
  3. Lassen Sie die App laufen und entsperrt. Öffnen Sie eine Anmeldeseite, für die Sie einen Login gespeichert haben: Die Erweiterung bietet nur die Logins an, die für genau diese Website gespeichert sind. Nichts wird ausgefüllt, bevor Sie klicken.
  4. Melden Sie sich irgendwo neu an, und die Erweiterung bietet an, den Login zu speichern.

Die Erweiterung meldet, dass sie die App nicht erreicht? Öffnen Sie in der App Geräte und Verbindungen, wählen Sie Bridge reparieren und starten Sie dann den Browser neu.

4 Passwörter übernehmen

Wählen Sie in der Seitenleiste Import und Export und wählen Sie eine Exportdatei von 1Password, Bitwarden, LastPass, Dashlane, Proton Pass, KeePass oder KeePassXC, Chrome, Edge, Brave, Firefox oder Safari oder eine beliebige CSV-Datei. Sie prüfen jeden Eintrag, bevor etwas gespeichert wird, und nichts geht online. Löschen Sie die Exportdatei anschließend, denn die meisten Exporte enthalten Passwörter im Klartext.

Die kostenlose Edition fasst bis zu 4 Einträge. Pro hebt das Limit auf.

5 Windows-Apps ausfüllen

Öffnen Sie bei Programmen wie Spiele-Launchern einen Desktop-Login in der App und wählen Sie App-Zuordnung…, um ihn einmal mit dem Anmeldefenster des Programms zu verknüpfen. Danach erscheint neben dem Passwortfeld eine Ausfüllschaltfläche, oder Sie nutzen die Tastenkombination. LocalGateKeys lehnt das Ausfüllen ab, wenn sich das Programm oder Fenster seit der Verknüpfung geändert hat.

6 Pro aktivieren

Pro ist eine einmalige Zahlung, die unbegrenzte Einträge, Synchronisierung zwischen Ihren Geräten, Zwei-Faktor-Codes und Dokumente ergänzt. Fügen Sie nach dem Kauf Ihren Lizenzschlüssel in der App unter Werkzeuge > Lizenz ein. Siehe Ihre Pro-Lizenz.

iPhone und Android

iPhone: installieren Sie LocalGateKeys aus dem App Store. Es synchronisiert mit Ihrem Windows-PC.

Android: eine Android-App ist geplant. Sie ist noch nicht verfügbar.

Die Einrichtungsschritte für Android erscheinen auf dieser Seite, sobald die App veröffentlicht ist. Bis dahin bleibt Ihr Tresor auf Ihrem PC, und mit Pro können Sie zwischen Windows-PCs synchronisieren.
