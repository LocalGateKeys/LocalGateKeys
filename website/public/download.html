Check the installer before running it

Compare the installer's fingerprint with the SHA-256 value above. In PowerShell, from the folder you downloaded it to:

Get-FileHash .\LocalGateKeys-Setup-Personal.exe -Algorithm SHA256

If the values do not match, do not run the file. Download it again from this page and tell us at security@localgatekeys.app.

What you need

  • Windows 10 or Windows 11, 64-bit
  • A current version of Google Chrome or Microsoft Edge for browser fill
  • Windows Hello hardware (fingerprint reader, Hello camera or a PIN) for Windows Hello unlock
  • For sync: Pro, and two or more PCs on the same network or a cloud-drive app installed on each

After installing

The Get started guide walks through every step, with screenshots.

  1. Open LocalGateKeys and choose a master password of at least 12 characters. Write it down somewhere safe; we cannot reset it.
  2. Create a recovery phrase in Settings and keep it offline.
  3. Turn on scheduled backups in Settings.
  4. Add the browser extension for Edge and pin it to the toolbar. The extension only works with the app installed.
  5. Bought Pro? Enter your licence key in Tools > Licence. See your Pro licence.
