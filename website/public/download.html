Used the old installer?

Uninstall it in Windows Settings › Apps › Installed apps, then install LocalGateKeys from the Microsoft Store. Your vault stays where it is: the Store app opens it with the same master password.

What you need

  • Windows 10 or Windows 11, 64-bit
  • A current version of Google Chrome or Microsoft Edge for browser fill
  • Windows Hello hardware (fingerprint reader, Hello camera or a PIN) for Windows Hello unlock
  • For sync: Pro, and two or more devices on the same network, or a cloud-drive app on each
  • For Apple Watch codes: Pro, and an Apple Watch paired with your iPhone

After installing

The Get started guide walks through every step, with screenshots.

  1. Open LocalGateKeys and choose a master password of at least 12 characters. Write it down somewhere safe; we cannot reset it.
  2. Create a recovery phrase when the setup guide offers it, and keep it offline.
  3. Turn on scheduled backups in Settings.
  4. Add the browser extension for Edge, Firefox or Chrome and pin it to the toolbar. The extension only works with the app installed.
  5. Bought Pro? Enter your licence key in Tools > Licence. See your Pro licence.
