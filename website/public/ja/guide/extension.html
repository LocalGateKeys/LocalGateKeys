このデバイスのすべての画面と機能を手順ごとに説明します。各見出しは共有できるリンクです。

どのデバイスでも知っておきたいこと

  • 保管庫はあなたのデバイスにとどまります。アカウントはなく、パスワードを保存する LocalGateKeys のサーバーもありません。
  • マスターパスワードやアプリのパスワードは誰にもリセットできません。リカバリーフレーズを設定し、紙に書いて保管してください。
  • Free は最大 7 件まで保存できます。Pro(US$29.99、買い切り)では項目数が無制限になり、2 要素コード、ファイル、同期が使えます。既存の項目の編集、削除、入力がブロックされることはありません。

拡張機能のトピック

Web サイトでサインイン情報を入力・保存します。同じ PC 上の LocalGateKeys アプリとだけ通信するので、先に Windows アプリをインストールしてください。Safari をお使いですか？ここでダウンロードするものはありません。Mac と iPhone のアプリが自動入力で Safari に入力し、Safari 機能拡張も含まれています。Mac の自動入力と Safari または iPhone の場合をご覧ください。

インストールと接続

  1. Windows アプリをインストールして設定します。
  2. 拡張機能を追加します:Edge は Edge アドオンから(インストールを選択)。Chrome は Chrome ウェブストアから(Chrome に追加を選択)。Firefox は Firefox Add-onsから(Firefox へ追加を選択)。
  3. ツールバーのパズルピースのアイコンをクリックし、LocalGateKeys をピン留めします。
  4. LocalGateKeys のアイコンをクリックします。接続カードに接続済みまたはロック中と表示されれば OK です。

ペアリングは不要です。拡張機能がアプリを自動で見つけます。アプリのセットアップガイドには、確認用の接続をテストの手順があります。

拡張機能のウィンドウ

接続
接続済み(準備完了)、ロック中(操作を選ぶとアプリがロック解除を求めます)、セットアップが必要、オフライン。↻ で何もロック解除せずに状態を更新します。
現在のサイト
開いているサイトです。このサイト用に保存されたログインだけが提案されます。
クイック操作
ログインを入力、ID を入力、カードを入力…、ログインを保存、パスワードを生成。
保存の確認
このサイトで保存の確認を表示するかどうかを切り替えるスイッチです。

設計上、勝手に入力されることはありません。入力は必ずクリックから始まり、拡張機能がマスターパスワードを求めることもありません。ロック解除は常に LocalGateKeys のウィンドウで行います。

ログインを入力する

  1. サイトのサインインページを開きます。
  2. ユーザー名またはパスワード欄の中の LocalGateKeys アイコン(LocalGateKeys で入力)をクリックするか、拡張機能を開いてログインを入力を選びます。
  3. そのサイトに複数のアカウントがある場合は、アカウントを選択で 1 つ選びます。
  4. 保管庫がロックされている場合は、表示される LocalGateKeys のウィンドウでロックを解除します。

ログインで入力後にサインインがオンなら、フォームが自動で送信されます。特殊なフォームでは自動サインインをスキップしましたと表示されるので、サイトのサインインボタンをクリックしてください。

新しいログインや変更したログインを保存する

  1. いつもどおり Web サイトにサインインします。
  2. 拡張機能がこのログインを保存しますか?と確認します(変更されたパスワードの更新を提案することもあります)。
  3. 保管庫に保存を選び、LocalGateKeys のウィンドウで確定します。今はしないやこのサイトでは保存しないも選べます。

手動で保存するには、フォームに入力してから拡張機能のウィンドウでログインを保存を選びます。サイトの確認を再びオンにするには、拡張機能のウィンドウのスイッチを使います。

2FA コードを入力する

サイトが 6 桁のコードを求めたら、コード欄の LocalGateKeys アイコン(LocalGateKeys で 2FA コードを入力)をクリックします。ページに渡るのは現在のコードだけで、セットアップキーは渡りません。コードの期限が迫っている場合、拡張機能は新しいコードを少し待ちます。

ログインには、アプリで 2FA セットアップキーが保存されている必要があります(2 要素コードを参照)。設定 › ロック › 2FA コードを渡す前に確認がオンの場合は、毎回アプリで確定します。

カードと ID

  1. 購入手続きや住所のフォームで、フィールド内のアイコンをクリックするか、カードを入力… / ID を入力を選びます。
  2. カードまたは ID を選びます。
  3. 入力するフィールドにチェックを入れます。セキュリティコード(CVV)は既定でオフです。必要なときだけチェックしてください。
  4. 確認して承認を選び、LocalGateKeys のウィンドウで承認します。

登録ページでパスワードを作成する

登録フォームやパスワード変更フォームでパスワードを生成を選びます。新しいパスワードが新しいパスワード欄に入ります。ページを離れる前に、保存の確認またはログインを保存で保存してください。

パスキー

サイトがパスキーの作成や使用を提案したとき、LocalGateKeys が処理してパスキーを保管庫に保存できます。アプリの 設定 › 自動入力 › パスキーに LocalGateKeys を提案でオン/オフを切り替えます。対応できない場合は、ブラウザのパスキー画面に切り替わります。
