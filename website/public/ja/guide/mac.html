どのデバイスでも知っておきたいこと

  • 保管庫はあなたのデバイスにとどまります。アカウントはなく、パスワードを保存する LocalGateKeys のサーバーもありません。
  • マスターパスワードやアプリのパスワードは誰にもリセットできません。リカバリーフレーズを設定し、紙に書いて保管してください。
  • Free は最大 7 件まで保存できます。Pro(US$29.99、買い切り)では項目数が無制限になり、2 要素コード、ファイル、同期が使えます。既存の項目の編集、削除、入力がブロックされることはありません。

Mac のトピック

サイドバーには項目(すべての項目、お気に入り、最近使った項目、各種類、コレクション)と、ツールのセキュリティセンター、ジェネレーター、同期とデバイス、インポートとエクスポート、ゴミ箱が並び、一番下に設定があります。リカバリーセンターは設定 › バックアップから、デバイスと接続は同期とデバイスから開きます。

保管庫を作成する

  1. LocalGateKeys を開き、マスターパスワードを 2 回入力して保管庫を作成を選びます。
  2. 続いてセットアップです:Touch ID を設定、パスワードをインポート…、リカバリーフレーズを開く、Safari と自動入力のためのデバイスと接続を開く。

ロック解除とロック

  • Touch ID:設定 › セキュリティ › ロック解除 › Touch ID。指紋を変更した場合は、一度マスターパスワードを使ってください。
  • マスターパスワードを変更:設定 › ロック解除。項目はそのまま残ります。
  • リカバリーフレーズ:リカバリーセンターで設定し、3 つの単語を確認します。マスターパスワードを忘れた場合は、ロック画面でマスターパスワードを忘れた場合 › リカバリーフレーズで復旧を選びます。
  • ロック:⌘L。設定 › ロック で、操作がないときのロック、画面ロックと連動、スリープ時、セッションの最大時間を設定します。操作がないときのロックで、何を操作とみなすかも選べます。

項目

  • 新規項目(⌘N)では iPhone と同じ種類に加えてファイルを添付…(Pro)が使えます。
  • コピー:⌘C(パスワード)、⇧⌘C(ユーザー名)、⌘T(2FA コード)。
  • カスタムフィールド用のフィールドを追加、タグ、コレクション(他のデバイスと同期されます)。
  • ⌫ で項目を最近削除した項目に移します。サイドバーのゴミ箱を開き、選択を復元またはゴミ箱を空にするを使います。
  • 添付ファイルは、Touch ID またはマスターパスワードの後にクイックルックで開きます。
  • 生成:ランダムなパスワード(文字の種類を選択、紛らわしい文字を避ける)またはパスフレーズ(大文字化、数字を追加、区切り文字)。

2 要素コード Pro

QR コードをスキャン…を選び、画像を選択…、⌘V でスクリーンショットを貼り付け(⌃⇧⌘4 でコピー)、または画像をドラッグします。コードは自動入力で Safari に入力されます。

セキュリティセンター

弱い、使い回し、古いパスワードを表示します。設定 › プライバシー › 漏洩チェックをオンにすると(厳格なオフラインモードがオフの場合)、すべてのパスワードを確認で漏洩を調べます。

自動入力、パスキー、Safari

  1. デバイスと接続を開きます。
  2. 自動入力の設定を開くを選び、システム設定 › 自動入力とパスワード で LocalGateKeys をオンにします。
  3. Safari の設定を開くを選び、Safari › 設定 › 機能拡張 で LocalGateKeys 機能拡張をオンにします。

Safari でサインイン情報を入力するには、ユーザ名またはパスワードの欄をクリックします。その下に LocalGateKeys のログインが表示されるので、1 つ選び、Touch ID またはマスターパスワードで確認します。パスキーと 2FA コードも同じように表示され、自動入力はほかの Mac アプリでも使えます。

Safari 機能拡張は、サインインした後に新しいログインの保存を提案します。取り込んだ内容は、次に LocalGateKeys のロックを解除したときに確認します。他のブラウザは Mac ではまだサポートされていません。

ログインが表示されない場合は、デバイスと接続を開き、自動入力がオンになっているか確認してください。同じシステム設定のページで「パスワード」をオフにすると、LocalGateKeys だけがログインを表示します。

デバイスと接続を開いたときに LocalGateKeys が終了する場合は、Mac App Store でアップデートしてください。

インポートとエクスポート

  • Apple パスワード(macOS 26):ログイン、2FA、パスキー。インポート前に確認します。
  • ファイル:Bitwarden の .json(パスワード保護付きも可)、1Password の .1pux、KeePass の .kdbx、列を選択付きの CSV。
  • iPhone と Android の .lgkm バックアップ:新しい項目をすべて追加、重複は両方を保持、すべてスキップから選びます。何も消去されません。
  • 暗号化バックアップ、または CSV(暗号化なし、事前に確認)をエクスポートします。

バックアップ

リカバリーセンターで:

  • 完全バックアップ:.lgk ファイルを作成…、または復元…(保管庫を置き換えます)。Mac と Windows の間で使えます。安全のためのコピーが残るので、元に戻す…で復元を取り消せます。
  • スケジュールバックアップ:頻度、曜日、時刻、保持する数、フォルダーとミラーフォルダー、バックアップのパスワード(12 文字以上)。
  • リカバリーキット…:最新のバックアップを説明するファイルで、バックアップと一緒に保管します。緊急キットを印刷…では、保管庫とバックアップの場所と復元方法を記したページを印刷します。

同期 Pro

  • Wi-Fi(このネットワーク):Wi-Fi 同期をオンにするを選び、QR コードを表示…を選びます。デバイスが参加したらコードを確認し、承認または拒否を選びます。後で心当たりがなければ元に戻すを選びます。
  • コードで参加:もう一方のデバイスでQR コードを表示、コードのテキストをコピーの順に選び、そのテキストをここに貼り付けます。
  • クラウドフォルダー:Dropbox や iCloud Drive などのフォルダーで、同期パスワードを使ってグループに参加するか作成します。OneDrive と Google Drive は、Apple 側の問題が解決するまで現在使えません。
  • 同期から退出… / この Mac の同期をリセット…。

共有

項目を選んで共有…を選びます。受け取るには 編集 › 共有された項目を受け取る…を選び(または ⌘K で検索)、ファイルを開くかドロップして(または QR テキストを貼り付けて)、6 つの単語を入力します。パスキーやファイルが添付された項目は共有できません。

Pro

Pro は 設定 › プラン で購入します。1 回の購入で iPhone と Mac の両方のアプリに有効です。もう一方のデバイスでは購入を復元を使います。Pro の iPhone と同期している無料の Mac には同期したデバイスからの Proと表示されます。

設定

設定はメインウインドウでも ⌘, でも同じで、ツールはサイドバーの下部に常に表示されます。設定 › バックアップには、スケジュール、毎週の復元テスト、保持する自動バックアップの数があります。リカバリーセンター、ライセンス、セットアップの再表示はどちらのウインドウからも開けます。そのほかの設定:自動ロックで何をアクティビティとみなすか、2 段階認証コードをコピーする前の確認、保管庫に保存した書類をほかのアプリで開く、クイックアクセスの独自ショートカット、ヘルプのリンク。

強要時パスワード(Pro、設定 › 強要時パスワード):誰かにロック解除を強要されたときのための 2 つ目のマスターパスワードです。選んだ項目だけが入った別の保管庫が開き、本物の保管庫は設定した時間のあいだマスターパスワードを受け付けなくなります。
