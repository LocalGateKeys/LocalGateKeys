LocalGateKeysをダウンロード

ダウンロードは、どちらのエディションも共通で、WindowsでもMacでもiPhoneでも同じです。最初はすべて無料版として始まり、Proにすると7件の上限がなくなり、同期、2段階認証コード、ドキュメントが使えるようになります。

Microsoft Store

LocalGateKeys をインストールし、常に最新の状態に保ちます。Windows 10 または 11、64 ビット。

ユーザーガイド

Microsoft Storeで入手

Google Chrome用拡張機能

同じPCにLocalGateKeysアプリがインストールされている必要があります。

ユーザーガイド

Chromeに追加

Microsoft Edge用拡張機能

同じPCにLocalGateKeysアプリがインストールされている必要があります。

ユーザーガイド

Edgeに追加

Mozilla Firefox 用拡張機能

Windows 版 Firefox 用。同じ PC に LocalGateKeys アプリのインストールが必要です。

ユーザーガイド

Firefox に追加

iPhone

iPhoneアプリはApp Storeで公開中で、Apple Watchアプリも含まれます。PCやMacと同期し、アプリ内でProを購入するとWindowsも利用できるようになります。

ユーザーガイド

App Storeでダウンロード

Mac

Mac アプリは Mac App Store で入手できます。PC や iPhone と同期し、Touch ID とメニューバーに対応しています。Safari では自動入力でサインイン情報を入力し、Safari 機能拡張が新しいサインインの保存を提案します。

ユーザーガイド

Mac App Store からダウンロード

Android

Android アプリは準備中です。まだ Google Play にはありません。

ユーザーガイド

近日公開

以前のインストーラー版を使っていましたか？

Windows の設定 › アプリ › インストールされているアプリ でアンインストールしてから、Microsoft Store から LocalGateKeys をインストールしてください。保管庫はそのまま残り、Store 版アプリが同じマスターパスワードで開きます。

必要なもの

  • Windows 10またはWindows 11(64ビット)
  • ブラウザーでの入力には、最新バージョンのGoogle ChromeまたはMicrosoft Edge
  • Windows Helloでのロック解除には、Windows Helloに対応したハードウェア(指紋リーダー、Helloカメラ、またはPIN)
  • 同期には、Proと、同じネットワーク上の2台以上のデバイス、またはそれぞれにインストールされたクラウドドライブアプリ
  • Apple Watchのコードを使うには、Proと、iPhoneとペアリングしたApple Watchが必要です

インストール後

はじめにガイドでは、すべての手順をスクリーンショット付きで説明しています。

  1. LocalGateKeysを開き、12文字以上のマスターパスワードを決めます。安全な場所に書き留めておいてください。当社ではリセットできません。
  2. セットアップガイドが案内したら、リカバリーフレーズを作成し、オフラインで保管してください。
  3. 設定で定期バックアップをオンにします。
  4. ブラウザー拡張機能を追加し(Edge用), Firefox(Chrome用)、ツールバーにピン留めします。拡張機能は、アプリがインストールされている場合にのみ動作します。
  5. Proを購入しましたか? 「ツール > ライセンス」にライセンスキーを入力してください。Proライセンスもご覧ください。
