LocalGateKeysをダウンロード

ダウンロードは、どちらのエディションも共通です。最初は無料版として始まり、Proライセンスキーを入れると4件の上限がなくなり、同期、2段階認証コード、ドキュメントが使えるようになります。

Microsoft Store

インストールも更新も、いちばん簡単な方法です。Windows 10または11(64ビット)。

Microsoft Storeで入手

Windows用インストーラー

バージョン0.4.10。Storeを使いたくない方向けです。Windows 10または11(64ビット)。

SHA-256: E08185448318A793E20A5662DB38C58D93774FFA6B819D9EC6A1D8DB9967192D

このインストーラーにはまだコード署名がないため、Windows SmartScreenに「Windows によってPCが保護されました」と表示されることがあります。まず上のSHA-256を確認し(下の「インストーラーを確認する」を参照)、一致していれば「詳細情報」を選び、「実行」を選んでください。

インストーラーをダウンロード

Google Chrome用拡張機能

同じPCにLocalGateKeysアプリがインストールされている必要があります。

iPhone

iPhoneアプリはApp Storeで公開中です。PCと同期します。

App Storeでダウンロード

実行する前にインストーラーを確認する

インストーラーのフィンガープリントを、上のSHA-256の値と比べてください。ダウンロードしたフォルダーで、PowerShellから次のように実行します:

Get-FileHash .\LocalGateKeys-Setup-Personal.exe -Algorithm SHA256

値が一致しない場合は、そのファイルを実行しないでください。このページからもう一度ダウンロードし、security@localgatekeys.appまでお知らせください。

必要なもの

  • Windows 10またはWindows 11(64ビット)
  • ブラウザーでの入力には、最新バージョンのGoogle ChromeまたはMicrosoft Edge
  • Windows Helloでのロック解除には、Windows Helloに対応したハードウェア(指紋リーダー、Helloカメラ、またはPIN)
  • 同期には、Proと、同じネットワーク上の2台以上のPC、またはそれぞれにインストールされたクラウドドライブアプリ

インストール後

はじめにガイドでは、すべての手順をスクリーンショット付きで説明しています。

  1. LocalGateKeysを開き、12文字以上のマスターパスワードを決めます。安全な場所に書き留めておいてください。当社ではリセットできません。
  2. 設定でリカバリーフレーズを作成し、オフラインで保管してください。
  3. 設定で定期バックアップをオンにします。
  4. ブラウザー拡張機能を追加し(Edge用)、ツールバーにピン留めします。拡張機能は、アプリがインストールされている場合にのみ動作します。
  5. Proを購入しましたか? 「ツール > ライセンス」にライセンスキーを入力してください。Proライセンスもご覧ください。
