セキュリティモデルをわかりやすく

LocalGateKeysが守るように設計されているもの、そして守れないもの。

保管庫の暗号化の仕組み

ランダムな256ビットの鍵が保管庫を暗号化します。この鍵はそのままの形では保存されず、ロック解除の方法ごとに別々にラップ(暗号化)されます。そのため、パスワードを変更してもすべてを再暗号化する必要はなく、別の保管庫からコピーしたラッパーは拒否されます。

保管庫の暗号化
AES-256-GCM。保存のたびに新しいランダムなナンスを使用
マスターパスワード
Argon2id、3パス、並列度4、ラッパーごとにランダムなソルト。メモリはWindowsアプリで256 MiB(メモリが4 GB未満のPCでは64 MiB)、Mac、iPhone、Androidのアプリで64 MiB
リカバリーフレーズ
任意の24語のBIP39フレーズ(256ビット)。HKDF-SHA256で拡張
Windows Hello、Touch ID、Face ID、指紋認証
デバイスが保護する保存領域から保管庫の鍵を取り出します。マスターパスワードが保存されることはありません
バックアップと転送
Argon2idとAES-256-GCM。パラメーターは認証付きヘッダーに保存
デバイス同期
ランダムなグループ鍵を、X25519とHKDF-SHA256で各デバイスに渡します。クラウドフォルダーの場合は、さらに同期パスワードからArgon2idでラップします。すべてのレコードはAES-256-GCMで封印され、項目、バージョン、鍵のエポックに結び付けられます。各デバイスのファイルは、書き込んだデバイスに結び付けられます
パスキー
ES256(P-256)の鍵を暗号化された保管庫内に保持します。署名するデータは、ページからではなく、ブラウザーが報告するオリジンからアプリが組み立てます。Microsoft Store版のアプリはWindows 11のパスキープロバイダーにもなれます(既定ではオフ)。その場合、Windowsはパスキーのサイト名とアカウント名を独自の一覧に保持しますが、鍵は保持しません
ディスクへの書き込み
一時ファイルに書き込み、フラッシュしてから、アトミックに置き換えるので、クラッシュしても保管庫が中途半端な状態で残ることはありません
AIエージェント
既定ではオフ(Pro)。エージェントは、お使いのデバイス上のlgk mcpを通じてのみアプリにアクセスでき、許可したログインと項目だけが見えます。リクエストは1件ずつあなたが承認し、サインインの入力はアプリ自身が行います。エージェントへの応答にパスワードが含まれることはありません。各リクエストはアクセスログに記録され、その項目はSHA-256ハッシュで連鎖しています。セキュリティチェックで連鎖が損なわれていないかを確認できます

守ることを想定しているもの

  • 保管庫のファイルやバックアップをコピーしたが、マスターパスワードを知らない相手
  • 別のWebサイトのために保存されたログインやパスキーを、Webサイトが取得すること
  • 専用のブラウザーヘルパーに渡すセッションシークレットを持たずに、PC上の別のプログラムがLocalGateKeysと通信すること
  • 紐付けした後で、すり替え、更新、変更が行われたデスクトップアプリへの入力
  • 暗号化されていないパスワードがディスクにあること
  • ご自身の操作なしにフォームが送信されること
  • クラウドプロバイダーが同期データを読み取ること(保存されるのは暗号文だけ)
  • LocalGateKeysが提示するアカウントをWebページが読み取ること。Chrome、Edge、Firefoxでは、ページが読み取れない拡張機能専用のフレームに一覧を表示します
  • AIエージェントがLocalGateKeysからパスワードを取得すること。エージェントへの応答にパスワードは含まれず、エージェントに見えるのは許可したログインだけです

守れないもの

  • すでにPCで動作しているマルウェアや、管理者権限を持つ相手
  • 侵害されたブラウザー、Windows、または依存コンポーネント
  • ご自身の意思でパスワードを入力したWebサイト
  • 保管庫がロック解除されている間に、あなたのPCを使う人
  • 攻撃者が内容を操作できる、正規のアプリの中でのフィッシング
  • 保管庫、バックアップ、マスターパスワードをすべて失い、リカバリーフレーズもない場合: 当社を含め、誰にも開けません
  • ブラウザーを操作するAIエージェントが、LocalGateKeysがページに入力したパスワードを読み取ること、またはあなたが承認したコマンドが受け取ったシークレットを外部に渡すこと

LocalGateKeysが決して行わないこと

パスワードを入力する方法の中には、スパイウェアと区別がつかないものがあり、設計上排除しています。LocalGateKeysには次のものが含まれません:

  • キーボードフックやキー入力の記録
  • クリップボードの監視
  • 認証情報を探すための画面の読み取りやOCR
  • 他のプログラムのメモリのスキャン
  • ブラウザーに保存されたパスワードのデータベースの復号
  • 他のプログラムやゲームへのコード注入
  • ご自身が開始していないサインインの送信

ネットワークについて正直に

LocalGateKeysのアカウントはなく、保管庫を保持するサーバーもありません。アプリがインターネットに接続するのは、次の場合だけです:

  • アップデート。WindowsアプリはMicrosoft Storeが、MacアプリとiPhoneアプリはApp Storeがアップデートします。LocalGateKeys自身がインストーラーをダウンロードしたり実行したりすることはありません。提供を終了したWindowsのインストーラー版(最終版の0.4.12まで)は、「アップデートを確認」を選んだときに当社のサーバーから小さなファイルを1つダウンロードし、アプリに組み込まれた鍵で署名を検証します。
  • ライセンス失効リスト。インストーラー版でのアップデート確認のたび、およびMicrosoft Store版のアプリで厳格なオフラインモードがオフのときに「アップデートを確認」を選ぶと、アプリは返金済みライセンスの署名付きリストをダウンロードし、お使いのPC上でライセンスを照合します。ライセンスに関する情報は何も送信しません。
  • Webサイトのアイコン。サイトのアイコンを表示するため、アプリはそのサイト自身のアドレスからアイコンをダウンロードします。ユーザー名、パスワード、保管庫のデータは送信されませんが、ダウンロードのたびに、そのサイトとネットワークを監視している人に、保管庫にそこのアカウントがあることが伝わります。既定ではオフで、設定で「Webサイトのアイコンを表示」をオンにした場合にのみ行われます。厳格オフラインモードではブロックされます。
  • 漏えいチェック(オンにした場合)。チェックを開始すると、アプリは各パスワードのSHA-1ハッシュの先頭5文字をHave I Been Pwnedに送信します。このサービスが目にするのはIPアドレスだけで、パスワード、完全なハッシュ、ユーザー名、Webサイトを目にすることはありません。
  • 同期(設定した場合)。家庭内のネットワークでは、デバイス同士が直接通信します。クラウドフォルダー経由の場合は、クラウドドライブアプリがアップロードを行います。
  • Mac、iPhone、AndroidアプリでのPro購入。アプリはストアの署名付き購入記録を当社のライセンスサーバーに送信し、サーバーはライセンスキーを返します。メールアドレスやデバイスのデータは送信しません。
  • 確認済みサイト。そっくりなアドレスの検出はお使いのデバイス上で行われます。保存したサイトがアプリの外に出ることはなく、サーバーには何も送信されません。

Windowsアプリでは、セキュリティセンター › ネットワークアクティビティに、これらの接続が時刻、ホスト、結果とともに一覧表示されます。保存したWebサイトの名前はアプリの実行中にだけ表示され、ディスクに書き込まれることはありません。自宅のネットワーク上のデバイスは「ローカルネットワーク」と表示されます。

厳格オフラインモードは既定でオンです。バックグラウンドでのインターネット通信、Webサイトのアイコン、漏えいチェックをブロックし、アップデートの確認では事前にお尋ねします。アップデートを確認したときに当社のサーバーが目にする情報は、プライバシーポリシーに正確に記載しています。

既知の制限事項

  • マスターパスワードは、アプリに届いた時点で消去可能なバッファに移され、必要とした処理が終わると消去されます。入力するページはMicrosoft Edge WebView2で動作しています。ページは入力欄を空にし、アプリは受け渡しで作られたコピーを手放しますが、これは鍵が計算される前に行われます。ただし、この2つのコピーはどちらもメモリ上で上書きできないため、しばらくの間は痕跡が残ることがあります。
  • カメラによるロック解除ではランダムな頭の動きを求めるため、カメラの前に平らにかざした写真や、画面に映した静止画では通過できません。ただし、これはあくまで利便性のためのチェックであり、認定された保護ではありません。曲げたり折ったりした写真、指示に合わせて動く動画、マスクでは通過する可能性があります。より強力なのは Windows Hello です。
  • Windowsアプリへの入力は、管理者として実行されているプログラム、独自に描画されたゲームの画面、検証できない埋め込みWebビューでは動作しません。
  • 保管庫は、古いコピーに巻き戻されたことを検出します。同期を使っている場合は、他のデバイスが保管庫の新しさを記憶しているため、どれかのデバイスに古いコピーが戻されると、次の同期でどのアプリでも通知されます。同期を使わない場合、Windows PCは保管庫フォルダーの外に2つ目の記録を保持するため、アンカーファイルごと元に戻された古い保管庫は受け付けられません。ただし、Windowsアカウントの設定を変更できる人は、この記録も削除できます。iPhone、Mac、Androidのアプリは他のアプリからファイルを保護していますが、同期を使わない場合、古いコピーに置き換えられても気づきません。
  • パスキーはChrome、Edge、Firefoxで使えます。別のサイトのフレーム内でパスキーを使ってサインインする機能は、外側のサイトが許可している場合にChromeとEdgeで動作します。Firefoxでの場合と、別のサイトのフレーム内でパスキーを作成する場合は、ブラウザー標準のパスキーのダイアログを使います。新しいパスキーを承認した後にサイト側でキャンセルされると、アプリはそのパスキーを再び削除します。サイトがパスキーを保持したかどうかをアプリが判断できない場合、パスキーは保管庫に残るため、アプリで削除できます。
  • そっくりなアドレスの警告は目安であり、防壁ではありません。ページ自身のスクリプトは、たとえばフォームを送信せずにパスワードを送るなどして、これを回避できます。アドレスはご自身でも確認してください。
  • 緊急アクセスにはサーバーがないため、待機期間とあなたの拒否を強制するのはアプリだけです。十分な数のシェアを持つ人は、待たずにすぐバックアップを復旧できます。一緒に動かない人を選び、シェアは別々に保管してください。
  • 強制用パスワードは、アプリのロック解除を強要される場合に備えるものです。ディスク上のファイルを調べる人には効きません。注意深い人なら2つ目の保管庫があることに気づく可能性があります。Windows、Mac、iPhone、Androidで使えます。
