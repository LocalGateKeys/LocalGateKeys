できることと、その動作場所

これらはすべてご自身のデバイス上で動作します。Windowsアプリ、ブラウザー拡張機能、iPhoneアプリが対象です。無料版は7件まで。Proでは上限がなくなり、同期、2段階認証コード、ドキュメントが加わります。

保管庫

ディスク上で暗号化
保存した内容はすべて、マスターパスワードで保護された鍵により、Argon2idとAES-256-GCMで暗号化されます。パスワードだけでなく、名前、ユーザー名、Webサイトも暗号化されます。
パスワード以外にも
Webサイトやデスクトップアプリのログイン、パスキー、支払いカード、銀行口座、個人情報、セキュアノート、ドキュメント、SSHキー、APIキー、Wi-Fiネットワーク、ブックマーク、ソフトウェアライセンス、サブスクリプション、保証、購入履歴を、それぞれ専用の欄で保存できます。
ドキュメント(Pro)
スキャンした書類などのファイルを、1件あたり最大25 MBまで保管庫に保管できます。各ファイルはそれぞれ専用の鍵で暗号化されます。ドキュメントのプレビュー、コピーの保存、他のアプリで開くことができます。同期すると、ファイルは暗号化されたまま他のデバイスにも届きます。
2段階認証コード(Pro)
サイトのセットアップキーを保存すると、LocalGateKeysがログインの上部とホーム画面のワンタイムコードカードに現在のコードを表示します。コードはTOTP標準(RFC 6238)に従い、6〜8桁、15〜120秒、SHA-1、SHA-256、SHA-512に対応します。
Apple Watchでコードを表示(Pro)
選んだ2段階認証コードをApple Watchに最大10件表示できます。Watchに表示されるのはコードだけで、パスワードは表示されず、iPhoneが近くになくても使えます。
QRコードをスキャン
「QRコードをスキャン」を選び、サイトの2段階認証のQRコードをWin+Shift+Sで切り取って貼り付けるか、画像をドロップするか、Webカメラにかざします。Google Authenticatorのエクスポート用QRコードにも対応しています。画像はPC上で読み取られ、保存されることはありません。
パスワードジェネレーター
8〜256文字のランダムなパスワード、または3〜16語のパスフレーズを作成します。
パスワードの状態
保存したパスワードのうち、弱いもの、使い回しているもの、1年以上経過したもの、2段階認証コードがないものを確認できます。Have I Been Pwnedでの漏えいチェックは、オンにするまでオフで、開始したときだけ実行され、送信するのはハッシュの先頭5文字だけです。パスワード自体は決して送信されません。
サイトのロゴと種類のアイコン
各項目には、サイトのアイコン、よく知られたサイトの内蔵ロゴ、または種類を表すアイコンが表示されるので、ひと目で見分けられます。
検索、並べ替え、コレクション
コマンドパレット(Ctrl+K)、フィルターのチップ、お気に入り、自分で作るコレクションで項目を探せます。リストは、タイトル、更新日、作成日の順に並べ替えられ、お気に入りを先頭に表示できます。検索ボックスから、リストで矢印キー、Enter、Ctrl+Cをそのまま使えます。
ゴミ箱と元に戻す
削除した項目はゴミ箱に移動し、その確認メッセージには「元に戻す」ボタンがあります。ゴミ箱は30日後に自動で空になります。手動で空にするまですべて残す設定にもできます。
パスワード履歴
ログインのパスワードを変更すると、以前のパスワードが最大10件、暗号化された履歴に1年間保存されます。コピーも復元もできます。
確認済みサイト
ブラウザー拡張機能は、保存済みのサイトを「確認済みサイト」として表示し、1文字入れ替えたようなそっくりのアドレスでサインインや保存をする前に警告します。チェックはお使いのデバイス上で行われ、保存したサイトがアプリの外に出ることはありません。Safariはサイト名だけの封印されたリストを保持します。Androidでは、自動入力の保存確認にも同じ判定が表示され、そっくりのアドレスに保存する前に確認します。

データの取り込みと書き出し

他のパスワードマネージャーからインポート
1Password、Bitwarden、LastPass、Dashlane、Proton Pass、KeePass、KeePassXC(.kdbxファイルを含む)、Chrome、Edge、Brave、Firefox、Safariのエクスポート、またはその他のCSVファイルを取り込めます。書き込む前にすべての項目を確認でき、インポートがオンラインに接続することはありません。iPhoneでは、Apple パスワードからログイン、2段階認証コード、パスキーをそのまま取り込めます(iOS 26以降)。また、多くのパスワードマネージャーや認証アプリのファイルもインポートできます。
エクスポート
暗号化されたKeePass KDBX 4ファイル、Bitwarden互換のCSVまたはJSON、KeePass XMLにエクスポートできます。どのエクスポートでも、最初にマスターパスワードを確認します。
項目を1件だけ安全に共有
ログインやメモを.lgkshareファイルまたはQRコードで送れます。6語のコードでロックされ、そのコードは別の方法で相手に伝えます。開けるのは1回だけで、コードを3回間違えると破棄されます。パスキー、ドキュメント、ファイルを添付した項目は共有できません。

サインイン情報の入力

ChromeとEdgeの拡張機能
Webサイトでログインの入力と保存ができます。ユーザー名とパスワードを別々のページで求めるサインインにも対応しています。拡張機能は、小さなローカルヘルパーを通じて、完全に一致するサイトのログインをPC上のアプリに問い合わせます。2段階認証コード、住所、支払いカードの入力にも対応しています。
保存の確認はご自身で操作
サインインすると、拡張機能が新しいログインの保存や、変更されたパスワードの更新を提案します。ツールバーのボタンから、サイトごとにこの確認をオフにできます。
入力は必ずご自身が開始
アカウントを選ぶまで、何も入力されません。設定で「入力後にサインイン」をオンにしない限りフォームは送信されず、オンにした場合でも、ご自身が開始した入力の後だけです。
パスキー
ChromeやEdgeでWebサイトがパスキーを提示すると、LocalGateKeysは保管庫に保存し、そのパスキーでサインインできます。パスキーはすべて、Windows Helloまたはマスターパスワードを使ってデスクトップアプリで承認します。ブラウザー標準のパスキーのダイアログも、いつでもワンクリックで選べます。秘密鍵がアプリの外に出ることはありません。
Windowsアプリでの入力
Windowsプログラムのサインイン画面に、パスワード欄の横の入力ボタンまたはホットキー(Ctrl+Shift+Space)で入力できます。アプリは一度だけ紐付けし、その後でプログラム、ウィンドウ、入力欄が変わっていた場合、入力は拒否されます。
クイックアクセス
ホットキー(既定ではCtrl+Alt+K)で、どこからでも保管庫を検索してコピーできます。Ctrl+Alt+Lで保管庫をすぐにロックします。
キー入力の記録は一切なし
LocalGateKeysはキーボードフックをインストールせず、パスワードを探すために画面の内容を読み取らず、他のプログラムに何も注入しません。アプリが適切なサインイン欄を公開していない場合、入力は行われません。

ロック解除

マスターパスワード
12文字以上で、ディスクには決して書き込まれません。保管庫を開く唯一のもので、当社ではリセットできません。
Windows Hello
LocalGateKeysで設定すると、Windows Helloを通じて指紋、顔、またはPINでロック解除できます。
カメラによる確認
Windows HelloのないPC向けの、任意のWebカメラによる顔の確認です。利便性のための機能であり、認定を受けたなりすまし対策ではありません。可能であればWindows Helloをお使いください。
リカバリーフレーズ
マスターパスワードを忘れたときに保管庫を開ける、任意の24語のフレーズです。一度だけ表示され、アプリが保存することはありません。
自動ロックとクリップボードの消去
保管庫は、ご自身で選んだ時間が経つとロックされ、コピーしたパスワードはクリップボードから消去されます。消去されるのは、LocalGateKeysがコピーしたものだけです。

バックアップ

暗号化された定期バックアップ
毎日または毎週、指定した時刻に実行します。各バックアップは、添付ファイルを含む完全な暗号化ファイルで、書き込み後に検証されます。
指定したフォルダーにもう1部コピー
各バックアップを、OneDrive、Google Drive、Dropbox、Proton Driveのフォルダーなど、好きな場所にコピーできます。コピーされるのは暗号化されたバックアップファイルだけで、使用中の保管庫はコピーされません。
暗号化された転送パッケージ
選択した項目を、専用のパスワードで保護された暗号化ファイルとして、別の保管庫へ移せます。
スマートフォンのバックアップ
iPhone と Android のアプリは、選んだパスワードで暗号化した .lgkm バックアップを保存します。どの iPhone、Android スマートフォン、Mac、PC でも復元できます。同期と同じように統合され、保管庫が消去されることはありません。

緊急アクセスと強制用パスワード(Pro)

緊急アクセス
リカバリーフレーズを最大5つのシェアに分け、信頼できる人に渡します。あなたが決めた数(2〜5)が集まれば復旧できます。各人に渡すのは、署名付きファイル、QRコード、または印刷した用紙です。アカウントもサーバーもありません。クラウドフォルダーやUSBメモリーなどのフォルダーを共有します。
待機期間と拒否
アクセスが必要な人は、自分のLocalGateKeysから申請します。あなたが決めた待機期間(1〜30日)が過ぎると、アプリは最新の暗号化バックアップのコピーを開きます。それまでは、あなたのどの端末からでも「拒否」できます。すぐに許可することもできます。スマートフォンでは、手順の最後にリカバリーフレーズが表示されます。バックアップはパソコンで開いてください。
限界
アプリの外では、待機期間もあなたの拒否も強制するものはありません。十分な数のシェアを持つ人たちが協力すれば、すぐにバックアップを開けます。一緒に動かない人を選び、シェアは別々に保管してください。リカバリーフレーズを作り直すと、古いシェアは使えなくなります。
強制用パスワード
2つ目のパスワードで、サンプル項目を入れたもっともらしい保管庫が開きます。本物については何も分かりません。開いている間、本物の保管庫は設定した時間だけロックされ、同期は行われません。後ろからのぞく人や、アプリを開くよう迫る人から保管庫を隠せます。ファイルを調べる人に、この機能があること自体を隠すことはできません。Windows、Mac、iPhone、Androidで使えます。

上級者向けツール

バックアップの復元テスト
週に1回、LocalGateKeysは最新のバックアップを一時フォルダーに復元し、開けることを確認してから、そのコピーを削除します。バックアップが古いパスワードを使っている場合はお知らせします。
パスワード変更アシスタント
サイトのパスワードを変更するページを開きます。厳選したリスト、標準の /.well-known/change-password アドレス、またはサインインページを使います。第三者のサイトには入力しません。
複数の保管庫（Pro）
「仕事」と「個人」のように、保管庫を分けて使えます。無料プランでは保管庫は1つです。無料の7項目の上限は、すべての保管庫の合計で数えます。
印刷できる保管庫の健全性レポート
印刷できる1ページのレポートです。パスワードも項目名も含まれません。
有効期限付きで取り消せる共有
共有は1時間または1日で期限切れにでき、1回だけ使え、取り消せます。ベストエフォートです。
相続パックのテンプレート
遺言執行者向けのテンプレートで、緊急アクセスの隣にあります。

開発者と AI エージェント向け

AI エージェントがサインイン、パスワードは PC に残ります (Pro)
Claude Code などの MCP エージェントは、サイトへのサインインを LocalGateKeys に依頼できます。リクエストはすべてあなたが承認し、ブラウザー拡張機能がフォームに入力します。エージェントがパスワードを見ることはありません。Windows では claude mcp add localgatekeys -- LocalGateKeysNativeHost.exe mcp を使います。Store 版では lgk コマンドラインを LocalGateKeysNativeHost.exe lgk として実行します。 AI エージェントがサインイン、パスワードは PC に残ります
改ざんを検出できるアクセスログ
各アクティビティ記録はハッシュで前の記録とつながっているため、ログが変更、切り詰め、または消去されるとセキュリティチェックに表示されます。

デバイス間の同期(Pro)

家庭内のWi-Fiで
PCまたはiPhoneは、1回限り使えるQRコードで一度だけペアリングします(PC同士ではそのテキストを貼り付けます)。両方のデバイスがロック解除されて同じネットワーク上にあるとき、認証され暗号化された接続で変更を直接やり取りします。インターネットは経由しません。PCのアドレスが変わった場合は「再検索」で再接続でき、各デバイスには最後に同期した時刻が表示されます。
ご自身のクラウドフォルダー経由で
デバイス同士が同じネットワークに接続されることが少ない場合は、すでに使っているDropboxやiCloud Driveなどのクラウドフォルダーを経由し、同期パスワードで保護して同期できます。プロバイダーが保存するのは、暗号化されたファイルだけです。両方の方法を併用することもできます。
同期される内容
ログイン、メモ、カードなどの項目と、添付したドキュメントのファイルが同期されます。コレクションは各デバイスに残ります。2台で同時に編集した場合は両方のバージョンが残り、削除した項目は他のデバイスではゴミ箱に移動します。デバイスが保管庫の古いコピーを戻してきた場合、Windowsアプリはそれを受け入れず、警告を表示します。
iPhone
iPhoneアプリはWindows PCやMacと同期します。iPhoneがProの場合、無料版のPCをペアリングすると、同期によってライセンスが引き継がれ、PCもProになります。App Storeで入手。

iPhoneでは

SafariとアプリでのAutoFill
SafariやほかのアプリでQuickTypeバーの候補からログインを入力でき、パスキーにもLocalGateKeysを使えます。iOS 18以降では、あらゆるテキストフィールドでカードや住所などの情報も入力できます。Safari拡張機能は、サインイン後に新しいログインの保存を提案します。
Face ID、Touch ID、またはアプリ用パスワード
保管庫はFace ID、Touch ID、またはiPhoneのパスコードで開くので、新しいパスワードを作る必要はありません。パスコードを他の人が知っている場合は、24語のリカバリーフレーズで守られたアプリ用パスワードを追加できます。
セキュリティチェック
「セキュリティ」タブでは保管庫のスコアを確認でき、弱いパスワード、使い回し、古いパスワード、2段階認証コードを設定できるログインが一覧表示されます。漏えいチェックは、オンにするまで動作しません。
最近削除した項目、履歴、通知
削除した項目は「最近削除した項目」に30日間残り、「取り消す」ですぐに戻せます。すべてのログインにパスワード履歴が残り、カード、パスポート、免許証などの期限が近づくと通知を受け取れます。
添付ファイル(Pro)
ドキュメントや写真を保管庫に添付できます。暗号化して保存され、ほかのデバイスとも同期します。
10言語に対応
iPhoneアプリは、英語、ドイツ語、スペイン語、イタリア語、日本語、韓国語、オランダ語、ポーランド語、ブラジルポルトガル語、簡体字中国語に対応しています。

プライバシー

アカウント不要
登録やサインインは一切ありません。Proライセンスはご自身で保管するキーで、デバイス上で確認されます。iPhoneでは、ProはApp Storeでの購入で、アプリがライセンスサーバーに送るのはApp Storeのレシートだけです。
テレメトリーなし
アプリは、使用状況データ、クラッシュレポート、アクセス解析を送信しません。
厳格オフラインモード
既定でオンです。バックグラウンドでのインターネット通信と漏えいチェックをブロックし、アップデートの確認では事前にお尋ねします。
Webサイトのアイコンは選択制
サイトのアイコンを表示するため、アプリはそのサイトからアイコンをダウンロードします。これでサイトに伝わるのは、そこにアカウントがあるということだけです。既定ではオフです。設定で「Webサイトのアイコンを表示」をオンにしてください(厳格オフラインモードはオフにする必要があります)。
アップデートの確認はご自身で開始
アップデートの確認では、署名付きの小さなファイルを1つダウンロードします。アプリが自分で何かをダウンロードしたりインストールしたりすることはありません。
