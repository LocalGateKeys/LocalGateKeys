はじめに

Windowsアプリをインストールし、保管庫を作成して、ブラウザー拡張機能を追加します。所要時間は5分ほどで、アカウントは不要です。iPhoneアプリは、いつでも追加できます。

  1. 1. アプリをインストール
  2. 2. 保管庫を作成
  3. 3. ブラウザー拡張機能を追加
  4. 4. パスワードを取り込む
  5. 5. Windowsアプリに入力
  6. 6. Proをオンにする
  7. 7. iPhoneを追加

1 Windowsアプリをインストール

LocalGateKeys は Windows 10 (バージョン 2004 以降) と Windows 11 (64 ビット) で動作し、Microsoft Store から入手できます。

  • Microsoft Store。Storeがインストールし、最新の状態に保ちます。Microsoft StoreでLocalGateKeysを開き、入手、続いて開くを選びます。
  • 以前のインストーラー版を使っていましたか？ Windows の設定 › アプリ(Windows 11 ではインストールされているアプリ、Windows 10 ではアプリと機能)でアンインストールしてから、Microsoft Store からインストールしてください。保管庫はそのまま残り、Store 版アプリが同じマスターパスワードで開きます。

Microsoft Storeで入手 その他のダウンロード

2 保管庫を作成

  1. LocalGateKeysを開きます。初回起動時に保管庫の作成を求められ、その後の短いセットアップガイドで、Windows Hello、インポート、リカバリーフレーズ、ブラウザー拡張機能を設定できます。どの手順もスキップでき、あとからセットアップを完了カードで続けられます。
  2. 12文字以上のマスターパスワードを決めます。書き留めて、安全な場所に保管してください。当社がパスワードを保持することはないため、誰もリセットできません。
  3. サイドバーのセキュリティセンターを開き、リカバリーフレーズを設定します。紙などに書いて、オフラインで保管してください。マスターパスワードを忘れたときに、保管庫を開けます。
  4. 同じ場所で、PCに指紋リーダー、Helloカメラ、またはPINがある場合はWindows Helloをオンにすると、普段のロック解除が速くなります。
  5. 設定で定期バックアップをオンにし、USBドライブやすでにバックアップしているフォルダーなど、暗号化されたバックアップファイルの保存先を選びます。

3 ブラウザー拡張機能を追加

拡張機能は、ブラウザーでサインイン情報を入力します。通信相手は同じPC上のLocalGateKeysアプリだけなので、先にアプリをインストールしてください。

  1. 拡張機能を追加します:
    • Microsoft Edge: Edgeアドオンで開き、入手を選びます。
    • Google Chrome: Chromeウェブストアで開き、Chromeに追加を選びます。
    • Mozilla Firefox（Windows）: Firefox Add-ons で開き、Firefox へ追加を選びます。
  2. ピン留めします: ブラウザーの拡張機能メニュー(パズルのピースのアイコン)を開き、LocalGateKeysをツールバーにピン留めしてください。
  3. アプリを起動したまま、ロック解除しておきます。ログインを保存済みのサインインページを開くと、拡張機能は完全に一致するサイトに保存されたログインだけを提示します。クリックするまで、何も入力されません。
  4. 初めてのサイトでサインインすると、拡張機能がログインの保存を提案します。

拡張機能がアプリに接続できないと表示される場合は? アプリでデバイスと接続を開き、ブリッジを修復を選んでから、ブラウザーを再起動してください。

4 パスワードを取り込む

サイドバーのインポートとエクスポートを選び、1Password、Bitwarden、LastPass、Dashlane、Proton Pass、KeePass、KeePassXC、Chrome、Edge、Brave、Firefox、Safariのエクスポートファイル、または任意のCSVを選びます。保存する前にすべての項目を確認でき、オンラインに接続することはありません。ほとんどのエクスポートはパスワードを平文で含むため、取り込んだ後はエクスポートファイルを削除してください。

無料版で保存できるのは7件までです。Proでは上限がなくなります。

5 Windowsアプリに入力

ゲームランチャーなどのプログラムでは、アプリでデスクトップのログインを開いてアプリの紐付け…を選び、そのプログラムのサインイン画面に一度だけ紐付けします。その後は、パスワード欄の横に入力ボタンが表示されます。Ctrl+Shift+Space を押しても入力できます。紐付けた後でプログラムやウィンドウが変わっていた場合、LocalGateKeysは入力を拒否します。

6 Proをオンにする

Proは1回のお支払いで、項目の無制限化、デバイス間の同期、2段階認証コード、ドキュメントが加わります。購入後は、ライセンスページのLocalGateKeysにインストールを選ぶか、設定 › プランと同期 › ライセンスにライセンスキーを貼り付けてください。Proライセンスもご覧ください。

7 iPhoneを追加

iPhoneアプリは、専用の暗号化された保管庫を持ち、PCと同期します。同期はProに含まれます。

  1. App StoreからLocalGateKeysをインストールして開きます。
  2. ロック解除をタップします。保管庫はFace ID、Touch ID、またはiPhoneのパスコードで開くので、パスワードを作る必要はありません。続く短いセットアップで、インポート、任意のアプリ用パスワード、AutoFillを設定できます。
  3. AutoFillをオンにします。LocalGateKeysで「設定 › AutoFill › AutoFill設定を開く」を選び、一般 › AutoFillとパスワードでLocalGateKeysをオンにします。
  4. PCとペアリングします。PCで「同期とデバイス」を開き、Wi-Fi同期をオンにしてQRコードを表示を選びます。iPhoneでは同期タブを開き、QRコードをスキャンをタップします。両方の画面に同じコードが表示されていることを確認し、PCで承認を選びます。
  5. Apple Watch(Pro):iPhoneのWatchアプリからLocalGateKeysをインストールし、2段階認証コードのあるログインを開いてApple Watchに表示をタップします。

iPhoneでProを購入しましたか。ペアリングすると、無料版のPCは同期によってライセンスを引き継ぎ、Proになります。iPhoneの各画面のヘルプはユーザーガイドにあります。

Mac：Mac App Store からアプリを入手できます。Android：アプリは準備中で、まだ利用できません。
