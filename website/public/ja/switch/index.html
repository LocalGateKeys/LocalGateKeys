LocalGateKeysへの乗り換え

今お使いのパスワードマネージャーを選んでください。各ガイドで、エクスポート方法、LocalGateKeysへのインポート方法、移行されないものを説明します。

  • 1Password
  • Bitwarden
  • LastPass
  • Dashlane
  • Enpass
  • KeePass
  • Proton Pass
  • NordPass
  • Apple Passwords
  • Google Password Manager
  • Microsoft Authenticator

パスキーはCSVエクスポートでは移行されません。LocalGateKeysは、CXFファイル（Appleのパスワードアプリや、CXFをエクスポートできる他のアプリ）からパスキーをインポートできます。対応はPC、Android、iPhone、Macです。
