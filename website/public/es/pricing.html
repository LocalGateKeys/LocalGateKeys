Cómo funciona el límite de 4 elementos

Cuentan todos los tipos de elemento: inicios de sesión, claves de acceso, notas, tarjetas, identidades, documentos y los demás. Los elementos de la papelera no cuentan.

Nunca se quita nada. Si tienes más de 4 elementos sin Pro, por ejemplo tras actualizar desde una versión anterior o tras eliminar una licencia, todos los elementos siguen siendo utilizables, editables y rellenables. Solo se espera para añadir uno nuevo hasta que compres Pro o vuelvas a tener menos de 4. Las importaciones traen tantos elementos como lugares libres tengas, y te dicen cuántos antes de empezar.

Sincronización, códigos de dos factores y documentos

Forman parte de Pro. Sin Pro, los códigos de dos factores y los documentos que ya guardaste siguen funcionando: puedes verlos, copiarlos, rellenarlos, exportarlos y eliminarlos. Solo añadirlos o cambiarlos, y sincronizar, necesitan Pro. Las claves de dos factores de una importación se conservan como campos ocultos, así que no se pierde nada.

Paga una vez, conserva cada actualización

Pro no es una suscripción. Pagas US$4.99 una vez, y cada versión futura de LocalGateKeys conserva Pro. No hay nada que renovar, ni cuenta ni servidor de activación.
