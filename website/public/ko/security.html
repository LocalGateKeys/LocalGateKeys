보안 모델, 쉬운 말로

LocalGateKeys가 보호하도록 설계된 것과 보호할 수 없는 것.

보관함이 암호화되는 방식

무작위 256비트 키가 보관함을 암호화합니다. 이 키는 그대로 저장되지 않고, 잠금을 해제할 수 있는 각 방법마다 따로 래핑(암호화)됩니다. 그래서 비밀번호를 바꿔도 모든 것을 다시 암호화할 필요가 없으며, 다른 보관함에서 복사한 래퍼는 거부됩니다.

보관함 암호화
저장할 때마다 새로운 무작위 nonce를 사용하는 AES-256-GCM
마스터 비밀번호
Argon2id, 3회 반복, 병렬도 4, 래퍼마다 무작위 솔트. 메모리는 Windows 앱에서 256 MiB(메모리가 4 GB 미만인 PC에서는 64 MiB), Mac, iPhone, Android 앱에서 64 MiB
복구 문구
선택 사항인 24단어 BIP39 문구(256비트), HKDF-SHA256으로 확장
Windows Hello, Touch ID, Face ID, 지문
기기가 보호하는 저장소에서 보관함 키를 꺼냅니다. 마스터 비밀번호는 저장하지 않습니다
백업 및 전송
인증된 헤더에 매개변수가 저장되는 Argon2id와 AES-256-GCM
기기 동기화
X25519와 HKDF-SHA256으로 각 기기에 전달되는 무작위 그룹 키이며, 클라우드 폴더의 경우 동기화 비밀번호로도 Argon2id를 통해 래핑됩니다. 모든 레코드는 AES-256-GCM으로 봉인되고 항목, 버전, 키 에포크에 묶이며, 모든 기기 파일은 그것을 쓴 기기에 묶입니다
패스키
암호화된 보관함 안에 보관하는 ES256(P-256) 키. 앱은 서명할 데이터를 페이지가 아니라 브라우저가 알려 주는 출처로 만듭니다. Microsoft Store 앱은 Windows 11의 패스키 공급자가 될 수도 있습니다(기본값은 꺼짐). 이 경우 Windows는 패스키 사이트와 계정 이름을 자체 목록에 보관하지만 키는 보관하지 않습니다
디스크에 쓰기
임시 파일에 쓰고, 플러시한 다음, 원자적으로 교체하므로 충돌이 나도 반쪽짜리 보관함이 남지 않습니다
AI 에이전트
기본값은 꺼짐(Pro). 에이전트는 내 기기의 lgk mcp를 통해서만 앱에 접근하며, 허용한 로그인과 항목만 볼 수 있습니다. 요청은 하나하나 직접 승인하고, 로그인 입력은 앱이 직접 하며, 에이전트에 보내는 응답에는 비밀번호가 담기지 않습니다. 모든 요청은 SHA-256 해시로 항목이 이어진 접근 기록에 남고, 보안 점검에서 이 연결이 온전한지 알려 줍니다

다음으로부터 보호하도록 설계됨

  • 마스터 비밀번호를 모른 채 보관함 파일이나 백업을 복사한 사람
  • 다른 웹사이트에 저장된 로그인이나 패스키를 얻어 가는 웹사이트
  • 자체 브라우저 도우미에게 전달하는 세션 비밀 없이 LocalGateKeys와 통신하는 PC의 다른 프로그램
  • 바인딩한 이후 교체, 업데이트 또는 변경된 데스크톱 앱 채우기
  • 암호화되지 않은 채 디스크에 놓여 있는 비밀번호
  • 내가 모르는 사이에 제출되는 양식
  • 클라우드 제공업체가 동기화된 데이터를 읽는 것: 암호문만 저장합니다
  • LocalGateKeys가 제안하는 계정을 웹 페이지가 읽는 것. Chrome, Edge, Firefox에서는 페이지가 읽을 수 없는 별도의 확장 프로그램 프레임에 목록을 그립니다
  • AI 에이전트가 LocalGateKeys에서 비밀번호를 얻는 것. 에이전트에 보내는 응답에는 비밀번호가 없으며, 에이전트는 허용한 로그인만 볼 수 있습니다

보호할 수 없는 것

  • 이미 PC에서 실행 중인 악성 코드 또는 관리자 권한을 가진 사람
  • 침해된 브라우저, Windows 설치 또는 종속 구성 요소
  • 비밀번호를 일부러 채워 넣은 웹사이트
  • 보관함이 잠금 해제된 동안 PC를 사용하는 사람
  • 공격자가 제어하는 콘텐츠를 보여 주는 정상 앱 내부의 피싱
  • 복구 문구 없이 보관함, 백업, 마스터 비밀번호를 모두 잃은 경우: 저희를 포함해 누구도 열 수 없습니다
  • 브라우저를 조종하는 AI 에이전트가 LocalGateKeys가 페이지에 입력한 비밀번호를 읽는 것, 또는 승인한 명령이 받은 비밀을 다른 곳으로 넘기는 것

LocalGateKeys가 절대 하지 않는 일

비밀번호를 채우는 일부 방식은 스파이웨어와 구별할 수 없으므로 설계상 배제했습니다. LocalGateKeys에는 다음이 없습니다:

  • 키보드 후크 또는 키 입력 기록
  • 클립보드 모니터링
  • 자격 증명을 찾기 위한 화면 읽기 또는 OCR
  • 다른 프로그램의 메모리 검색
  • 브라우저에 저장된 비밀번호 데이터베이스의 복호화
  • 다른 프로그램이나 게임에 대한 코드 주입
  • 내가 시작하지 않은 로그인의 제출

네트워크에 대해 솔직하게

LocalGateKeys 계정도, 보관함을 보관하는 서버도 없습니다. 앱이 인터넷에 연결되는 경우는 다음뿐입니다:

  • 업데이트. Windows 앱은 Microsoft Store가, Mac과 iPhone 앱은 App Store가 업데이트합니다. LocalGateKeys가 직접 설치 관리자를 다운로드하거나 실행하는 일은 없습니다. 지원이 끝난 Windows 설치 관리자 버전(마지막 버전인 0.4.12까지)은 업데이트 확인을 선택하면 저희 서버에서 작은 파일 하나를 다운로드하고 앱에 내장된 키로 서명을 검증합니다.
  • 라이선스 해지 목록. 설치 관리자 버전에서 업데이트를 확인할 때마다, 그리고 Microsoft Store 앱에서 엄격한 오프라인 모드가 꺼진 상태로 업데이트 확인을 선택하면, 앱이 환불된 라이선스의 서명된 목록을 다운로드해 PC에서 라이선스를 대조합니다. 라이선스에 관한 정보는 아무것도 보내지 않습니다.
  • 웹사이트 아이콘. 사이트의 아이콘을 표시하기 위해 앱은 해당 사이트 자체 주소에서 아이콘을 다운로드합니다. 사용자 이름, 비밀번호, 보관함 데이터는 전송되지 않지만, 각 다운로드는 그 사이트와 네트워크를 지켜보는 누구에게나 내 보관함에 그곳 계정이 있다는 사실을 알려 줍니다. 기본적으로 꺼져 있으며 설정에서 "웹사이트 아이콘 표시"를 켠 경우에만 발생하고, 엄격한 오프라인 모드에서는 차단됩니다.
  • 유출 확인(켠 경우). 확인을 시작하면 앱은 각 비밀번호의 SHA-1 해시 첫 다섯 글자를 Have I Been Pwned에 전송합니다. 이 서비스는 IP 주소를 볼 수 있지만 비밀번호, 전체 해시, 사용자 이름, 웹사이트는 절대 볼 수 없습니다.
  • 동기화(설정한 경우). 집 네트워크에서는 기기끼리 직접 통신합니다. 클라우드 폴더를 통할 때는 클라우드 드라이브 앱이 업로드를 처리합니다.
  • Mac, iPhone, Android 앱에서 Pro 구매. 앱은 스토어의 서명된 구매 기록을 저희 라이선스 서버로 보내고, 서버는 라이선스 키로 응답합니다. 이메일 주소나 기기 데이터는 보내지 않습니다.
  • 확인된 사이트. 비슷한 주소 검사는 기기에서 실행됩니다. 저장된 사이트는 앱 밖으로 나가지 않으며 서버로 전송되는 것은 없습니다.

Windows 앱에서는 보안 센터 › 네트워크 활동에 이 연결들이 시간, 호스트, 결과와 함께 표시됩니다. 저장한 웹사이트 이름은 앱이 실행되는 동안에만 표시되고 디스크에 기록되지 않으며, 내 네트워크의 기기는 '로컬 네트워크'로 표시됩니다.

엄격한 오프라인 모드는 기본적으로 켜져 있습니다. 백그라운드 인터넷 요청, 웹사이트 아이콘, 유출 확인을 차단하며, 업데이트 확인은 먼저 사용자에게 묻습니다. 업데이트를 확인할 때 저희 서버가 무엇을 보는지는 개인정보 처리방침에 정확히 나와 있습니다.

알려진 한계

  • 마스터 비밀번호는 앱에 도달하는 즉시 지울 수 있는 버퍼로 옮겨지며, 필요로 했던 작업이 끝나면 지워집니다. 비밀번호를 입력하는 페이지는 Microsoft Edge WebView2에서 실행됩니다. 페이지는 입력란을 비우고 앱은 넘기는 과정에서 만들어진 사본을 놓아 주지만, 이는 키가 계산되기 전에 이루어집니다. 그래도 이 두 사본은 메모리에서 덮어쓸 수 없으므로 짧은 시간 동안 흔적이 남을 수 있습니다.
  • 카메라 잠금 해제는 무작위로 고개를 움직이도록 요구하므로, 카메라 앞에 평평하게 든 사진이나 화면 속 정지 이미지로는 통과할 수 없습니다. 하지만 이는 편의를 위한 확인일 뿐 인증된 보호 수단이 아닙니다. 구부리거나 접은 사진, 안내를 따라 움직이는 동영상, 마스크는 통과할 수 있습니다. 더 강력한 선택은 Windows Hello입니다.
  • Windows 앱 채우기는 관리자 권한으로 실행되는 프로그램, 직접 그려 낸 게임 인터페이스, 검증할 수 없는 내장 웹 뷰에서는 작동하지 않습니다.
  • 보관함은 이전 사본으로 되돌려지는 것을 감지합니다. 동기화를 사용하면 다른 기기가 보관함이 얼마나 최신이었는지 기억하므로, 한 기기에 이전 사본을 되돌려 놓으면 다음 동기화 때 모든 앱에서 알려 줍니다. 동기화를 사용하지 않으면 Windows PC는 보관함 폴더 밖에 두 번째 기록을 보관하므로, 앵커 파일과 함께 다시 넣은 이전 보관함은 거부됩니다. Windows 계정 설정을 바꿀 수 있는 사람은 이 기록도 지울 수 있습니다. iPhone, Mac, Android 앱은 다른 앱이 자기 파일에 접근하지 못하게 하지만, 동기화를 사용하지 않으면 이전 사본으로 바꿔 놓아도 알아차리지 못합니다.
  • 패스키는 Chrome, Edge, Firefox에서 작동합니다. 다른 사이트의 프레임 안에서 패스키로 로그인하는 것은 바깥 사이트가 허용할 때 Chrome과 Edge에서 작동합니다. Firefox에서, 그리고 다른 사이트의 프레임 안에서 패스키를 만들 때는 브라우저 자체의 패스키 대화 상자를 사용합니다. 새 패스키를 승인한 후 사이트가 취소하면 앱이 그 패스키를 다시 삭제합니다. 사이트가 패스키를 유지했는지 앱이 알 수 없는 경우에는 패스키가 보관함에 남으며, 앱에서 삭제할 수 있습니다.
  • 비슷한 주소 경고는 참고용이며 방벽이 아닙니다. 페이지 자체의 스크립트는 예를 들어 양식 제출 없이 비밀번호를 보내는 방식으로 이를 우회할 수 있습니다. 주소는 직접 확인하세요.
  • 비상 액세스에는 서버가 없으므로 대기 기간과 내 거부는 앱만 지킵니다. 충분한 조각을 가진 사람은 기다리지 않고 바로 백업을 복구할 수 있습니다. 함께 행동하지 않을 사람을 고르고 조각은 따로 보관하세요.
  • 강요 대응 비밀번호는 앱 잠금 해제를 강요받는 상황에 대비한 것입니다. 디스크의 파일을 조사하는 사람에게는 소용없으며, 꼼꼼한 사람은 두 번째 보관함이 있다는 것을 알아낼 수 있습니다. Windows, Mac, iPhone, Android에서 쓸 수 있습니다.

보안 감사를 위한 소스 코드

LocalGateKeys는 소스 공개(source-available) 소프트웨어입니다. 누구나 보관함을 어떻게 보호하는지 확인할 수 있도록 전체 소스 코드를 GitHub에 공개합니다. 라이선스(보안 연구 허가가 포함된 PolyForm Strict)에 따라 취약점을 찾아 신고할 목적으로 코드를 비공개로 읽고, 빌드하고, 테스트할 수 있습니다. 오픈 소스가 아니므로 복사, 재배포, 판매는 허용되지 않습니다.
