Mac용 LocalGateKeys

이 기기의 모든 화면과 기능을 단계별로 안내합니다. 모든 제목은 공유할 수 있는 링크입니다.

  • Windows
  • Mac
  • iPhone 및 iPad
  • Android
  • 브라우저 확장 프로그램

모든 기기에서 알아 두면 좋은 점

  • 보관함은 사용자의 기기에만 있습니다. 계정이 없으며 비밀번호를 보관하는 LocalGateKeys 서버도 없습니다.
  • 마스터 비밀번호나 앱 비밀번호는 누구도 재설정할 수 없습니다. 복구 문구를 설정하고 종이에 적어 보관하십시오.
  • Free는 항목을 최대 7개까지 보관합니다. Pro(US$29.99, 한 번 결제)는 무제한 항목, 2단계 인증 코드, 파일, 동기화를 제공합니다. 이미 있는 항목의 편집, 삭제, 입력은 절대 차단되지 않습니다.

Mac 주제

사이드바에는 항목(모든 항목, 즐겨찾기, 최근 사용, 각 종류, 컬렉션)과 도구 보안 센터, 생성기, 동기화 및 기기, 가져오기 및 내보내기, 휴지통이 있고, 맨 아래에 설정이 있습니다. 복구 센터는 설정 › 백업에서, 기기 및 연결은 동기화 및 기기에서 엽니다.

보관함 만들기

  1. LocalGateKeys를 열고 마스터 비밀번호를 두 번 입력한 다음 보관함 만들기를 선택합니다.
  2. 설정이 이어집니다: Touch ID 설정, 비밀번호 가져오기…, 복구 문구 열기, Safari와 자동 완성을 위한 기기 및 연결 열기.

잠금 해제와 잠금

  • Touch ID: 설정 › 보안 › 잠금 해제 › Touch ID. 지문을 변경하면 마스터 비밀번호를 한 번 사용하십시오.
  • 마스터 비밀번호 변경: 설정 › 잠금 해제. 항목은 그대로 유지됩니다.
  • 복구 문구: 복구 센터에서 설정하고 세 단어를 확인합니다. 마스터 비밀번호를 잊으면 잠금 화면에서 마스터 비밀번호를 잊으셨습니까? › 복구 문구로 복구를 선택합니다.
  • 잠금: ⌘L. 설정 › 잠금에서 유휴 시 잠금, 화면과 함께 잠금, 잠자기 시 잠금, 최대 세션 시간을 설정합니다. 유휴 시 잠금에서 무엇을 활동으로 볼지도 선택할 수 있습니다.

항목

  • 새 항목(⌘N)은 iPhone과 같은 유형에 파일 첨부…(Pro)가 추가됩니다.
  • ⌘C(비밀번호), ⇧⌘C(사용자 이름), ⌘T(2FA 코드)로 복사합니다.
  • 사용자 지정 필드용 필드 추가, 태그, 컬렉션(다른 기기와 동기화됨).
  • ⌫는 항목을 최근 삭제된 항목으로 옮깁니다. 사이드바에서 휴지통을 열고 선택 항목 복원 또는 휴지통 비우기를 사용합니다.
  • 첨부 파일은 Touch ID나 마스터 비밀번호 확인 후 훑어보기로 열립니다.
  • 생성기: 무작위 비밀번호(문자 집합 선택, 비슷한 문자 피하기) 또는 암호 문구(대문자 사용, 숫자 추가, 구분자).

2단계 인증 코드 Pro

QR 코드 스캔…을 선택한 다음 이미지 선택…, ⌘V로 스크린샷 붙여넣기(⌃⇧⌘4로 복사) 또는 이미지를 끌어다 놓습니다. 코드는 자동 완성을 통해 Safari에 입력됩니다.

보안 센터

약하거나 재사용되거나 오래된 비밀번호를 표시합니다. 설정 › 개인 정보 › 유출 확인을 켜면(엄격한 오프라인 모드가 꺼져 있을 때) 모든 비밀번호 확인으로 유출 여부를 확인합니다.

자동 완성, 패스키, Safari

  1. 기기 및 연결을 엽니다.
  2. 자동 완성 설정 열기를 선택하고 시스템 설정 › 자동 완성 및 암호에서 LocalGateKeys를 켭니다.
  3. Safari 설정 열기를 선택하고 Safari › 설정 › 확장 프로그램에서 LocalGateKeys 확장 프로그램을 켭니다.

Safari에서 로그인 정보를 입력하려면 사용자 이름 또는 암호 칸을 클릭합니다. Safari가 그 아래에 LocalGateKeys 로그인을 표시합니다. 하나를 선택하고 Touch ID 또는 마스터 비밀번호로 확인하십시오. 패스키와 2FA 코드도 같은 방식으로 제안되며, 자동 완성은 다른 Mac 앱에서도 작동합니다.

Safari 확장 프로그램은 로그인한 후 새 로그인 저장을 제안합니다. 저장된 내용은 다음에 LocalGateKeys 잠금을 해제할 때 검토합니다. 다른 브라우저는 아직 Mac에서 지원되지 않습니다.

로그인이 표시되지 않나요? 기기 및 연결을 열고 자동 완성이 켜져 있는지 확인하십시오. 같은 시스템 설정 페이지에서 암호를 끄면 LocalGateKeys만 로그인을 제안합니다.

기기 및 연결을 열 때 LocalGateKeys가 종료되면 Mac App Store에서 업데이트하십시오.

가져오기와 내보내기

  • Apple 암호(macOS 26): 로그인, 2FA, 패스키를 가져오기 전에 검토합니다.
  • 파일: Bitwarden .json(비밀번호로 보호된 파일 포함), 1Password .1pux, KeePass .kdbx, 열 선택이 있는 CSV.
  • iPhone 및 Android .lgkm 백업: 새 항목 모두 추가, 중복은 둘 다 유지, 모두 건너뛰기 중에서 선택합니다. 아무것도 지워지지 않습니다.
  • 암호화된 백업 또는 CSV(암호화되지 않음, 먼저 확인)를 내보냅니다.

백업

복구 센터에서:

  • 전체 백업: .lgk 파일을 만들기… 또는 복원…(보관함을 대체). Mac과 Windows 간에 작동합니다. 안전 사본이 보관되므로 되돌리기…로 복원을 취소할 수 있습니다.
  • 예약 백업: 빈도, 요일, 시간, 보관할 개수, 폴더 및 미러 폴더, 백업 비밀번호(12자 이상).
  • 복구 키트…: 마지막 백업을 설명하는 파일로, 백업과 함께 보관합니다. 비상 키트 인쇄…는 보관함과 백업의 위치 및 복원 방법을 적은 페이지를 인쇄합니다.

동기화 Pro

  • Wi-Fi(이 네트워크): Wi-Fi 동기화 켜기를 선택한 다음 QR 코드 표시…를 선택합니다. 기기가 참여하면 코드를 확인하고 수락 또는 거절을 선택합니다. 나중에 알아볼 수 없는 기기라면 실행 취소를 선택합니다.
  • 코드로 참여: 다른 기기에서 QR 코드 표시, 코드 텍스트 복사를 차례로 선택하고 그 텍스트를 여기에 붙여 넣습니다.
  • 클라우드 폴더: Dropbox나 iCloud Drive 같은 폴더에서 동기화 비밀번호로 그룹에 참여하거나 그룹을 만듭니다. OneDrive와 Google Drive는 Apple 관련 문제가 해결될 때까지 현재 사용할 수 없습니다.
  • 동기화 나가기… / 이 Mac에서 동기화 재설정….

공유

항목을 선택하고 공유…를 선택합니다. 받으려면 편집 › 공유 항목 받기…를 선택하고(또는 ⌘K로 찾기), 파일을 열거나 끌어다 놓은 다음(또는 QR 텍스트를 붙여 넣은 다음) 여섯 단어를 입력합니다. 패스키와 파일이 첨부된 항목은 공유할 수 없습니다.

Pro

설정 › 요금제에서 Pro를 구매합니다. 한 번 구매로 iPhone 앱과 Mac 앱 모두에 적용되며, 다른 기기에서는 구매 항목 복원을 사용합니다. Pro iPhone과 동기화된 무료 Mac에는 동기화된 기기의 Pro가 표시됩니다.

설정

설정은 기본 창과 ⌘,에서 똑같고, 도구는 사이드바 아래쪽에 항상 표시됩니다. 설정 › 백업에는 백업 일정, 주간 복원 테스트, 보관할 자동 백업 수가 있으며, 복구 센터·라이선스·설정 다시 보기는 두 창 어디서나 열립니다. 그 밖의 설정: 자동 잠금에서 활동으로 칠 대상, 2단계 인증 코드 복사 전 확인, 보관함에 저장된 문서를 다른 앱에서 열기, 나만의 빠른 액세스 단축키, 도움말 링크.

강요 대비 비밀번호(Pro, 설정 › 강요 대비 비밀번호): 누군가 잠금 해제를 강요할 때 쓰는 두 번째 마스터 비밀번호입니다. 고른 항목만 있는 별도의 보관함이 열리고, 내 보관함은 설정한 시간 동안 마스터 비밀번호를 거부합니다.
