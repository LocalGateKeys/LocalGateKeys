Edge, Chrome 및 Firefox용 브라우저 확장 프로그램

이 기기의 모든 화면과 기능을 단계별로 안내합니다. 모든 제목은 공유할 수 있는 링크입니다.

  • Windows
  • Mac
  • iPhone 및 iPad
  • Android
  • 브라우저 확장 프로그램

모든 기기에서 알아 두면 좋은 점

  • 보관함은 사용자의 기기에만 있습니다. 계정이 없으며 비밀번호를 보관하는 LocalGateKeys 서버도 없습니다.
  • 마스터 비밀번호나 앱 비밀번호는 누구도 재설정할 수 없습니다. 복구 문구를 설정하고 종이에 적어 보관하십시오.
  • Free는 항목을 최대 7개까지 보관합니다. Pro(US$29.99, 한 번 결제)는 무제한 항목, 2단계 인증 코드, 파일, 동기화를 제공합니다. 이미 있는 항목의 편집, 삭제, 입력은 절대 차단되지 않습니다.

확장 프로그램 주제

웹사이트에서 로그인 정보를 입력하고 저장합니다. 같은 PC의 LocalGateKeys 앱과만 통신하므로 Windows 앱을 먼저 설치하십시오. Safari를 사용하시나요? 여기서 다운로드할 것은 없습니다. Mac 및 iPhone 앱이 자동 완성으로 Safari에서 입력하며 Safari 확장 프로그램도 포함되어 있습니다. Mac의 자동 완성 및 Safari 또는 iPhone의 경우를 참조하십시오.

이 탭의 내용
  1. 설치 및 연결
  2. 확장 프로그램 창
  3. 로그인 입력
  4. 로그인 저장
  5. 2FA 코드 입력
  6. 카드와 신원 정보
  7. 새 비밀번호
  8. 패스키
  9. 문제 해결

설치 및 연결

  1. Windows 앱을 설치하고 설정합니다.
  2. 확장 프로그램을 추가합니다. Edge는 Edge 추가 기능에서 추가합니다(다운로드 선택). Chrome은 Chrome 웹 스토어에서 추가합니다(Chrome에 추가 선택). Firefox는 Firefox 부가 기능에서 추가합니다(Firefox에 추가 선택).
  3. 도구 모음의 퍼즐 조각 아이콘을 클릭하고 LocalGateKeys를 고정합니다.
  4. LocalGateKeys 아이콘을 클릭합니다. 연결 카드에 연결됨 또는 잠김이 표시되어야 합니다.

페어링할 필요가 없습니다. 확장 프로그램이 앱을 자동으로 찾습니다. 앱의 설정 가이드에 이를 확인하는 연결 테스트 단계가 있습니다.

확장 프로그램 창

연결
연결됨(준비 완료), 잠김(작업을 선택하면 앱이 잠금 해제를 요청), 설정 필요 또는 오프라인. ↻는 아무것도 잠금 해제하지 않고 상태를 새로 고칩니다.
현재 사이트
현재 열려 있는 사이트입니다. 정확히 이 사이트에 저장된 로그인만 제안됩니다.
빠른 작업
로그인 입력, 신원 정보 입력, 카드 입력…, 로그인 저장, 비밀번호 생성.
저장 확인
이 사이트에서 저장 확인을 끄거나 켜는 스위치입니다.

설계상 아무것도 저절로 입력되지 않습니다. 모든 입력은 사용자의 클릭으로 시작되며, 확장 프로그램은 마스터 비밀번호를 절대 묻지 않습니다. 잠금 해제는 항상 LocalGateKeys 창에서 이루어집니다.

로그인 입력

  1. 사이트의 로그인 페이지를 엽니다.
  2. 사용자 이름 또는 비밀번호 상자 안의 LocalGateKeys 아이콘(LocalGateKeys로 입력)을 클릭하거나, 확장 프로그램을 열고 로그인 입력을 선택합니다.
  3. 사이트에 계정이 여러 개 있으면 계정 선택에서 하나를 고릅니다.
  4. 보관함이 잠겨 있으면 LocalGateKeys 창이 나타날 때 잠금을 해제합니다.

로그인에 입력 후 로그인이 켜져 있으면 양식이 자동으로 제출됩니다. 특이한 양식에서는 자동 로그인을 건너뛰었습니다가 표시되므로 사이트의 로그인 버튼을 클릭하면 됩니다.

새 로그인 또는 변경된 로그인 저장

  1. 평소처럼 웹사이트에 로그인합니다.
  2. 확장 프로그램이 이 로그인을 저장하시겠습니까?라고 묻습니다(또는 변경된 비밀번호 업데이트를 제안합니다).
  3. 보관함에 저장을 선택하고 LocalGateKeys 창에서 확인합니다. 또는 나중에나 이 사이트에서 사용 안 함을 선택합니다.

직접 저장하려면 양식을 작성하고 확장 프로그램 창에서 로그인 저장을 선택합니다. 사이트의 확인을 다시 켜려면 확장 프로그램 창의 스위치를 사용합니다.

2FA 코드 입력

사이트에서 6자리 코드를 요구하면 코드 상자의 LocalGateKeys 아이콘(LocalGateKeys로 2FA 코드 입력)을 클릭합니다. 페이지에는 현재 코드만 전달되며 설정 키는 절대 전달되지 않습니다. 코드가 곧 만료되면 확장 프로그램이 새 코드를 잠시 기다립니다.

로그인에 2FA 설정 키가 앱에 저장되어 있어야 합니다(2단계 인증 코드 참조). 설정 › 잠금 › 2FA 코드를 전달하기 전에 확인이 켜져 있으면 매번 앱에서 확인합니다.

카드와 신원 정보

  1. 결제 또는 주소 양식에서 필드의 아이콘을 클릭하거나 카드 입력… / 신원 정보 입력을 선택합니다.
  2. 카드나 신원 정보를 선택합니다.
  3. 입력할 필드를 선택합니다. 보안 코드(CVV)는 기본적으로 선택되어 있지 않으므로 필요할 때만 선택하십시오.
  4. 검토 후 승인을 선택한 다음 LocalGateKeys 창에서 승인합니다.

가입 페이지에서 비밀번호 만들기

가입 또는 비밀번호 변경 양식에서 비밀번호 생성을 선택합니다. 새 비밀번호가 새 비밀번호 입력란에 들어갑니다. 페이지를 떠나기 전에 저장 확인이나 로그인 저장으로 저장하십시오.

패스키

사이트에서 패스키 생성이나 사용을 제안하면 LocalGateKeys가 처리하여 패스키를 보관함에 보관할 수 있습니다. 앱의 설정 › 자동 입력 › 패스키에 LocalGateKeys 제안에서 켜거나 끕니다. 처리할 수 없는 경우에는 브라우저 자체의 패스키 창이 대신 나타납니다.

문제 해결

표시 내용해결 방법
오프라인 / 앱에 연결할 수 없음LocalGateKeys를 엽니다. 기기 및 연결에서 브리지 복구를 선택한 다음 브라우저를 다시 시작합니다.
설정 필요앱에서 프로필 선택을 마친 다음 ↻를 누릅니다.
브라우저 연동이 일시 중지됨앱의 설정 › 자동 입력에서 브라우저 자동 입력을 다시 켭니다.
버전 불일치확장 프로그램과 앱을 모두 업데이트한 다음 둘 다 다시 시작합니다.
브리지 응답 시간이 너무 오래 걸림열려 있는 LocalGateKeys 확인 창을 닫고 다시 시도합니다.
이 사이트에 저장된 로그인 없음로그인의 웹사이트가 이 사이트와 일치해야 합니다. 앱에서 편집하십시오.
이 로그인은 입력이 비활성화됨앱에서 로그인 편집 › 자동 입력 규칙 › 입력.
이 페이지에서는 사용할 수 없음확장 프로그램은 브라우저 페이지(설정, 새 탭)에서 작동하지 않습니다. 일반 http/https 페이지를 여십시오.

그래도 해결되지 않으면 기기 및 연결 › 보고서 내보내기를 선택하여 support@localgatekeys.app로 이메일을 보내 주십시오. 비밀번호는 포함되지 않습니다.
