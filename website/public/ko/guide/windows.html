Windows용 LocalGateKeys

이 기기의 모든 화면과 기능을 단계별로 안내합니다. 모든 제목은 공유할 수 있는 링크입니다.

  • Windows
  • Mac
  • iPhone 및 iPad
  • Android
  • 브라우저 확장 프로그램

모든 기기에서 알아 두면 좋은 점

  • 보관함은 사용자의 기기에만 있습니다. 계정이 없으며 비밀번호를 보관하는 LocalGateKeys 서버도 없습니다.
  • 마스터 비밀번호나 앱 비밀번호는 누구도 재설정할 수 없습니다. 복구 문구를 설정하고 종이에 적어 보관하십시오.
  • Free는 항목을 최대 7개까지 보관합니다. Pro(US$29.99, 한 번 결제)는 무제한 항목, 2단계 인증 코드, 파일, 동기화를 제공합니다. 이미 있는 항목의 편집, 삭제, 입력은 절대 차단되지 않습니다.

Windows 주제

Windows 10(버전 2004 이상) 및 Windows 11, 64비트. Microsoft Store 또는 다운로드 페이지에서 설치합니다.

처음 시작과 프로필

  1. LocalGateKeys를 엽니다. 12자 이상의 마스터 비밀번호를 입력하고 비밀번호 확인에 다시 입력한 다음 보관함 만들기를 선택합니다.
  2. 이어서 LocalGateKeys 설정 가이드가 다섯 단계로 진행됩니다. 보관함 만들기, Windows Hello 설정, 비밀번호 가져오기, 복구 문구 열기(저장했음을 확인하기 위해 단어 세 개를 다시 입력), 브라우저 확장 프로그램의 연결 테스트입니다.
  3. 모든 단계는 건너뛰기할 수 있습니다. 건너뛴 단계는 보관함의 설정 마무리 카드에 남아 있으며 설정 계속과 숨기기가 있습니다.

팁. 가이드를 다시 보려면 설정 › 도움말 및 진단 › 설정 다시 보기를 선택합니다.

프로필

각 프로필은 자체 마스터 비밀번호가 있는 별도의 보관함입니다. 예를 들어 업무용과 가정용으로 나눌 수 있습니다.

  • 잠금 해제 화면에서 다른 프로필 사용을 선택한 다음 프로필 만들기를 선택하고 프로필 이름을 입력합니다.
  • 프로필을 편집하려면 Ctrl+K를 누르고 프로필 전환을 실행합니다. 여기에서 프로필 추가, 편집, 사진… 및 강조 색상 설정, 제거를 할 수 있습니다.
  • 트레이 메뉴의 잠그고 사용자 전환은 잠근 후 바로 프로필 선택으로 이동합니다.

잠금 해제와 잠금

잠금 해제 방법

  • 마스터 비밀번호를 입력한 다음 잠금 해제. 항상 작동합니다.
  • Windows Hello로 잠금 해제: 지문, 얼굴 또는 PIN. 설정 › 잠금 해제 › Windows Hello › 설정에서 설정합니다. Windows Hello 자동 시작(기본적으로 켜짐)은 창이 열리자마자 확인 창을 표시합니다.
  • 대신 카메라 사용: 일반 웹캠을 이용한 얼굴 대조로, PC에서 처리됩니다. Windows Hello보다 덜 안전합니다. 카메라 확인 설정으로 설정합니다.

마스터 비밀번호를 잊으셨습니까?

  1. 잠금 해제 화면에서 잊으셨습니까? 복구 문구 사용을 선택합니다.
  2. 24개 단어를 공백으로 구분하여 입력합니다.
  3. 새 마스터 비밀번호(12자 이상)를 정하고 두 번 입력한 다음 보관함 복구를 선택합니다.

그 후 Windows Hello와 카메라 확인을 다시 설정합니다. 복구 문구는 계속 사용할 수 있습니다.

마스터 비밀번호 변경

설정 › 잠금 해제 › 마스터 비밀번호 › 변경…. 현재 비밀번호와 새 비밀번호(두 번)를 입력합니다. 복구 문구를 계속 사용하려면 24개 단어도 입력하십시오. 그렇지 않으면 나중에 새 문구를 만드십시오. 이미 만든 백업은 만들 때의 비밀번호를 유지합니다.

잠금

  • 상단 막대의 잠금 버튼 또는 Ctrl+L.
  • 긴급 잠금: Windows 어디서나 Ctrl+Alt+L. 즉시 잠그고 진행 중인 입력을 취소합니다.
  • 설정 › 잠금:
    • 비활성 후 잠금: 안 함 또는 1분에서 24시간.
    • Windows가 잠기면 잠금(Win+L, 사용자 전환, 로그아웃) 및 절전 시 잠금(덮개 닫기, 절전, 최대 절전).
    • 잠금 해제 상태 최대 시간: 무엇을 하고 있든 적용되는 고정 제한입니다.
    • 활동 기준: 컴퓨터 활동 또는 보관함 활동.
    • 브라우저 확장 프로그램에 2FA 코드를 전달하기 전에 확인.

트레이 아이콘 메뉴에는 LocalGateKeys 열기, 보관함 잠금 해제, 보관함 잠금, 잠금 및 사용자 전환, 빠른 액세스, 업데이트 확인, 브라우저 통합 및 데스크톱 채우기 아이콘 스위치, 종료가 있습니다.

항목 목록

  • 필터: 전체, 확인 필요, 2FA 없음, 만료 예정.
  • 정렬: 제목 A–Z, 제목 Z–A, 수정한 날짜, 만든 날짜.
  • 행의 표시는 유출되었거나 약하거나 재사용된 비밀번호를 나타냅니다.
  • 행을 마우스 오른쪽 버튼으로 클릭(또는 Shift+F10)하면 편집, 사용자 이름 복사, 비밀번호 복사, 2FA 코드 복사, 웹사이트 열기, 공유…, 즐겨찾기에 추가, 휴지통으로 이동…을 사용할 수 있습니다.

세부 정보 창

선택한 항목의 필드를 표시합니다. 비밀번호는 클릭할 때까지 숨겨져 있습니다. 버튼으로 사용자 이름, 비밀번호, 2FA 코드를 복사하고, 웹사이트를 열고, 편집, 공유, 휴지통으로 이동할 수 있습니다. 문서에는 파일 열기, 안전한 미리 보기, 사본 저장…, 파일 바꾸기…가 추가됩니다.

항목 추가 및 편집

  1. 새 항목을 선택하거나 Ctrl+N을 누릅니다.
  2. 유형을 선택합니다(클릭, 번호 누르기 또는 이름 입력):
    • 로그인: 웹사이트 로그인, 데스크톱 앱 로그인, 패스키
    • 금융: 결제 카드, 은행 계좌 · 개인: 신원 정보, 보안 메모, 문서
    • 기술: SSH 키, API 키, Wi-Fi 네트워크, 북마크 · 소유물: 라이선스, 구독, 보증, 구매
  3. 필드를 입력하고 저장을 선택합니다. 저장하지 않은 변경 사항이 있는 상태로 나가면 변경 사항을 삭제하시겠습니까?라고 묻습니다.

로그인 자세히 보기

  • 제목, 웹사이트, 사용자 이름, 비밀번호, 메모.
  • 비밀번호 옆의 변경으로 새 비밀번호를 직접 입력하거나, 암호 문구, 무작위, PIN 중에서 골라 만들 수 있습니다. 웹사이트에서도 변경한 다음 저장하십시오.
  • 2단계 인증: 사이트의 설정 키를 여기에 붙여 넣습니다(Pro). 2단계 인증 코드를 참조하십시오.
  • 사용자 지정 필드: 그 밖의 정보는 필드 추가로 입력합니다. 필드를 숨김으로 표시하면 비밀번호처럼 취급됩니다.
  • 비밀번호 기록: 이전 비밀번호는 최대 5개까지 암호화되어 1년간 보관됩니다. 이전 비밀번호 복사 또는 이 비밀번호 복원.
  • 복구 코드: 한 줄에 하나씩. 다음 코드 복사 후 사용은 하나를 복사하고 목록에서 제거합니다.
  • 자동 채우기 규칙: 채우기(클릭 시 또는 끔), 채운 후 로그인(기본값, 안 함 또는 항상), 항상 마스터 비밀번호 요청, 브라우저의 변경 사항 저장 제안.

기타 유형

각 유형에는 고유한 필드가 있습니다. 날짜는 YYYY-MM-DD 형식으로 입력합니다. 모든 항목은 즐겨찾기로 지정하고 태그(쉼표로 구분)를 달 수 있습니다. 문서는 파일 선택 후 저장을 사용합니다(Pro).

컬렉션과 미리 알림

  • 컬렉션으로 항목을 원하는 대로 묶을 수 있습니다: 컬렉션 추가, 이름 바꾸기, 보관. 다른 기기와 동기화되며, 다른 사람과 공유할 수도 있습니다(공유 컬렉션 참고).
  • 미리 알림에는 곧 만료되거나 기한이 지난 항목이 완료 및 1일 후 다시 알림과 함께 표시됩니다.
  • 활동에는 보관함에서 일어난 일의 기록이 표시됩니다.

삭제, 휴지통, 실행 취소

  1. 항목을 선택하고 휴지통으로 이동을 선택하거나 Delete를 누릅니다.
  2. 실행 취소가 있는 메시지가 나타납니다. 클릭하면 항목이 바로 돌아옵니다.
  3. 나중에 도구 › 휴지통을 열고 선택 항목 복원, 선택 항목 삭제, 휴지통 비우기를 사용합니다. 휴지통에서 삭제하면 되돌릴 수 없습니다.

설정 › 개인 정보 › 삭제한 항목 보관 기간에서 7, 14, 30, 90일을 선택하고, 휴지통 자동 비우기로 자동으로 비울 수 있습니다.

검색, 명령 팔레트, 빠른 액세스

  • 검색: Ctrl+F를 누르고 입력한 다음 Enter로 첫 결과를 열거나 ↓로 목록으로 이동합니다.
  • 명령 팔레트: Ctrl+K로 항목과 작업을 찾습니다. >로 시작하면 작업만(지금 백업, 비밀번호 생성, 지금 잠그기, 동기화 상태…), #는 태그, @는 컬렉션을 찾습니다.
  • 빠른 액세스: Windows 어디서나 Ctrl+Alt+K를 누르면 LocalGateKeys가 빠른 액세스 페이지로 열려 로그인, 메모, 북마크를 찾을 수 있습니다. 단축키는 설정 › 자동 채우기 › 빠른 액세스에서 변경합니다.

비밀번호 생성기

홈의 생성기 카드 또는 Ctrl+K › 비밀번호 생성에서 엽니다.

  • 무작위: 길이와 사용할 문자(A–Z, a–z, 0–9, 기호)를 선택합니다.
  • 암호 문구: 단어 수를 선택합니다. 입력하기 쉽고, 충분히 길면 똑같이 강력합니다.
  • 다시 생성으로 새로 만들고 복사로 복사합니다.

보안 센터와 비밀번호 상태

도구 › 보안 센터에는 먼저 고쳐야 할 항목이 표시됩니다. 약하거나 재사용되거나 오래되거나 유출된 비밀번호와 2FA를 사용할 수 있는 로그인입니다.

  • 모두 유출 확인은 비밀번호를 Have I Been Pwned 목록과 비교합니다. PC 밖으로 나가는 것은 해시의 처음 5자뿐이며 비밀번호는 절대 나가지 않습니다.
  • 유출 확인을 사용하려면 설정 › 개인 정보에서 두 가지를 바꿔야 합니다. 엄격한 오프라인 모드(기본적으로 켜짐)를 끄고 유출 확인을 켭니다. 엄격한 오프라인 모드는 유출 확인, 웹사이트 아이콘 및 기타 모든 네트워크 요청을 차단합니다.
  • 비밀번호 상태에서 항목 열기 또는 비밀번호 변경으로 항목을 수정합니다.

보안 센터 아래쪽의 네트워크 활동에는 LocalGateKeys가 온라인에 접속한 때와 이유(업데이트 확인, 유출 확인, 웹사이트 아이콘, 내 기기와의 동기화)가 모두 표시됩니다.

2단계 인증 코드와 QR 스캔 Pro

LocalGateKeys는 사이트가 비밀번호 다음에 요구하는 6자리 코드를 표시할 수 있으므로 별도의 인증 앱이 필요 없습니다.

  1. 웹사이트에서 2단계 인증/인증 앱 로그인을 켜서 QR 코드가 표시되게 합니다.
  2. LocalGateKeys에서 Ctrl+K › QR 코드 스캔을 선택합니다. 다음 세 가지 방법 중 하나로 이미지를 가져옵니다.
    • 스크린샷 붙여넣기: Win+Shift+S를 누르고 QR 코드를 선택한 다음 Ctrl+V를 누릅니다.
    • 이미지 선택…(PNG, JPEG, BMP)하거나 이미지를 끌어다 놓습니다.
    • 웹캠 사용을 선택하고 코드가 표시된 휴대폰 화면을 웹캠에 비춥니다.
  3. 해당하는 로그인 또는 새 로그인을 선택한 다음 편집기에서 열기와 저장을 선택합니다.
  4. 웹사이트에 현재 코드를 입력하여 2FA 설정을 마칩니다.

설정 키나 otpauth:// 링크를 로그인의 2단계 인증 섹션에 바로 붙여 넣을 수도 있습니다.

Google Authenticator에서 옮기기

  1. Google Authenticator에서 계정 이전 › 내보내기를 선택합니다.
  2. 표시된 QR 코드를 스캔합니다(코드가 여러 개이면 각각 스캔: "코드 3개 중 1개 스캔됨").
  3. 계정을 선택하고 기존 로그인에 추가 또는 새 로그인을 선택한 다음 추가를 선택합니다. 중복은 건너뜁니다.

이렇게 만든 새 로그인에는 needs-password 태그가 붙습니다. 실제 비밀번호는 나중에 입력하십시오. 이미지는 메모리에서만 읽히며 저장되지 않습니다. Free에서는 이미 있는 코드는 계속 작동하지만 추가하거나 변경하려면 Pro가 필요합니다.

다른 비밀번호 관리자에서 가져오기

  1. 이전 앱에서 비밀번호를 내보냅니다(아래 목록 참조).
  2. LocalGateKeys에서 도구 › 가져오기 및 내보내기 › 비밀번호 및 항목 가져오기…를 열고 파일을 선택합니다. 형식은 자동으로 인식됩니다. 암호화된 파일은 가져오기 비밀번호를 요청합니다.
  3. 알 수 없는 앱의 일반 CSV는 열 선택을 표시합니다. 어떤 열이 제목, 사용자 이름, 비밀번호 등인지 지정합니다.
  4. 각 행을 검토합니다: 추가, 건너뛰기, 바꾸기, 병합, 둘 다 유지. 새 항목 모두 추가, 충돌 모두 바꾸기, 모두 건너뛰기로 한 번에 처리할 수 있습니다.
  5. 가져오기를 선택합니다. 모두 한 번에 들어가며, 하나라도 실패하면 아무것도 기록되지 않습니다.
  6. 내보낸 파일을 삭제하십시오. 비밀번호가 암호화되지 않은 상태로 들어 있습니다.

내보내기와 암호화 전송

도구 › 가져오기 및 내보내기 › 내보내기…에서 제공하는 형식:

  • KeePass KDBX 4: 직접 정한 비밀번호(12자 이상)로 암호화됩니다. 안전한 선택입니다.
  • Bitwarden 호환 CSV, Bitwarden JSON, KeePass 2 XML: 암호화되지 않습니다. 사용 후 삭제하십시오.
  • Credential Exchange (CXF) JSON: 고른 로그인, 메모, 패스키를 다른 비밀번호 관리자용으로 내보냅니다. 암호화되지 않으며, 패스키 개인 키는 동의한 경우에만 포함됩니다.
  • 2FA 코드도 가져가려면 일회용 비밀번호(2FA) 비밀 키 포함을 선택합니다.

암호화 전송…은 선택한 항목(즐겨찾기, 유형, 태그 기준)을 비밀번호로 보호된 패키지에 담아 다른 프로필이나 PC로 옮깁니다. 받는 쪽에서 패키지 가져오기, 검사, 미리 보기를 선택한 다음 가져옵니다.

백업과 복원

예약 백업(권장)

  1. 설정 › 백업 › 백업 비밀번호 › 설정…. 12자 이상을 사용하고 적어 두십시오.
  2. 예약 백업: 매일 또는 매주, 시간과 요일을 지정합니다.
  3. 클라우드 사본 › 선택…에서 USB 드라이브나 두 번째 디스크 같은 폴더를 골라 두 번째 사본을 만듭니다.
  4. 이전 예약 백업: 최신 백업만 유지하거나, 최신 백업과 그 이전 백업을 유지합니다.
  5. 주간 복원 테스트: 매주 LocalGateKeys가 예약 백업을 복원할 수 있는지 확인합니다. 아무것도 저장되지 않습니다. 보관할 자동 백업 수로 남길 자동 백업 수를 정합니다.

백업은 보관함이 잠금 해제되어 있을 때만 실행됩니다. 앱이 닫혀 있어 놓친 백업은 다음 잠금 해제 때 실행됩니다.

백업 및 복원 페이지

백업 및 복구 카드, Ctrl+K, 또는 잠금 해제 화면의 백업 및 복원에서 엽니다.

  • 백업 만들기: 자체 비밀번호가 있는 암호화된 .lgk 파일.
  • 백업 확인: 보관함을 건드리지 않고 파일이 열리는지 확인합니다.
  • 백업 복원: 백업 비밀번호와 백업 당시의 마스터 비밀번호가 필요합니다. 새 프로필로 복원할 수도 있습니다.
  • 복원 테스트: 임시 사본을 열어 백업이 작동하는지 확인한 다음 테스트 사본 삭제를 선택합니다.
  • 복구 문구(설정 / 교체…)와 인쇄용 시트인 복구 키트 만들기.

휴대폰 백업 복원

가져오기 및 내보내기 › 휴대폰 백업 복원…에서 iPhone 앱의 .lgkm 파일을 선택하고, 비밀번호를 입력한 뒤 미리 보기, 복원을 선택합니다. 항목은 보관함에 추가되며 아무것도 지워지지 않습니다.

기기 간 동기화 Pro

동기화는 잠금 해제 상태에서만 실행됩니다. 잠금 해제할 때, 5분마다, 변경 후 몇 초 뒤에 실행됩니다. 두 가지 방법이 있으며 둘 다 사용할 수 있습니다.

Wi-Fi(같은 네트워크의 휴대폰 또는 다른 PC)

  1. 동기화 및 기기 › Wi-Fi 동기화 켜기…. 제안된 주소와 포트(47821)를 그대로 두고, 요청되면 Windows 방화벽에서 허용을 선택합니다.
  2. QR 코드 표시…를 선택합니다. 코드는 120초 동안 한 번만 작동합니다.
  3. 휴대폰 앱의 동기화 탭에서 스캔합니다. 다른 PC의 경우 코드 텍스트 복사를 선택하고 그 PC에서 QR 텍스트로 참여…를 사용합니다.
  4. 두 기기에 6자리 코드가 표시됩니다. 일치할 때만 수락을 선택하고, 그렇지 않으면 거절을 선택합니다.
  5. 페어링 직후 실수였다면 실행 취소로 새 기기를 제거할 수 있습니다.

PC 주소가 바뀌면 휴대폰에서 다시 찾기를 선택합니다.

클라우드 폴더(Dropbox, iCloud Drive…)

  1. 첫 번째 기기에서: 동기화 그룹 만들기…를 선택하고, 클라우드 앱이 동기화하는 폴더를 고른 뒤 강력한 동기화 비밀번호(12자 이상)를 설정합니다.
  2. 다른 각 기기에서: 폴더에 참여…를 선택하고 LocalGateKeys Sync가 있는 폴더를 고른 뒤 동기화 비밀번호를 입력합니다.

클라우드에는 암호화된 파일만 보입니다.

OneDrive와 Google Drive는 Apple 관련 문제가 해결될 때까지 현재 동기화에 사용할 수 없습니다. Dropbox, iCloud Drive 또는 Wi-Fi 동기화를 사용하십시오.

동기화 관리

  • 동기화 상태 페이지(사이드바의 동기화 표시를 클릭)에서 지금 동기화.
  • 기기 제거…(새 동기화 비밀번호를 설정), 동기화 비밀번호 변경….
  • 동기화 나가기…는 항목을 유지하고 그룹 정보를 지웁니다. 이 PC에서 동기화 재설정…은 키도 지웁니다(두 번 확인).
  • 한 항목이 두 기기에서 동시에 변경되면 추가 사본의 제목에 (동기화 충돌)이 붙습니다.

그룹의 모든 기기에 Pro가 필요합니다. Pro가 있는 iPhone과 페어링한 Free PC는 동기화를 통해 라이선스를 이어받아 Pro가 됩니다(Pro 라이선스 참고). 그룹당 최대 16대의 기기를 연결할 수 있습니다.

다른 사람과 항목 공유

  1. 항목을 선택하고 공유, 공유 만들기를 차례로 선택합니다.
  2. LocalGateKeys에 여섯 단어로 된 공유 코드가 표시됩니다. 파일로 저장…(.lgkshare) 또는 QR 코드 표시를 선택합니다.
  3. 파일을 보내고, 여섯 단어는 전화나 직접 만나서 등 다른 방법으로 상대방에게 알려 줍니다.

받기: .lgkshare 파일을 두 번 클릭하거나 Ctrl+K › 받은 공유 항목 › 공유 항목 열기…를 선택합니다. 여섯 단어를 입력하고 미리 보기를 확인한 다음 보관함에 저장, 둘 다 유지 또는 거절을 선택합니다. 패스키, 문서, 파일이 첨부된 항목은 공유할 수 없습니다.

Windows 앱 입력

LocalGateKeys는 웹사이트뿐 아니라 일반 Windows 프로그램의 로그인 창도 입력할 수 있습니다.

  1. 프로그램의 로그인 창을 엽니다.
  2. Ctrl+N을 누르고 데스크톱 앱 로그인을 선택한 다음 앱 검사…를 선택합니다.
  3. 로그인 필드 지정: 사용자 이름과 비밀번호 입력란을 가리킵니다. 원하면 로그인 버튼 지정….
  4. 로그인 저장.
  5. 다음부터는 해당 프로그램에서 Ctrl+Shift+Space를 누르거나 비밀번호 입력란 옆의 입력 버튼을 클릭합니다.

업데이트 후 프로그램이 바뀌면 로그인을 열고 앱 바인딩… › 바인딩 새로 고침…을 선택합니다. LocalGateKeys는 창 구성만 읽으며 입력하는 내용은 절대 읽지 않습니다.

공유 컬렉션 Pro

모두가 접근할 수 있는 폴더(예: 공유 OneDrive 폴더)를 통해 가족이나 팀과 컬렉션 하나를 공유하세요. 컬렉션을 열고 컬렉션 공유를 선택한 뒤 폴더, 구성원의 편집 또는 보기 전용 여부, 공유 비밀번호를 정합니다.

다른 사람은 공유 컬렉션에 참여를 선택하고 폴더를 고른 뒤 공유 비밀번호를 입력합니다. 그러면 내가 참여 승인을 선택합니다. 폴더를 거치는 것은 그 컬렉션뿐이며 다른 항목은 비공개로 유지됩니다. 언제든 사람을 제거하거나 공유 중지 또는 나가기를 할 수 있습니다.

긴급 액세스와 강요 대비 비밀번호 Pro

  • 긴급 액세스(Pro): 백업 및 복원 페이지에서 긴급 액세스 설정을 선택합니다. 복구 문구가 신뢰하는 사람들을 위한 조각으로 나뉘며, 필요한 조각 수와 대기 기간을 정합니다. 각 보유자에게 해당 종이나 조각 파일을 전달하세요.
  • 충분한 보유자가 공유 폴더를 통해 액세스를 요청하면 내 기기에 요청이 표시되고, 대기 기간이 끝날 때까지 거부할 수 있습니다. 보유자는 액세스를 받았습니다를 선택하고 조각을 추가한 뒤 액세스 요청을 선택합니다. 승인되면 보관함이 새 프로필로 열립니다.
  • 같은 페이지의 유산 팩은 상속인을 위한 메모(유언장 위치, 해지할 계정, 기기, 조각 보유자)를 만든 다음 인쇄할 비상 키트를 만듭니다.
  • 강요 대비 비밀번호(Pro): 설정 › 잠금 해제 › 강요 대비 비밀번호 › 설정. 누군가 잠금 해제를 강요할 때 쓰는 두 번째 마스터 비밀번호입니다. 고른 항목만 있는 별도의 보관함이 열리고, 실제 보관함은 설정한 시간 동안 마스터 비밀번호를 거부합니다. Windows, Mac, iPhone, Android에서 쓸 수 있습니다.

개발자 도구와 AI 에이전트

설정 › 개발자에서 보관함의 SSH 키를 이 PC의 ssh와 Git에 제공해 로그인과 커밋 서명에 쓸 수 있습니다. 서명할 때마다 승인을 요청합니다. 생성은 보관함에 새 Ed25519 키를 만듭니다.

AI 에이전트가 LocalGateKeys를 사용하도록 허용을 켜면 Claude Code 같은 에이전트가 MCP로 연결할 수 있습니다. 로그인이나 읽기는 매번 승인하며, 에이전트는 비밀번호를 볼 수 없고 모든 요청이 기록됩니다. Microsoft Store 버전에서는 claude mcp add localgatekeys -- LocalGateKeysNativeHost.exe mcp로 추가합니다.

설정

상단의 설정 검색 상자(Ctrl+F)로 모든 옵션을 찾을 수 있습니다. 변경 사항은 즉시 저장됩니다.

Windows Hello, 보안 키, 카메라 확인, 키 파일, YubiKey, 마스터 비밀번호, 복구 문구.
잠금
자동 잠금 시간과 조건(잠금 해제와 잠금 참조).
자동 입력
브라우저 자동 입력, 패스키에 LocalGateKeys 제안, 데스크톱 앱 자동 입력, 입력 후 로그인, 빠른 액세스 단축키. Windows 패스키에 LocalGateKeys 사용을 켜면 Windows 11의 모든 앱과 브라우저에서 패스키를 쓸 수 있으며, 매번 사용자의 승인을 받습니다.
개인 정보
클립보드 지우기 시간(5초에서 5분), 유출 확인, 엄격한 오프라인 모드, 스크린샷 및 화면 공유에서 숨기기, 휴지통 보관 기간, 다른 앱에서 문서 열기.
백업
백업과 복원을 참조하십시오.
모양 및 앱
테마 시스템, 라이트, 다크, 언어, Windows와 함께 시작(잠긴 상태로 시작), 트레이에서 계속 실행, 업데이트.
요금제 및 동기화
라이선스, 기기 동기화, 동기화에서 제거되면 이 기기 지우기.
개발자
SSH 에이전트와 Git 서명, AI 에이전트(개발자 도구와 AI 에이전트 참고).
도움말 및 진단
키보드 단축키, 설정 다시 보기, 기기 및 연결, 오류 로그, 법적 고지 페이지.

Pro 라이선스

  1. 가격 페이지에서 Pro를 구매합니다. 키(LGK1-로 시작)는 이메일로 전송됩니다.
  2. 설정 › 요금제 및 동기화 › 라이선스를 열고 키를 붙여 넣은 다음 설치를 선택하거나, .lgklicense 파일이면 파일 열기…를 선택합니다.

iPhone 앱에서 Pro를 구매했나요? PC를 iPhone과 페어링하면(동기화 참고) Free PC가 동기화를 통해 Pro가 됩니다. 또는 iPhone의 설정에서 키 복사를 선택해 같은 방법으로 PC에 설치하세요. 라이선스 페이지에는 무료 7개 항목 중 몇 개를 사용했는지 표시됩니다. 자세한 내용은 Pro 라이선스를 참고하세요.

업데이트

Microsoft Store의 LocalGateKeys는 Store를 통해 자동으로 업데이트됩니다. 아직 이전 설치 프로그램 버전을 사용 중이신가요? 마지막 업데이트는 0.4.12입니다. Windows 설정 › 앱 › 설치된 앱에서 제거한 다음 Microsoft Store에서 LocalGateKeys를 설치하세요. 보관함은 그대로 남아 있으며 같은 마스터 비밀번호로 열립니다.
