iPhone용 LocalGateKeys

이 기기의 모든 화면과 기능을 단계별로 안내합니다. 모든 제목은 공유할 수 있는 링크입니다.

  • Windows
  • Mac
  • iPhone 및 iPad
  • Android
  • 브라우저 확장 프로그램

모든 기기에서 알아 두면 좋은 점

  • 보관함은 사용자의 기기에만 있습니다. 계정이 없으며 비밀번호를 보관하는 LocalGateKeys 서버도 없습니다.
  • 마스터 비밀번호나 앱 비밀번호는 누구도 재설정할 수 없습니다. 복구 문구를 설정하고 종이에 적어 보관하십시오.
  • Free는 항목을 최대 7개까지 보관합니다. Pro(US$29.99, 한 번 결제)는 무제한 항목, 2단계 인증 코드, 파일, 동기화를 제공합니다. 이미 있는 항목의 편집, 삭제, 입력은 절대 차단되지 않습니다.

처음 시작과 잠금 해제

만들 비밀번호가 없습니다. 보관함은 휴대폰과 마찬가지로 Face ID, Touch ID 또는 iPhone 암호로 열립니다. (iPhone에 암호가 설정되어 있어야 합니다.)

  1. 앱을 열고 잠금 해제를 탭합니다.
  2. 간단한 설정이 이어집니다: Face ID로 잠금 해제, 비밀번호 가져오기, 앱 비밀번호 추가(선택 사항), 자동 완성 켜기.
  3. 원하는 것은 건너뛰어도 됩니다. 보관함 상단의 설정 마무리 카드나 설정 › 설정 다시 보기로 돌아갈 수 있습니다.

앱 비밀번호와 복구 문구

iPhone 암호 대신 LocalGateKeys를 여는 선택적 추가 비밀번호입니다. 다른 사람이 암호를 알고 있을 때 유용합니다.

  1. 설정 › 앱 비밀번호 › 앱 비밀번호 사용을 켭니다.
  2. 강력한 비밀번호(12자 이상)를 정하고, 바로 잠금 해제하려면 Face ID로 잠금 해제를 켜 둡니다.
  3. 24단어 복구 문구를 적어 두고 적어 두었습니다를 탭한 다음 요청한 세 단어를 입력합니다.

잊으셨습니까? 잠금 해제 화면에서 앱 비밀번호를 잊으셨습니까?를 탭하고 24단어를 입력한 다음 새 앱 비밀번호를 정합니다.

iPhone에 새 얼굴이나 지문을 추가하면 안전을 위해 Face ID 바로 가기가 꺼집니다. 앱 비밀번호를 한 번 입력하고 다시 켜십시오.

항목: 추가, 편집, 삭제

  1. 보관함 탭에서 +를 탭하고 유형을 선택합니다: 웹 로그인, 보안 메모, 카드, 신원 정보, 은행 계좌, 구매, 구독, 보증, Wi-Fi, 소프트웨어 라이선스, API 키, SSH 키, 북마크.
  2. 필드를 입력하고 저장을 탭합니다. 도중에 나가면 저장하지 않은 항목을 나중에 계속할 수 있도록 제안합니다.
  • 보관함에서 항목을 길게 눌러 사용자 이름 복사, 비밀번호 복사, 2FA 코드 복사, 웹사이트 열기, 즐겨찾기 지정을 할 수 있습니다. 항목을 열면 모든 필드를 복사하거나, 별표를 표시하거나, 공유할 수 있습니다. 복사한 텍스트는 잠시 후 클립보드에서 지워지며 다른 Apple 기기로 전달되지 않습니다.
  • 로그인의 비밀번호 기록에는 이전 비밀번호가 보관됩니다. 복사하거나 복원할 수 있습니다(Face ID 요청).
  • 로그인을 제외한 모든 항목(카드, 구독, 보증, 라이선스 등)에 만료 전 미리 알림을 설정할 수 있습니다. 카드는 만료일이 제안됩니다.
  • +에서 파일 첨부(Pro, 최대 25MB, 암호화하여 저장).
  • 삭제: 항목이 최근 삭제된 항목으로 이동하며 몇 초 동안 실행 취소할 수 있습니다. 설정 › 데이터 › 최근 삭제된 항목에서 복원 또는 영구 삭제할 수 있습니다.
  • 이름이나 날짜순, 즐겨찾기 우선 또는 유형별로 정렬합니다.

검색과 빠른 작업

보관함 상단의 검색 버튼(돋보기)을 탭하고 입력합니다. 보관함을 아래로 당기면 동기화됩니다. 먼저 >를 입력하면 작업이 표시됩니다: 새 항목, 비밀번호 생성, QR 코드 스캔, 지금 잠그기, 지금 동기화, 보안 점검, 최근 삭제된 항목, 가져오기 및 내보내기 등.

비밀번호 생성기

> 비밀번호 생성에서, 또는 로그인의 비밀번호를 편집하는 중에 사용합니다. 길이를 정한 비밀번호 또는 단어 수와 구분 기호를 정한 암호 문구를 선택합니다. 새로 고침 버튼을 탭해 다시 생성한 다음 사용합니다. 마지막으로 사용한 옵션을 기억하며, 설정 › 비밀번호 생성기 › 기본값으로 재설정으로 기본값을 되돌릴 수 있습니다.

2단계 인증 코드 Pro

  1. 웹사이트에서 인증 앱 2FA를 켜서 QR 코드가 표시되게 합니다.
  2. LocalGateKeys에서 QR 코드 스캔을 선택합니다(> 또는 로그인의 2FA 필드에서). 카메라 사용 또는 사진에서 선택(스크린샷의 경우)을 탭합니다.
  3. 코드는 일치하는 로그인으로 들어가거나, 저장할 준비가 된 새 로그인이 열립니다.

코드는 항목과 보관함의 코드 행에 표시됩니다. 로그인의 2FA 비밀 키 필드에 설정 키를 붙여 넣을 수도 있습니다. Google Authenticator 내보내기(계정 이전)도 여러 부분으로 나뉜 것을 포함해 사용할 수 있습니다.

손목에서 코드를 보고 싶으십니까? Apple Watch를 참조하십시오.

앱과 Safari에서 자동 완성

  1. LocalGateKeys에서 설정 › 자동 완성 › 자동 완성 설정 열기로 이동합니다.
  2. iPhone 설정의 일반 › 자동 완성 및 암호에서 LocalGateKeys를 켭니다.
  3. 이제 앱이나 웹사이트에서 사용자 이름 또는 비밀번호 상자를 탭하면 키보드 위에 로그인이 나타납니다. 열쇠 아이콘을 탭하여 선택할 수도 있습니다.

설정 › 자동 완성의 옵션:

  • QuickType 막대에 로그인 표시: 키보드 위에 제안을 표시합니다.
  • 채울 때 2FA 코드 복사: 다음 화면에서 코드를 붙여 넣을 수 있습니다. 클립보드 지우기 시간(기본값 60초)이 지나면 지워집니다.
  • 패스키에 LocalGateKeys 제안.

iOS 18 이상에서는 카드와 연락처 정보도 채워집니다. 텍스트 필드를 탭하고 자동 완성 › 암호를 선택한 다음 필드를 고릅니다. https 사이트에 저장된 로그인은 일반 http 페이지에서는 제안되지 않습니다.

패스키

자동 완성이 켜진 상태에서 웹사이트가 패스키 생성을 제안하면 LocalGateKeys를 선택합니다. 패스키는 보관함에 저장되고 PC와 동기화됩니다. iPhone으로 컴퓨터의 QR 코드를 스캔하여 로그인할 수도 있습니다. 패스키 세부 정보 페이지에는 사이트와 계정이 표시되며, 키 자체는 절대 표시되지 않습니다. 이름을 바꾸거나 삭제할 수 있습니다.

Safari에서 로그인 저장

  1. iPhone 설정 › 앱 › Safari › 확장 프로그램 › LocalGateKeys: 켜고 모든 웹사이트에서 허용합니다.
  2. Safari에서 사이트에 로그인하고 확인 창에서 저장을 탭합니다.
  3. 다음에 LocalGateKeys를 잠금 해제하면 Safari에서 저장하시겠습니까?에 포착된 내용이 새 로그인 또는 저장된 비밀번호 업데이트 표시와 함께 나열됩니다. 유지할 항목을 선택하거나 나중에 결정을 선택합니다.

사이트에서 확인 창을 멈추려면 이 사이트에서 사용 안 함을 선택합니다.

보안 탭

점수와 함께 유출됨, 중복, 취약, 이전 또는 2FA를 사용할 수 있는 로그인 목록을 보여 줍니다. 로그인을 왼쪽으로 쓸어 비밀번호 변경 또는 닫기를 선택합니다. 유출 확인은 설정 › 엄격한 오프라인 모드(기본적으로 켜짐)를 끄고 유출 검사 허용을 켤 때까지 꺼져 있습니다.

가져오기와 내보내기

Apple 암호에서(iOS 26)

  1. 암호 앱을 열고 메뉴를 탭한 다음 다른 앱으로 데이터 내보내기를 선택합니다.
  2. LocalGateKeys를 선택합니다. 로그인, 2FA 코드, 패스키가 옮겨집니다. 다시 해도 중복으로 추가되지 않습니다.

파일에서

설정 › 가져오기 및 내보내기 › 파일에서 가져오기: Apple 암호, Safari, Chrome, Edge, Brave, Firefox, Bitwarden(비밀번호로 보호된 파일 포함), 1Password(.1pux), LastPass, KeePass(.kdbx), Proton Pass, Dashlane에서 내보낸 파일 또는 기타 CSV. 가져오기를 탭하기 전에 모든 항목을 검토합니다. 그 후 내보낸 파일을 삭제하십시오.

백업과 내보내기

  • 암호화된 백업 내보내기: 12자 이상의 비밀번호가 있는 .lgkm 파일. Windows에서 복원할 수 있습니다.
  • CSV로 내보내기: 암호화되지 않으며 다른 앱으로 옮길 때 사용합니다. 확인을 요청합니다.
  • CXF 파일로 내보내기…는 고른 로그인, 메모, 패스키를 다른 비밀번호 관리자가 가져올 수 있는 Credential Exchange 파일로 저장합니다. 파일은 암호화되지 않습니다.

PC와 동기화 Pro

Wi-Fi로

  1. PC에서 동기화 및 기기를 열고 QR 코드 표시를 선택합니다.
  2. iPhone에서 동기화 탭을 열고 120초 안에 QR 코드 스캔을 탭합니다. (처음에는 로컬 네트워크 접근을 허용합니다.) 카메라가 없으면 코드 텍스트 붙여넣기를 탭하고 컴퓨터의 코드 텍스트 복사로 얻은 텍스트를 붙여 넣습니다.
  3. 두 화면에 같은 코드가 표시되는지 확인한 다음 컴퓨터에서 수락을 선택합니다.

두 기기가 같은 Wi-Fi에 있고 잠금 해제되어 있으면 동기화됩니다. 지금 동기화로 강제로 실행하고, 컴퓨터 주소가 바뀌었다면 다시 찾기가 도움이 됩니다.

클라우드 폴더로

폴더에 참여…를 탭하고 iCloud Drive 또는 Dropbox에서 LocalGateKeys Sync 폴더를 선택한 다음 그룹의 동기화 비밀번호를 입력합니다.

OneDrive와 Google Drive는 Apple 관련 문제가 해결될 때까지 현재 동기화에 사용할 수 없습니다. Dropbox, iCloud Drive 또는 Wi-Fi 동기화를 사용하십시오.

중지

동기화 나가기… 또는 이 iPhone에서 동기화 재설정…(각각 두 번 확인). 항목은 휴대폰에 남아 있습니다.

항목 공유

  1. 항목을 열고 공유를 탭합니다.
  2. 앱에 여섯 단어가 표시됩니다. AirDrop 또는 파일 공유…로 파일을 보내거나 코드를 QR로 표시합니다.
  3. 여섯 단어는 파일과 따로, 절대 파일과 함께 보내지 말고 상대방에게 알려 주십시오.

받기: AirDrop이나 파일 앱에서 .lgkshare 파일을 열고(또는 공유 항목 받기) 여섯 단어를 입력합니다. 패스키와 파일이 첨부된 항목은 공유할 수 없습니다.

설정

개인 정보
엄격한 오프라인 모드, 웹사이트 아이콘, 알림의 항목 이름, 유출 확인.
모양
시스템, 라이트 또는 다크.
데이터
최근 삭제된 항목, 삭제한 항목 보관 기간, 가져오기 및 내보내기.
지우기
이 iPhone의 보관함 지우기는 이 iPhone의 보관함만 삭제합니다(두 번 확인). PC와 동기화 폴더는 변경되지 않습니다.

강요 대비 비밀번호 등

  • 강요 대비 비밀번호(Pro): 누군가 잠금 해제를 강요할 때 쓰는 두 번째 앱 비밀번호입니다. 고른 항목만 있는 별도의 보관함이 열리고, 내 보관함은 설정한 시간 동안 앱 비밀번호를 거부합니다. 먼저 앱 비밀번호를 켠 다음 설정의 강요 대비 비밀번호에서 설정하세요.
  • 동기화 탭의 이 휴대폰에서 Wi-Fi 동기화 호스트하기(Pro)를 켜면 다른 기기가 iPhone과 직접 페어링할 수 있어 PC가 필요 없습니다.
  • PC에서 만든 긴급 액세스 계획은 동기화로 iPhone에도 전달되므로 여기서도 요청을 거부하거나 승인할 수 있습니다. 유산 정리 팩 메모 만들기로 상속인을 위한 메모를 추가합니다.

Pro

설정 › Pro › 업그레이드를 선택한 다음 구매합니다: 한 번의 결제이며 구독도 계정도 필요 없습니다. 새 iPhone에서는 같은 Apple 계정으로 구매 복원을 사용하세요.

구매하면 Windows도 잠금 해제됩니다. 동기화 탭에서 PC와 iPhone을 페어링하면 Free PC가 동기화를 통해 라이선스를 이어받아 Pro가 됩니다. 또는 키 복사를 선택해 그 키를 PC에 설치하세요(설정 › 요금제 및 동기화 › 라이선스).
