LocalGateKeys 다운로드

두 에디션 모두 하나의 다운로드로 설치됩니다. 처음에는 모두 Free로 시작하며, Pro 라이선스 키를 입력하면 4개 항목 제한이 없어지고 동기화, 2단계 인증 코드, 문서가 켜집니다.

Microsoft Store

설치와 업데이트를 가장 쉽게 하는 방법입니다. Windows 10 또는 11, 64비트.

Microsoft Store에서 받기

Windows용 설치 관리자

버전 0.4.10, Store를 사용하지 않으려는 분을 위한 것입니다. Windows 10 또는 11, 64비트.

SHA-256: E08185448318A793E20A5662DB38C58D93774FFA6B819D9EC6A1D8DB9967192D

설치 관리자에 아직 코드 서명이 없어 Windows SmartScreen에 "Windows의 PC 보호"가 표시될 수 있습니다. 먼저 위의 SHA-256을 확인하세요(아래 "설치 관리자 확인" 참조). 일치하면 추가 정보를 선택한 다음 실행을 선택하세요.

App Store에서 다운로드

실행하기 전에 설치 관리자 확인

설치 관리자의 지문을 위의 SHA-256 값과 비교하세요. 다운로드한 폴더에서 PowerShell로 다음을 실행합니다:

Get-FileHash .\LocalGateKeys-Setup-Personal.exe -Algorithm SHA256

값이 일치하지 않으면 파일을 실행하지 마세요. 이 페이지에서 다시 다운로드하고 security@localgatekeys.app로 알려 주세요.

필요한 것

  • Windows 10 또는 Windows 11, 64비트
  • 브라우저 채우기를 위한 최신 버전의 Google Chrome 또는 Microsoft Edge
  • Windows Hello 잠금 해제를 위한 Windows Hello 하드웨어(지문 인식기, Hello 카메라 또는 PIN)
  • 동기화용: Pro, 그리고 같은 네트워크에 있는 PC 두 대 이상 또는 각 PC에 설치된 클라우드 드라이브 앱

설치한 후

시작 가이드에서 스크린샷과 함께 모든 단계를 안내합니다.

  1. LocalGateKeys를 열고 12자 이상의 마스터 비밀번호를 정하세요. 안전한 곳에 적어 두세요. 저희는 이 비밀번호를 재설정해 드릴 수 없습니다.
  2. 설정에서 복구 문구를 만들고 오프라인으로 보관하세요.
  3. 설정에서 예약 백업을 켜세요.
  4. 브라우저 확장 프로그램을 추가하고 (Edge용) 도구 모음에 고정하세요. 확장 프로그램은 앱이 설치되어 있어야만 작동합니다.
  5. Pro를 구매하셨나요? 도구 > 라이선스에 라이선스 키를 입력하세요. 내 Pro 라이선스를 참조하세요.
