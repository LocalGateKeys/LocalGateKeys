LocalGateKeys 다운로드

Windows, Mac, iPhone 모두 두 에디션이 하나의 다운로드로 제공됩니다. 처음에는 모두 Free로 시작하며, Pro는 7개 항목 제한을 없애고 동기화, 2단계 인증 코드, 문서를 켭니다.

Microsoft Store

LocalGateKeys를 설치하고 항상 최신 상태로 유지합니다. Windows 10 또는 11, 64비트.

iPhone

iPhone 앱은 App Store에서 받을 수 있으며 Apple Watch 앱이 포함되어 있습니다. PC 및 Mac과 동기화되고, 앱에서 Pro를 구매하면 Windows도 잠금 해제됩니다.

사용자 가이드

App Store에서 다운로드

Mac

Mac 앱은 Mac App Store에 있습니다. PC 및 iPhone과 동기화되며 Touch ID와 메뉴 막대를 지원합니다. Safari에서는 자동 완성으로 로그인 정보를 입력하고, Safari 확장 프로그램이 새 로그인 저장을 제안합니다.

Android

Android 앱은 준비 중입니다. 아직 Google Play에 없습니다.

사용자 가이드

출시 예정

이전 설치 프로그램을 사용하셨나요?

Windows 설정 › 앱 › 설치된 앱에서 제거한 다음 Microsoft Store에서 LocalGateKeys를 설치하세요. 보관함은 그대로 남아 있습니다. Store 앱이 같은 마스터 비밀번호로 엽니다.

필요한 것

  • Windows 10 또는 Windows 11, 64비트
  • 브라우저 채우기를 위한 최신 버전의 Google Chrome 또는 Microsoft Edge
  • Windows Hello 잠금 해제를 위한 Windows Hello 하드웨어(지문 인식기, Hello 카메라 또는 PIN)
  • 동기화: Pro, 그리고 같은 네트워크의 기기 두 대 이상 또는 각 기기의 클라우드 드라이브 앱
  • Apple Watch 코드: Pro와 iPhone에 페어링된 Apple Watch가 필요합니다

설치한 후

시작 가이드에서 스크린샷과 함께 모든 단계를 안내합니다.

  1. LocalGateKeys를 열고 12자 이상의 마스터 비밀번호를 정하세요. 안전한 곳에 적어 두세요. 저희는 이 비밀번호를 재설정해 드릴 수 없습니다.
  2. 설정 안내에서 제안하면 복구 문구를 만들고 오프라인에 보관하세요.
  3. 설정에서 예약 백업을 켜세요.
  4. 브라우저 확장 프로그램을 추가하고 (Edge용), Firefox (Chrome용) 도구 모음에 고정하세요. 확장 프로그램은 앱이 설치되어 있어야만 작동합니다.
  5. Pro를 구매하셨나요? 도구 > 라이선스에 라이선스 키를 입력하세요. 내 Pro 라이선스를 참조하세요.
