시작하기

Windows 앱을 설치하고, 보관함을 만든 다음, 브라우저 확장 프로그램을 추가하세요. 약 5분이 걸리며 계정은 필요 없습니다.

1. 앱 설치 2. 보관함 만들기 3. 브라우저 확장 프로그램 추가 4. 비밀번호 가져오기 5. Windows 앱 채우기 6. Pro 켜기 iPhone 및 Android

1 Windows 앱 설치

LocalGateKeys는 Windows 10 및 Windows 11(64비트)에서 실행됩니다. 설치 방법 중 하나를 고르세요:

  • Microsoft Store(권장). Store가 설치하고 최신 상태로 유지해 줍니다. Microsoft Store에서 LocalGateKeys 열기, 받기를 선택한 다음 열기를 선택하세요.
  • 설치 관리자. 다운로드 페이지에서 받고, 거기에 나와 있는 대로 SHA-256을 확인한 다음 실행하세요. 설치 관리자에 아직 코드 서명이 없어 Windows SmartScreen이 경고할 수 있습니다. 지문이 일치하면 추가 정보를 선택한 다음 실행을 선택하세요.

한 PC에서는 둘 중 하나만 사용하세요.

Microsoft Store에서 받기 다른 다운로드

2 보관함 만들기

  1. LocalGateKeys를 엽니다. 처음 시작하면 보관함을 만들라고 안내합니다.
  2. 12자 이상의 마스터 비밀번호를 정하세요. 적어서 안전한 곳에 보관하세요. 저희는 이 비밀번호를 갖고 있지 않으므로 아무도 대신 재설정해 줄 수 없습니다.
  3. 사이드바에서 보안 센터를 열고 복구 문구를 설정하세요. 예를 들어 종이에 적어 오프라인으로 보관하세요. 마스터 비밀번호를 잊었을 때 보관함을 열 수 있습니다.
  4. PC에 지문 인식기, Hello 카메라 또는 PIN이 있다면 같은 곳에서 Windows Hello를 켜서 평소의 잠금 해제를 빠르게 하세요.
  5. 설정에서 예약 백업을 켜고 USB 드라이브나 이미 백업 중인 폴더처럼 암호화된 백업 파일을 보낼 위치를 고르세요.

3 브라우저 확장 프로그램 추가

확장 프로그램은 브라우저에서 로그인을 채웁니다. 같은 PC의 LocalGateKeys 앱과만 통신하므로 앱을 먼저 설치하세요.

  1. 확장 프로그램을 추가합니다:
    • Microsoft Edge: Edge 추가 기능에서 열고 가져오기를 선택하세요.
    • Google Chrome: Chrome 웹 스토어에 곧 출시됩니다.
  2. 고정하기: 브라우저의 확장 프로그램 메뉴(퍼즐 조각 아이콘)를 열고 LocalGateKeys를 도구 모음에 고정하세요.
  3. 앱을 실행한 상태로 잠금을 해제해 두세요. 로그인이 저장된 로그인 페이지로 이동하면 확장 프로그램이 정확히 그 사이트에 저장된 로그인만 제안합니다. 클릭하기 전에는 아무것도 채워지지 않습니다.
  4. 새로운 곳에 로그인하면 확장 프로그램이 로그인을 저장하도록 제안합니다.

확장 프로그램이 앱에 연결할 수 없다고 하나요? 앱에서 기기 및 연결을 열고 브리지 복구를 선택한 다음 브라우저를 다시 시작하세요.

4 비밀번호 가져오기

사이드바에서 가져오기 및 내보내기를 선택하고 1Password, Bitwarden, LastPass, Dashlane, Proton Pass, KeePass 또는 KeePassXC, Chrome, Edge, Brave, Firefox, Safari의 내보내기 파일이나 아무 CSV 파일을 고르세요. 무언가가 저장되기 전에 모든 항목을 직접 검토하며 아무것도 온라인으로 전송되지 않습니다. 대부분의 내보내기 파일에는 비밀번호가 일반 텍스트로 들어 있으므로 끝난 후에는 내보내기 파일을 삭제하세요.

Free 에디션은 항목을 4개까지 담을 수 있습니다. Pro는 제한을 없앱니다.

5 Windows 앱 채우기

게임 런처 같은 프로그램은 앱에서 데스크톱 로그인을 열고 앱 바인딩…을 선택해 프로그램의 로그인 창에 한 번 바인딩하세요. 그 후에는 비밀번호 필드 옆에 채우기 버튼이 나타나며 단축키도 사용할 수 있습니다. 바인딩한 이후 프로그램이나 창이 바뀌었다면 LocalGateKeys는 채우기를 거부합니다.

6 Pro 켜기

Pro는 항목 무제한, 기기 간 동기화, 2단계 인증 코드, 문서를 더하는 일회성 결제입니다. 구매한 후 앱의 도구 > 라이선스에 라이선스 키를 붙여 넣으세요. 내 Pro 라이선스를 참조하세요.

iPhone 및 Android

iPhone: App Store에서 LocalGateKeys를 설치하세요. Windows PC와 동기화됩니다.

Android: Android 앱을 계획 중입니다. 아직 사용할 수 없습니다.

Android의 설정 단계는 앱이 출시되면 이 페이지에 추가됩니다. 그때까지 보관함은 PC에 남아 있으며, Pro로 Windows PC 간에 동기화할 수 있습니다.
