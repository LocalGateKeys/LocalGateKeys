시작하기

Windows 앱을 설치하고, 보관함을 만든 다음, 브라우저 확장 프로그램을 추가하세요. 약 5분이 걸리며 계정은 필요 없습니다. iPhone 앱은 원할 때 언제든 추가할 수 있습니다.

1 Windows 앱 설치

LocalGateKeys는 Windows 10(버전 2004 이상) 및 Windows 11(64비트)에서 실행되며 Microsoft Store에서 받을 수 있습니다.

  • Microsoft Store. Store가 설치하고 최신 상태로 유지해 줍니다. Microsoft Store에서 LocalGateKeys 열기, 받기를 선택한 다음 열기를 선택하세요.
  • 이전 설치 프로그램을 사용하셨나요? Windows 설정 › 앱(Windows 11에서는 설치된 앱, Windows 10에서는 앱 및 기능)에서 제거한 다음 Microsoft Store에서 설치하세요. 보관함은 그대로 남아 있으며, Store 앱이 같은 마스터 비밀번호로 엽니다.

Microsoft Store에서 받기 다른 다운로드

2 보관함 만들기

  1. LocalGateKeys를 엽니다. 처음 시작하면 보관함을 만들라는 안내가 나오고, 이어서 짧은 설정 안내에서 Windows Hello, 가져오기, 복구 문구, 브라우저 확장 프로그램을 설정할 수 있습니다. 건너뛴 단계는 나중에 설정 완료 카드에서 마칠 수 있습니다.
  2. 12자 이상의 마스터 비밀번호를 정하세요. 적어서 안전한 곳에 보관하세요. 저희는 이 비밀번호를 갖고 있지 않으므로 아무도 대신 재설정해 줄 수 없습니다.
  3. 사이드바에서 보안 센터를 열고 복구 문구를 설정하세요. 예를 들어 종이에 적어 오프라인으로 보관하세요. 마스터 비밀번호를 잊었을 때 보관함을 열 수 있습니다.
  4. PC에 지문 인식기, Hello 카메라 또는 PIN이 있다면 같은 곳에서 Windows Hello를 켜서 평소의 잠금 해제를 빠르게 하세요.
  5. 설정에서 예약 백업을 켜고 USB 드라이브나 이미 백업 중인 폴더처럼 암호화된 백업 파일을 보낼 위치를 고르세요.

3 브라우저 확장 프로그램 추가

확장 프로그램은 브라우저에서 로그인을 채웁니다. 같은 PC의 LocalGateKeys 앱과만 통신하므로 앱을 먼저 설치하세요.

  1. 확장 프로그램을 추가합니다:
    • Microsoft Edge: Edge 추가 기능에서 열고 가져오기를 선택하세요.
    • Google Chrome: Chrome 웹 스토어에서 열고 Chrome에 추가를 선택하세요.
    • Mozilla Firefox (Windows): Firefox 부가 기능에서 열고 Firefox에 추가를 선택하세요.
  2. 고정하기: 브라우저의 확장 프로그램 메뉴(퍼즐 조각 아이콘)를 열고 LocalGateKeys를 도구 모음에 고정하세요.
  3. 앱을 실행한 상태로 잠금을 해제해 두세요. 로그인이 저장된 로그인 페이지로 이동하면 확장 프로그램이 정확히 그 사이트에 저장된 로그인만 제안합니다. 클릭하기 전에는 아무것도 채워지지 않습니다.
  4. 새로운 곳에 로그인하면 확장 프로그램이 로그인을 저장하도록 제안합니다.

확장 프로그램이 앱에 연결할 수 없다고 하나요? 앱에서 기기 및 연결을 열고 브리지 복구를 선택한 다음 브라우저를 다시 시작하세요.

4 비밀번호 가져오기

사이드바에서 가져오기 및 내보내기를 선택하고 1Password, Bitwarden, LastPass, Dashlane, Proton Pass, KeePass 또는 KeePassXC, Chrome, Edge, Brave, Firefox, Safari의 내보내기 파일이나 아무 CSV 파일을 고르세요. 무언가가 저장되기 전에 모든 항목을 직접 검토하며 아무것도 온라인으로 전송되지 않습니다. 대부분의 내보내기 파일에는 비밀번호가 일반 텍스트로 들어 있으므로 끝난 후에는 내보내기 파일을 삭제하세요.

Free 에디션은 항목을 7개까지 담을 수 있습니다. Pro는 제한을 없앱니다.

5 Windows 앱 채우기

게임 런처 같은 프로그램은 앱에서 데스크톱 로그인을 열고 앱 바인딩…을 선택해 프로그램의 로그인 창에 한 번 바인딩하세요. 그 후에는 비밀번호 필드 옆에 채우기 버튼이 나타나며, Ctrl+Shift+Space를 눌러도 됩니다. 바인딩한 이후 프로그램이나 창이 바뀌었다면 LocalGateKeys는 채우기를 거부합니다.

6 Pro 켜기

Pro는 한 번의 결제로 무제한 항목, 기기 간 동기화, 2단계 인증 코드, 문서를 더합니다. 구매한 뒤 라이선스 페이지에서 LocalGateKeys에 설치를 선택하거나, 설정 › 요금제 및 동기화 › 라이선스에 라이선스 키를 붙여 넣으세요. Pro 라이선스를 참고하세요.

7 iPhone 추가

iPhone 앱은 자체 암호화된 보관함을 두고 PC와 동기화됩니다. 동기화는 Pro에 포함됩니다.

  1. App Store에서 LocalGateKeys를 설치하고 엽니다.
  2. 잠금 해제를 탭합니다. 보관함은 Face ID, Touch ID 또는 iPhone 암호로 열리므로 만들어야 할 비밀번호가 없습니다. 이어지는 짧은 설정에서 가져오기, 선택 사항인 앱 비밀번호, AutoFill을 설정할 수 있습니다.
  3. AutoFill을 켭니다. LocalGateKeys에서 설정 › AutoFill › AutoFill 설정 열기를 선택한 다음, 일반 › AutoFill 및 암호에서 LocalGateKeys를 켭니다.
  4. PC와 페어링합니다. PC에서 동기화 및 기기를 열고 Wi-Fi 동기화를 켠 다음 QR 코드 표시를 선택합니다. iPhone에서는 동기화 탭을 열고 QR 코드 스캔을 탭합니다. 두 화면에 같은 코드가 표시되는지 확인한 다음, PC에서 수락을 선택합니다.
  5. Apple Watch(Pro): iPhone의 Watch 앱에서 LocalGateKeys를 설치한 다음, 2단계 인증 코드가 있는 로그인을 열고 Apple Watch에 표시를 탭합니다.

iPhone에서 Pro를 구매했나요? 페어링하면 Free PC가 동기화를 통해 라이선스를 이어받아 Pro가 됩니다. iPhone 화면별 도움말은 사용 설명서에 있습니다.

Mac: Mac App Store에서 앱을 받으세요. Android: 앱은 준비 중이며 아직 이용할 수 없습니다.

막히셨나요? 지원 및 FAQ를 확인하거나 support@localgatekeys.app로 이메일을 보내 주세요.
