시작하는 방법

암호화된 사본이 갈 곳은 내가 정합니다

모든 기기는 자체 암호화된 보관함을 유지합니다. 직접 설정하지 않으면 어떤 것도 기기를 벗어나지 않습니다. PC와 iPhone 간 동기화는 Pro에 포함됩니다.

  • 어디로도 보내지 않음

    모든 에디션의 기본값

    보관함은 기기에 머뭅니다. 예약 백업은 암호화된 파일이며 USB 드라이브나 동기화 폴더 등 원하는 곳에 보관할 수 있습니다.

  • 집 Wi-Fi

    Pro

    일회용 QR 코드로 PC와 iPhone을 한 번 페어링합니다. 같은 네트워크에서 잠금이 해제되어 있으면 암호화된 연결로 서로 직접 동기화합니다. 인터넷 연결은 사용되지 않습니다.

  • 내 클라우드 폴더

    Pro, 켜는 경우

    이미 사용 중인 Dropbox나 iCloud Drive 같은 클라우드 폴더를 동기화 위치로 지정하고 동기화 비밀번호로 보호하세요. 클라우드 제공업체는 읽을 수 없는 암호화된 파일을 저장합니다. 저희는 전혀 관여하지 않습니다.

매일 쓰기 좋은 기능

  • Chrome과 Edge에서 로그인을 채웁니다

    브라우저 확장 프로그램은 작은 로컬 도우미를 통해 PC의 LocalGateKeys 앱과 통신합니다. 현재 사이트와 정확히 일치하는 저장된 로그인만 제안합니다. 2단계 인증 코드, 주소, 결제 카드도 채우며, 로그인한 후 새 로그인을 저장하도록 제안합니다.

    패스키도 작동합니다: 웹사이트가 패스키를 보관함에 저장하고 그 패스키로 로그인할 수 있으며, 각각 데스크톱 앱에서 직접 승인합니다.

    확장 프로그램은 보관함 전체를 받지 않으며, 어떤 요청도 컴퓨터 밖으로 나가지 않습니다.

  • Windows 앱에서도

    데스크톱 앱 채우기는 게임 런처 같은 Windows 프로그램의 로그인 창에서 작동합니다. 창을 한 번 바인딩하면 비밀번호 필드 옆의 채우기 버튼이나 단축키로 저장된 필드를 채웁니다.

    Windows가 창에 대해 제공하는 접근성 정보만 읽습니다. 키 입력을 기록하지 않고, 다른 프로그램에 코드를 주입하지 않으며, 앱이나 창이 바뀌었다면 채우기를 거부합니다.

  • 2단계 인증 코드 내장 Pro

    사이트의 2단계 인증 설정 키를 로그인과 함께 저장하면 현재 코드가 로그인 상단과 홈의 일회용 코드 카드에 표시됩니다. 스크린샷이나 웹캠으로 사이트의 QR 코드를 스캔하거나 Google Authenticator에서 코드를 옮겨 올 수 있습니다. iPhone에서는 선택한 코드를 Apple Watch에 표시할 수 있습니다.

    코드는 내 기기에서 계산됩니다. 2단계 인증 코드는 Pro에 포함됩니다.

  • 비밀번호를 점검합니다

    생성기는 강력한 비밀번호나 암호 문구를 만듭니다. 비밀번호 상태는 저장된 비밀번호 중 취약하거나, 재사용되었거나, 오래되었거나, 2단계 인증 코드가 없는 것을 알려 주며, iPhone 앱은 같은 점검에 점수를 매깁니다. 켜면 직접 시작하는 유출 확인이 알려진 유출 목록과 비교하며, 이때 해시의 다섯 글자만 전송됩니다.

  • iPhone에서도

    iPhone 앱은 Safari와 다른 앱에서 로그인을 채우고, iOS 18 이상에서는 모든 텍스트 필드에서 카드와 신원 정보도 채웁니다. 보안 점검, 비밀번호 기록, 만료 알림, 실행 취소가 있는 최근 삭제된 항목을 제공하며, Face ID, Touch ID 또는 선택 사항인 앱 비밀번호로 열립니다.

    PC와 동기화되며, iPhone에서 Pro를 구매하면 Windows도 잠금 해제됩니다.

  • 항목 하나를 안전하게 공유

    로그인이나 메모를 파일 또는 QR 코드로 보내세요. 여섯 단어 코드로 잠기며, 이 코드는 전화 같은 다른 방법으로 상대방에게 알려 줍니다.

    한 번만 열 수 있고, 코드를 세 번 틀리면 파기됩니다.

처음 7개 항목은 무료

Free 에디션에는 브라우저 및 Windows 앱 채우기, 패스키, Windows Hello, 복구 문구, 안전한 공유, 가져오기, 예약 암호화 백업이 있으며, 항목은 기간 제한 없이 7개까지입니다. Pro는 항목 무제한, 동기화, 2단계 인증 코드(Apple Watch 포함), 문서를 더합니다.
