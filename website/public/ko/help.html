모든 화면과 기능에 대한 단계별 도움말입니다. 기기를 선택한 다음 주제로 이동하십시오. 모든 제목은 공유할 수 있는 링크입니다.

모든 기기에서 알아 두면 좋은 점

  • 보관함은 사용자의 기기에만 있습니다. 계정이 없으며 비밀번호를 보관하는 LocalGateKeys 서버도 없습니다.
  • 마스터 비밀번호나 앱 비밀번호는 누구도 재설정할 수 없습니다. 복구 문구를 설정하고 종이에 적어 보관하십시오.
  • Free는 항목을 최대 4개까지 보관합니다. Pro(US$4.99, 한 번 결제)는 무제한 항목, 2단계 인증 코드, 파일, 동기화를 제공합니다. 이미 있는 항목의 편집, 삭제, 입력은 절대 차단되지 않습니다.

처음 시작과 프로필

  1. LocalGateKeys를 엽니다. 12자 이상의 마스터 비밀번호를 입력하고 비밀번호 확인에 다시 입력한 다음 보관함 만들기를 선택합니다.
  2. 이어서 LocalGateKeys 설정 가이드가 다섯 단계로 진행됩니다. 보관함 만들기, Windows Hello 설정, 비밀번호 가져오기, 복구 문구 열기(저장했음을 확인하기 위해 단어 세 개를 다시 입력), 브라우저 확장 프로그램의 연결 테스트입니다.
  3. 모든 단계는 건너뛰기할 수 있습니다. 건너뛴 단계는 보관함의 설정 마무리 카드에 남아 있으며 설정 계속과 숨기기가 있습니다.

팁. 가이드를 다시 보려면 설정 › 도움말 및 진단 › 설정 다시 보기를 선택합니다.

프로필

각 프로필은 자체 마스터 비밀번호가 있는 별도의 보관함입니다. 예를 들어 업무용과 가정용으로 나눌 수 있습니다.

  • 잠금 해제 화면에서 다른 프로필 사용을 선택한 다음 프로필 만들기를 선택하고 프로필 이름을 입력합니다.
  • 프로필을 편집하려면 Ctrl+K를 누르고 프로필 전환을 실행합니다. 여기에서 프로필 추가, 편집, 사진… 및 강조 색상 설정, 제거를 할 수 있습니다.
  • 트레이 메뉴의 잠그고 사용자 전환은 잠근 후 바로 프로필 선택으로 이동합니다.

잠금 해제와 잠금

잠금 해제 방법

  • 마스터 비밀번호를 입력한 다음 잠금 해제. 항상 작동합니다.
  • Windows Hello로 잠금 해제: 지문, 얼굴 또는 PIN. 설정 › 잠금 해제 › Windows Hello › 설정에서 설정합니다. Windows Hello 자동 시작을 켜면 창이 열리자마자 확인 창이 표시됩니다.
  • 대신 카메라 사용: 일반 웹캠을 이용한 얼굴 대조로, PC에서 처리됩니다. Windows Hello보다 덜 안전합니다. 카메라 확인 설정으로 설정합니다.

마스터 비밀번호를 잊으셨습니까?

  1. 잠금 해제 화면에서 잊으셨습니까? 복구 문구 사용을 선택합니다.
  2. 24개 단어를 공백으로 구분하여 입력합니다.
  3. 새 마스터 비밀번호(12자 이상)를 정하고 두 번 입력한 다음 보관함 복구를 선택합니다.

그 후 Windows Hello와 카메라 확인을 다시 설정합니다. 복구 문구는 계속 사용할 수 있습니다.

마스터 비밀번호 변경

설정 › 잠금 해제 › 마스터 비밀번호 › 변경…. 현재 비밀번호와 새 비밀번호(두 번)를 입력합니다. 이미 만든 백업은 만들 때의 비밀번호를 유지합니다.

잠금

  • 상단 막대의 잠금 버튼 또는 Ctrl+L.
  • 긴급 잠금: Windows 어디서나 Ctrl+Alt+L. 즉시 잠그고 진행 중인 입력을 취소합니다.
  • 설정 › 잠금:
    • 비활성 후 잠금: 안 함 또는 1분에서 24시간.
    • Windows가 잠기면 잠금(Win+L, 사용자 전환, 로그아웃) 및 절전 시 잠금(덮개 닫기, 절전, 최대 절전).
    • 잠금 해제 상태 최대 시간: 무엇을 하고 있든 적용되는 고정 제한입니다.
    • 활동 기준: 컴퓨터 활동 또는 보관함 활동.
    • 브라우저 확장 프로그램에 2FA 코드를 전달하기 전에 확인.

트레이 아이콘 메뉴에는 보관함 잠금 해제, 보관함 잠그기, 빠른 액세스, 종료가 있습니다.

세부 정보 창

선택한 항목의 필드를 표시합니다. 비밀번호는 클릭할 때까지 숨겨져 있습니다. 버튼으로 사용자 이름, 비밀번호, 2FA 코드를 복사하고, 웹사이트를 열고, 편집, 공유, 휴지통으로 이동할 수 있습니다. 문서에는 파일 열기, 안전한 미리 보기, 사본 저장…, 파일 바꾸기…가 추가됩니다.

항목 추가 및 편집

  1. 새 항목을 선택하거나 Ctrl+N을 누릅니다.
  2. 유형을 선택합니다(클릭, 번호 누르기 또는 이름 입력):
    • 로그인: 웹사이트 로그인, 데스크톱 앱 로그인, 패스키
    • 개인: 결제 카드, 은행 계좌, 신원 정보, 보안 메모, 문서, Wi-Fi 네트워크
    • 소유물: 라이선스, 구매, 보증, 구독, 북마크
  3. 필드를 입력하고 저장을 선택합니다. 저장하지 않은 변경 사항이 있는 상태로 나가면 변경 사항을 삭제하시겠습니까?라고 묻습니다.

로그인 자세히 보기

  • 제목, 웹사이트, 사용자 이름, 비밀번호, 메모.
  • 비밀번호 옆의 변경은 생성기로 새 비밀번호를 만듭니다. 웹사이트에서도 변경한 다음 저장하십시오.
  • 2단계 인증: 사이트의 설정 키를 여기에 붙여 넣습니다(Pro). 2단계 인증 코드를 참조하십시오.
  • 사용자 지정 필드: 그 밖의 정보는 필드 추가로 입력합니다. 필드를 숨김으로 표시하면 비밀번호처럼 취급됩니다.
  • 비밀번호 기록: 이전 비밀번호는 암호화되어 1년간 보관됩니다. 이전 비밀번호 복사 또는 이 비밀번호 복원.
  • 복구 코드: 한 줄에 하나씩. 다음 코드 복사 후 사용은 하나를 복사하고 목록에서 제거합니다.
  • 자동 입력 규칙: 입력(기본값, 클릭 시, 안 함), 입력 후 로그인, 항상 마스터 비밀번호 요청, 브라우저의 변경 사항 저장 제안.

기타 유형

각 유형에는 고유한 필드가 있습니다. 날짜는 YYYY-MM-DD 형식으로 입력합니다. 모든 항목은 즐겨찾기로 지정하고 태그(쉼표로 구분)를 달 수 있습니다. 문서는 파일 선택 후 저장을 사용합니다(Pro).

컬렉션과 미리 알림

  • 컬렉션으로 항목을 원하는 대로 묶을 수 있습니다: 컬렉션 추가, 이름 바꾸기, 보관. 이 PC에만 저장되며 동기화되지 않습니다.
  • 미리 알림에는 곧 만료되거나 기한이 지난 항목이 완료 및 1일 후 다시 알림과 함께 표시됩니다.
  • 활동에는 보관함에서 일어난 일의 기록이 표시됩니다.

삭제, 휴지통, 실행 취소

  1. 항목을 선택하고 휴지통으로 이동을 선택하거나 Delete를 누릅니다.
  2. 실행 취소가 있는 메시지가 나타납니다. 클릭하면 항목이 바로 돌아옵니다.
  3. 나중에 도구 › 휴지통을 열고 선택 항목 복원, 선택 항목 삭제, 휴지통 비우기를 사용합니다. 휴지통에서 삭제하면 되돌릴 수 없습니다.

설정 › 개인 정보 › 삭제한 항목 보관 기간에서 7, 14, 30, 90일을 선택하고, 휴지통 자동 비우기로 자동으로 비울 수 있습니다.

검색, 명령 팔레트, 빠른 액세스

  • 검색: Ctrl+F를 누르고 입력한 다음 Enter로 첫 결과를 열거나 ↓로 목록으로 이동합니다.
  • 명령 팔레트: Ctrl+K로 항목과 작업을 찾습니다. >로 시작하면 작업만(지금 백업, 비밀번호 생성, 지금 잠그기, 동기화 상태…), #는 태그, @는 컬렉션을 찾습니다.
  • 빠른 액세스: Windows 어디서나 Ctrl+Alt+K를 누르면 로그인, 메모, 북마크를 찾는 작은 검색 창이 열립니다. 단축키는 설정 › 자동 입력 › 빠른 액세스에서 변경합니다.

비밀번호 생성기

홈의 생성기 카드, 로그인의 변경, 또는 Ctrl+K › 비밀번호 생성에서 엽니다.

  • 무작위: 길이와 대문자 및 기호 사용 여부를 선택합니다.
  • 암호 문구: 단어 수를 선택합니다. 입력하기 쉽고, 충분히 길면 똑같이 강력합니다.
  • 다시 생성으로 새로 만들고 복사로 복사합니다.

보안 센터와 비밀번호 상태

도구 › 보안 센터에는 먼저 고쳐야 할 항목이 표시됩니다. 약하거나 재사용되거나 오래되거나 유출된 비밀번호와 2FA를 사용할 수 있는 로그인입니다.

  • 모두 유출 확인은 비밀번호를 Have I Been Pwned 목록과 비교합니다. PC 밖으로 나가는 것은 해시의 처음 5자뿐이며 비밀번호는 절대 나가지 않습니다.
  • 유출 확인은 설정 › 개인 정보 › 유출 확인을 켤 때까지 꺼져 있습니다. 엄격한 오프라인 모드는 유출 확인, 웹사이트 아이콘 및 기타 모든 네트워크 요청을 차단합니다.
  • 비밀번호 상태에서 항목 열기 또는 비밀번호 변경으로 항목을 수정합니다.

2단계 인증 코드와 QR 스캔 Pro

LocalGateKeys는 사이트가 비밀번호 다음에 요구하는 6자리 코드를 표시할 수 있으므로 별도의 인증 앱이 필요 없습니다.

  1. 웹사이트에서 2단계 인증/인증 앱 로그인을 켜서 QR 코드가 표시되게 합니다.
  2. LocalGateKeys에서 도구 › QR 코드 스캔을 선택합니다. 다음 세 가지 방법 중 하나로 이미지를 가져옵니다.
    • 스크린샷 붙여넣기: Win+Shift+S를 누르고 QR 코드를 선택한 다음 Ctrl+V를 누릅니다.
    • 이미지 선택…(PNG, JPEG, BMP)하거나 이미지를 끌어다 놓습니다.
    • 웹캠 사용을 선택하고 코드가 표시된 휴대폰 화면을 웹캠에 비춥니다.
  3. 해당하는 로그인 또는 새 로그인을 선택한 다음 편집기에서 열기와 저장을 선택합니다.
  4. 웹사이트에 현재 코드를 입력하여 2FA 설정을 마칩니다.

설정 키나 otpauth:// 링크를 로그인의 2단계 인증 섹션에 바로 붙여 넣을 수도 있습니다.

Google Authenticator에서 옮기기

  1. Google Authenticator에서 계정 이전 › 내보내기를 선택합니다.
  2. 표시된 QR 코드를 스캔합니다(코드가 여러 개이면 각각 스캔: "코드 3개 중 1개 스캔됨").
  3. 계정을 선택하고 기존 로그인에 추가 또는 새 로그인을 선택한 다음 추가를 선택합니다. 중복은 건너뜁니다.

이렇게 만든 새 로그인에는 needs-password 태그가 붙습니다. 실제 비밀번호는 나중에 입력하십시오. 이미지는 메모리에서만 읽히며 저장되지 않습니다. Free에서는 이미 있는 코드는 계속 작동하지만 추가하거나 변경하려면 Pro가 필요합니다.

다른 비밀번호 관리자에서 가져오기

  1. 이전 앱에서 비밀번호를 내보냅니다(아래 목록 참조).
  2. LocalGateKeys에서 도구 › 가져오기 및 내보내기 › 비밀번호 및 항목 가져오기…를 열고 파일을 선택합니다. 형식은 자동으로 인식됩니다. 암호화된 파일은 가져오기 비밀번호를 요청합니다.
  3. 알 수 없는 앱의 일반 CSV는 열 선택을 표시합니다. 어떤 열이 제목, 사용자 이름, 비밀번호 등인지 지정합니다.
  4. 각 행을 검토합니다: 추가, 건너뛰기, 바꾸기, 병합, 둘 다 유지. 새 항목 모두 추가, 충돌 모두 바꾸기, 모두 건너뛰기로 한 번에 처리할 수 있습니다.
  5. 가져오기를 선택합니다. 모두 한 번에 들어가며, 하나라도 실패하면 아무것도 기록되지 않습니다.

백업과 복원

  2. 예약 백업: 매일 또는 매주, 시간과 요일을 지정합니다.
  3. 클라우드 사본 › 선택…에서 USB 드라이브나 두 번째 디스크 같은 폴더를 골라 두 번째 사본을 만듭니다.
  4. 이전 예약 백업: 최신 백업만 유지하거나, 최신 백업과 그 이전 백업을 유지합니다.

백업은 보관함이 잠금 해제되어 있을 때만 실행됩니다. 앱이 닫혀 있어 놓친 백업은 다음 잠금 해제 때 실행됩니다.

백업 및 복원 페이지

백업 및 복구 카드, Ctrl+K, 또는 잠금 해제 화면의 백업 및 복원에서 엽니다.

  • 백업 만들기: 자체 비밀번호가 있는 암호화된 .lgk 파일.
  • 백업 확인: 보관함을 건드리지 않고 파일이 열리는지 확인합니다.
  • 백업 복원: 백업 비밀번호와 백업 당시의 마스터 비밀번호가 필요합니다. 새 프로필로 복원할 수도 있습니다.
  • 복원 테스트: 임시 사본을 열어 백업이 작동하는지 확인한 다음 테스트 사본 삭제를 선택합니다.
  • 복구 문구(설정 / 교체…)와 인쇄용 시트인 복구 키트 만들기.

휴대폰 백업 복원

가져오기 및 내보내기 › 휴대폰 백업 복원…에서 iPhone 또는 Android 앱의 .lgkm 파일을 선택하고, 비밀번호를 입력한 뒤 미리 보기, 복원을 선택합니다. 항목은 보관함에 추가되며 아무것도 지워지지 않습니다.

기기 간 동기화 Pro

동기화는 잠금 해제 상태에서만 실행됩니다. 잠금 해제할 때, 5분마다, 변경 후 몇 초 뒤에 실행됩니다. 두 가지 방법이 있으며 둘 다 사용할 수 있습니다.

Wi-Fi(같은 네트워크의 휴대폰 또는 다른 PC)

  1. 도구 › 동기화 › Wi-Fi 동기화 켜기…. 제안된 주소와 포트(47821)를 그대로 두고, 요청되면 Windows 방화벽에서 허용을 선택합니다.
  2. QR 코드 표시…를 선택합니다. 코드는 120초 동안 한 번만 작동합니다.
  3. 휴대폰 앱의 동기화 탭에서 스캔합니다. 다른 PC의 경우 코드 텍스트 복사를 선택하고 그 PC에서 QR 텍스트로 참여…를 사용합니다.
  4. 두 기기에 6자리 코드가 표시됩니다. 일치할 때만 수락을 선택하고, 그렇지 않으면 거절을 선택합니다.
  5. 페어링 직후 실수였다면 실행 취소로 새 기기를 제거할 수 있습니다.

PC 주소가 바뀌면 휴대폰에서 다시 찾기를 선택합니다.

클라우드 폴더(Dropbox, iCloud Drive…)

  1. 첫 번째 기기에서: 동기화 그룹 만들기…를 선택하고, 클라우드 앱이 동기화하는 폴더를 고른 뒤 강력한 동기화 비밀번호(12자 이상)를 설정합니다.
  2. 다른 각 기기에서: 폴더에 참여…를 선택하고 LocalGateKeys Sync가 있는 폴더를 고른 뒤 동기화 비밀번호를 입력합니다.

클라우드에는 암호화된 파일만 보입니다.

OneDrive와 Google Drive는 Apple 관련 문제가 해결될 때까지 현재 동기화에 사용할 수 없습니다. Dropbox, iCloud Drive 또는 Wi-Fi 동기화를 사용하십시오.

동기화 관리

  • 동기화 상태 페이지(사이드바의 동기화 표시를 클릭)에서 지금 동기화.
  • 기기 제거…(새 동기화 비밀번호를 설정), 동기화 비밀번호 변경….
  • 동기화 나가기…는 항목을 유지하고 그룹 정보를 지웁니다. 이 PC에서 동기화 재설정…은 키도 지웁니다(두 번 확인).
  • 한 항목이 두 기기에서 동시에 변경되면 추가 사본의 제목에 (동기화 충돌)이 붙습니다.

PC마다 별도의 Pro 라이선스가 필요합니다. 휴대폰에서 구매한 Pro로 PC를 잠금 해제할 수 있습니다(Pro 라이선스 참조). 컬렉션은 동기화되지 않습니다. 그룹당 최대 16대입니다.

다른 사람과 항목 공유

  1. 항목을 선택하고 공유, 공유 만들기를 차례로 선택합니다.
  2. LocalGateKeys에 여섯 단어로 된 공유 코드가 표시됩니다. 파일로 저장…(.lgkshare) 또는 QR 코드 표시를 선택합니다.
  3. 파일을 보내고, 여섯 단어는 전화나 직접 만나서 등 다른 방법으로 상대방에게 알려 줍니다.

받기: .lgkshare 파일을 두 번 클릭하거나 Ctrl+K › 받은 공유 항목 › 공유 항목 열기…를 선택합니다. 여섯 단어를 입력하고 미리 보기를 확인한 다음 보관함에 저장, 둘 다 유지 또는 거절을 선택합니다. 패스키, 문서, 파일이 첨부된 항목은 공유할 수 없습니다.

  3. 사이트에 계정이 여러 개 있으면 계정 선택에서 하나를 고릅니다.
  4. 보관함이 잠겨 있으면 LocalGateKeys 창이 나타날 때 잠금을 해제합니다.

로그인에 입력 후 로그인이 켜져 있으면 양식이 자동으로 제출됩니다. 특이한 양식에서는 자동 로그인을 건너뛰었습니다가 표시되므로 사이트의 로그인 버튼을 클릭하면 됩니다.

새 로그인 또는 변경된 로그인 저장

  1. 평소처럼 웹사이트에 로그인합니다.
  2. 확장 프로그램이 이 로그인을 저장하시겠습니까?라고 묻습니다(또는 변경된 비밀번호 업데이트를 제안합니다).
  3. 보관함에 저장을 선택하고 LocalGateKeys 창에서 확인합니다. 또는 나중에나 이 사이트에서 사용 안 함을 선택합니다.

직접 저장하려면 양식을 작성하고 확장 프로그램 창에서 로그인 저장을 선택합니다. 사이트의 확인을 다시 켜려면 확장 프로그램 창의 스위치를 사용합니다.

2FA 코드 입력

사이트에서 6자리 코드를 요구하면 코드 상자의 LocalGateKeys 아이콘(LocalGateKeys로 2FA 코드 입력)을 클릭합니다. 페이지에는 현재 코드만 전달되며 설정 키는 절대 전달되지 않습니다. 코드가 곧 만료되면 확장 프로그램이 새 코드를 잠시 기다립니다.

로그인에 2FA 설정 키가 앱에 저장되어 있어야 합니다(2단계 인증 코드 참조). 설정 › 잠금 › 2FA 코드를 전달하기 전에 확인이 켜져 있으면 매번 앱에서 확인합니다.

카드와 신원 정보

  1. 결제 또는 주소 양식에서 필드의 아이콘을 클릭하거나 카드 입력… / 신원 정보 입력을 선택합니다.
  2. 카드나 신원 정보를 선택합니다.
  3. 입력할 필드를 선택합니다. 보안 코드(CVV)는 기본적으로 선택되어 있지 않으므로 필요할 때만 선택하십시오.
  4. 검토 후 승인을 선택한 다음 LocalGateKeys 창에서 승인합니다.

가입 페이지에서 비밀번호 만들기

가입 또는 비밀번호 변경 양식에서 비밀번호 생성을 선택합니다. 새 비밀번호가 새 비밀번호 입력란에 들어갑니다. 페이지를 떠나기 전에 저장 확인이나 로그인 저장으로 저장하십시오.

패스키

사이트에서 패스키 생성이나 사용을 제안하면 LocalGateKeys가 처리하여 패스키를 보관함에 보관할 수 있습니다. 앱의 설정 › 자동 입력 › 패스키에 LocalGateKeys 제안에서 켜거나 끕니다. 처리할 수 없는 경우에는 브라우저 자체의 패스키 창이 대신 나타납니다.

처음 시작과 잠금 해제

만들 비밀번호가 없습니다. 보관함은 휴대폰과 마찬가지로 Face ID, Touch ID 또는 iPhone 암호로 열립니다. (iPhone에 암호가 설정되어 있어야 합니다.)

  1. 앱을 열고 잠금 해제를 탭합니다.
  2. 간단한 설정이 이어집니다: Face ID로 잠금 해제, 비밀번호 가져오기, 앱 비밀번호 추가(선택 사항), 자동 완성 켜기.

앱 비밀번호와 복구 문구

iPhone 암호 대신 LocalGateKeys를 여는 선택적 추가 비밀번호입니다. 다른 사람이 암호를 알고 있을 때 유용합니다.

  1. 설정 › 앱 비밀번호 › 앱 비밀번호 사용을 켭니다.
  2. 강력한 비밀번호를 정합니다.
  3. 24단어 복구 문구를 적어 두고 적어 두었습니다를 탭한 다음 요청한 세 단어를 입력합니다.
  4. 원하면 Face ID로 잠금 해제를 바로 가기로 유지할 수 있습니다.

잊으셨습니까? 잠금 해제 화면에서 앱 비밀번호를 잊으셨습니까?를 탭하고 24단어를 입력한 다음 새 앱 비밀번호를 정합니다.

iPhone에 새 얼굴이나 지문을 추가하면 안전을 위해 Face ID 바로 가기가 꺼집니다. 앱 비밀번호를 한 번 입력하고 다시 켜십시오.

  • 삭제: 항목이 최근 삭제된 항목으로 이동하며 몇 초 동안 실행 취소할 수 있습니다. 설정 › 데이터 › 최근 삭제된 항목에서 복원 또는 영구 삭제할 수 있습니다.

2단계 인증 코드 Pro

  1. 웹사이트에서 인증 앱 2FA를 켜서 QR 코드가 표시되게 합니다.
  2. LocalGateKeys에서 QR 코드 스캔을 선택합니다(> 또는 로그인의 2FA 필드에서). 카메라 사용 또는 사진에서 선택(스크린샷의 경우)을 탭합니다.
  3. 코드는 일치하는 로그인으로 들어가거나, 저장할 준비가 된 새 로그인이 열립니다.

코드는 항목과 보관함의 코드 행에 표시됩니다. 로그인의 2FA 비밀 키 필드에 설정 키를 붙여 넣을 수도 있습니다. Google Authenticator 내보내기(계정 이전)도 여러 부분으로 나뉜 것을 포함해 사용할 수 있습니다.

설정 › 자동 완성의 옵션:

  • QuickType 막대에 로그인 표시: 키보드 위에 제안을 표시합니다.
  • 입력 시 2FA 코드 복사: 다음 화면에서 코드를 붙여 넣을 수 있습니다. 60초 후 지워집니다.

카드와 연락처 정보도 같은 방식으로 입력됩니다. https 사이트에 저장된 로그인은 일반 http 페이지에서는 제안되지 않습니다.

패스키

PC 또는 Mac과 동기화 Pro

Wi-Fi로

  1. PC 또는 Mac에서 동기화를 열고 QR 코드 표시를 선택합니다.
  2. iPhone에서 동기화 탭을 열고 120초 안에 QR 코드 스캔을 탭합니다. (처음에는 로컬 네트워크 접근을 허용합니다.) 카메라가 없으면 코드 텍스트 붙여넣기를 탭하고 컴퓨터의 코드 텍스트 복사로 얻은 텍스트를 붙여 넣습니다.

두 기기가 같은 Wi-Fi에 있고 잠금 해제되어 있으면 동기화됩니다. 지금 동기화로 강제로 실행하고, 컴퓨터 주소가 바뀌었다면 다시 찾기가 도움이 됩니다.

OneDrive와 Google Drive는 Apple 관련 문제가 해결될 때까지 현재 동기화에 사용할 수 없습니다. Dropbox, iCloud Drive 또는 Wi-Fi 동기화를 사용하십시오.

잠금 해제와 잠금

  • Touch ID: 설정 › 잠금 해제 › Touch ID로 잠금 해제. 지문을 변경하면 마스터 비밀번호를 한 번 사용하십시오.
  • 마스터 비밀번호 변경: 설정 › 잠금 해제. 항목은 그대로 유지됩니다.
  • 복구 문구: 복구 센터에서 설정하고 세 단어를 확인합니다. 마스터 비밀번호를 잊으면 잠금 화면에서 마스터 비밀번호를 잊으셨습니까? › 복구 문구로 복구를 선택합니다.
  • 잠금: ⌘L. 설정 › 잠금에서 유휴 시 잠금, 화면과 함께 잠금, 잠자기 시 잠금, 최대 세션 시간을 설정합니다.

항목

  • 새 항목(⌘N)은 iPhone과 같은 유형에 파일 첨부…(Pro)가 추가됩니다.
  • ⌘C(비밀번호), ⇧⌘C(사용자 이름), ⌘T(2FA 코드)로 복사합니다.
  • 사용자 지정 필드용 필드 추가, 태그, 컬렉션(이 Mac에만 저장).
  • ⌫는 항목을 최근 삭제된 항목으로 옮깁니다. 거기에서 선택 항목 복원 또는 휴지통 비우기를 사용합니다.
  • 첨부 파일은 Touch ID나 마스터 비밀번호 확인 후 훑어보기로 열립니다.
  • 생성기: 무작위 비밀번호(문자 집합 선택, 비슷한 문자 피하기) 또는 암호 문구(대문자 사용, 숫자 추가, 구분자).

자동 완성, 패스키, Safari

  1. 기기 및 연결을 엽니다.
  2. 자동 완성 설정 열기를 선택하고 시스템 설정 › 자동 완성 및 암호에서 LocalGateKeys를 켭니다.
  3. Safari 설정 열기를 선택하고 Safari › 설정 › 확장 프로그램에서 LocalGateKeys 확장 프로그램을 켭니다.

이제 비밀번호, 패스키, 2FA 코드가 Safari와 앱에서 입력됩니다. Safari에서의 새 로그인은 저장하도록 제안되며 다음 잠금 해제 때 검토합니다. 다른 브라우저는 아직 Mac에서 지원되지 않습니다.

처음 시작과 잠금 해제

보관함은 휴대폰의 지문, 얼굴 또는 화면 잠금으로 열립니다. (휴대폰에 화면 잠금이 있어야 합니다.) 간단한 설정이 이어집니다: 지문으로 잠금 해제, 자동 완성 설정 열기, 가져오기…, 선택 사항인 앱 비밀번호. 어떤 단계든 건너뛸 수 있으며, 설정 마무리 카드로 돌아올 수 있습니다.

설정 › 보안에서 앱을 나가면 자동 잠금(즉시부터 1시간까지 또는 안 함)을 설정하고 지금 잠그기를 사용할 수 있습니다. 앱은 최근 앱 화면에서 숨겨집니다.

앱 비밀번호와 복구 문구

  1. 설정 › 앱 비밀번호 켜기에서 비밀번호를 정합니다. 그때부터는 화면 잠금이 아니라 이 비밀번호로 LocalGateKeys를 엽니다.
  2. 24단어 복구 문구를 적어 두고 적어 두었습니다를 탭한 다음 요청한 단어를 입력합니다.

잊으셨습니까? 앱 비밀번호를 잊으셨습니까?를 탭하고 24단어를 입력한 다음 새 비밀번호를 정합니다. 변경과 끄기는 설정에 있습니다.

Google 백업에서 휴대폰을 복원한 후에는 보관함을 열 수 없습니다(키가 백업되지 않기 때문입니다). 새로 시작을 선택한 다음 PC와 동기화하여 모든 것을 되찾으십시오.

자동 입력

  1. 설정 › 자동 완성 › 자동 완성 설정 열기에서 LocalGateKeys를 선택합니다. (열리지 않으면 휴대폰 설정에서 자동 완성 서비스를 검색하십시오.)
  2. 앱이나 웹사이트에서 로그인 상자를 탭하고 제안 목록에서 로그인을 선택합니다. 요청하면 잠금을 해제합니다.
  3. 새로운 곳에 로그인한 후 로그인을 저장하시겠습니까?에서 저장을 선택하거나, 비밀번호가 바뀌었다면 비밀번호 업데이트를 선택합니다.

패스키

설정 › 패스키에 LocalGateKeys 제안을 켭니다. 사이트나 앱이 패스키를 제안하면 LocalGateKeys를 선택하고, 이후에는 패스키 사용으로 로그인합니다.

가져오기

다른 앱에서 가져오기 ›내보낸 파일 선택: Chrome, Edge, Brave, Firefox, Apple 암호, Bitwarden .json(비밀번호로 보호된 파일 포함), 1Password .1pux 또는 모든 CSV. 모두 검토한 다음 가져옵니다. 그 후 내보낸 파일을 삭제하십시오.

백업

백업 내보내기…는 직접 정한 비밀번호(복구할 수 없음)로 암호화한 .lgkm 파일을 저장합니다. 백업에서 복원…은 파일을 열어 미리 보기를 표시하며 더 최신 항목을 덮어쓰지 않습니다. PC 및 iPhone과도 작동합니다.

PC와 동기화 Pro

  1. PC의 Wi-Fi 카드에서 QR 코드 표시를 선택합니다.
  2. 휴대폰에서 동기화 탭 › QR 코드 스캔(또는 코드 텍스트 붙여넣기).
  3. 두 기기에 같은 코드가 표시되는지 확인하고 PC에서 수락합니다.

또는 동기화 비밀번호로 Dropbox나 Nextcloud에서 폴더에 참여…합니다. PC에도 Pro가 필요합니다.

OneDrive와 Google Drive는 Apple 관련 문제가 해결될 때까지 현재 동기화에 사용할 수 없습니다. Dropbox, Nextcloud 또는 Wi-Fi 동기화를 사용하십시오.

공유

항목 열기 › 이 항목 공유 › 파일로 보내기… 또는 QR 코드로 표시를 선택하고, 여섯 단어는 따로 알려 줍니다. 받기: 공유 항목 받기에서 여섯 단어를 입력한 다음 보관함에 추가를 선택합니다. 공유는 24시간 안에 한 번만 열 수 있으며, 코드를 세 번 틀리면 삭제됩니다. 패스키와 파일은 공유할 수 없습니다.

설정과 Pro

  • 모양: 시스템, 라이트 또는 다크, 그리고 이니셜.
  • 보안: 탭할 때까지 비밀번호 숨기기, 클립보드 지우기 시간, 이 휴대폰의 보관함 지우기(이 휴대폰만).
  • Pro: Google Play에서 한 번 구매하고, 같은 Google 계정의 다른 휴대폰에서 구매 항목 복원, 키 복사로 Windows도 잠금 해제합니다.
