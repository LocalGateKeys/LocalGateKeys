LocalGateKeys로 갈아타기

지금 쓰는 비밀번호 관리자를 고르세요. 각 안내에서 내보내기 방법, LocalGateKeys로 가져오는 방법, 옮겨지지 않는 항목을 설명합니다.

  • 1Password
  • Bitwarden
  • LastPass
  • Dashlane
  • Enpass
  • KeePass
  • Proton Pass
  • NordPass
  • Apple Passwords
  • Google Password Manager
  • Microsoft Authenticator

패스키는 CSV 내보내기로 옮겨지지 않습니다. LocalGateKeys는 CXF 파일(Apple 암호 앱 및 CXF로 내보내는 다른 앱)에서 패스키를 가져오며, PC, Android, iPhone, Mac에서 지원됩니다.

LocalGateKeys Pro는 US$29.99 한 번 결제입니다. 결제는 한 번. 모든 업데이트, 영원히, 무료. 무료 버전은 최대 7개 항목까지, 기간 제한 없이 사용할 수 있습니다.

LocalGateKeys

보관함을 내 기기에 두는 Windows, Mac 및 iPhone용 비밀번호 관리자입니다.

이 웹사이트는 쿠키를 사용하지 않는 Cloudflare Web Analytics로 페이지 방문 수를 집계합니다. 광고 추적기를 사용하지 않으며 쿠키를 설정하지 않습니다.
