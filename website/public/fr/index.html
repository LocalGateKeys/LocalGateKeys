Comment démarrer

Vous décidez où vont les copies chiffrées

Chaque appareil conserve son propre coffre-fort chiffré. Rien ne quitte un appareil sauf si vous l’avez configuré ainsi. La synchronisation entre votre PC et votre iPhone fait partie de Pro.

  • Nulle part

    Le réglage par défaut, dans toutes les éditions

    Le coffre-fort reste sur votre appareil. Les sauvegardes planifiées sont des fichiers chiffrés que vous gardez où vous voulez, y compris sur une clé USB ou dans un dossier de synchronisation.

  • Votre Wi-Fi domestique

    Pro

    Associez votre PC et votre iPhone une fois avec un code QR à usage unique. Lorsqu’ils sont sur le même réseau et déverrouillés, ils se synchronisent directement via une connexion chiffrée. Aucune connexion Internet n’est impliquée.

  • Votre propre dossier cloud

    Pro, si vous l’activez

    Faites pointer la synchronisation vers un dossier cloud que vous utilisez déjà, comme Dropbox ou iCloud Drive, protégé par un mot de passe de synchronisation. Votre fournisseur cloud stocke des fichiers chiffrés qu’il ne peut pas lire. Nous n’intervenons pas du tout.

Ce qu’il fait pour vous chaque jour

  • Remplit les connexions dans Chrome et Edge

    L’extension de navigateur communique avec l’app LocalGateKeys de votre PC par l’intermédiaire d’un petit assistant local. Elle ne propose que les identifiants enregistrés pour le site précis où vous vous trouvez. Elle remplit aussi les codes à deux facteurs, les adresses et les cartes de paiement, et propose d’enregistrer les nouveaux identifiants après votre connexion.

    Les clés d’accès fonctionnent aussi : un site web peut enregistrer une clé d’accès dans votre coffre-fort et vous connecter avec elle, et vous approuvez chacune dans l’app de bureau.

    L’extension ne reçoit jamais l’ensemble de votre coffre-fort, et aucune requête ne quitte votre ordinateur.

  • Et dans les apps Windows

    Le remplissage des apps de bureau fonctionne avec les fenêtres de connexion de programmes Windows comme les lanceurs de jeux. Vous associez une fenêtre une seule fois ; ensuite, un bouton de remplissage à côté du champ de mot de passe, ou un raccourci clavier, remplit les champs enregistrés.

    Il ne lit que les informations d’accessibilité que Windows expose sur une fenêtre. Il n’enregistre jamais vos frappes, n’injecte jamais de code dans un autre programme et refuse de remplir si l’app ou la fenêtre a changé.

  • Codes à deux facteurs intégrés Pro

    Enregistrez la clé de configuration à deux facteurs d’un site avec son identifiant, et le code actuel apparaît en haut de l’identifiant et sur la carte Codes à usage unique de l’Accueil. Scannez le code QR du site depuis une capture d’écran ou votre webcam, ou importez des codes depuis Google Authenticator. Sur iPhone, vous pouvez afficher les codes de votre choix sur votre Apple Watch.

    Les codes sont calculés sur vos propres appareils. Les codes à deux facteurs font partie de Pro.

  • Contrôle de vos mots de passe

    Le générateur crée des mots de passe robustes ou des phrases secrètes. La santé des mots de passe montre quels mots de passe enregistrés sont faibles, réutilisés, anciens ou sans code à deux facteurs, et l’app iPhone donne un score à ce même contrôle. Si vous l’activez, une vérification des fuites que vous lancez les compare aux fuites connues, en n’envoyant que cinq caractères d’une empreinte.

  • Sur votre iPhone aussi

    L’app iPhone remplit les identifiants dans Safari et d’autres apps, ainsi que les cartes et les identités dans n’importe quel champ de texte sous iOS 18 et versions ultérieures. Elle propose un contrôle de sécurité, l’historique des mots de passe, des rappels d’expiration et Supprimés récemment avec Annuler, et elle s’ouvre avec Face ID, Touch ID ou un mot de passe d’app facultatif.

    Elle se synchronise avec votre PC, et l’achat de Pro sur l’iPhone déverrouille aussi Windows.

  • Partagez un élément, en toute sécurité

    Envoyez un identifiant ou une note sous forme de fichier ou de code QR, verrouillé par un code de six mots que vous communiquez à l’autre personne par un autre moyen, par exemple par téléphone.

    Il ne s’ouvre qu’une fois, et trois codes erronés le détruisent.

Gratuit pour vos 7 premiers éléments

L’offre gratuite comprend le remplissage dans le navigateur et dans les apps Windows, les clés d’accès, Windows Hello, une phrase de récupération, le partage sécurisé, les imports et les sauvegardes chiffrées planifiées, pour jusqu’à 7 éléments sans limite de durée.
