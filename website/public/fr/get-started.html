Démarrer

Installez l’app Windows, créez votre coffre-fort, puis ajoutez l’extension de navigateur. Comptez environ cinq minutes, et vous n’avez jamais besoin d’un compte. Ajoutez l’app iPhone quand vous le souhaitez.

1 Installer l’app Windows

LocalGateKeys fonctionne sous Windows 10 (version 2004 ou ultérieure) et Windows 11, 64 bits, et s'obtient sur le Microsoft Store :

  • Microsoft Store. Le Store l’installe et la tient à jour. Ouvrez LocalGateKeys dans le Microsoft Store, choisissez Obtenir, puis Ouvrir.
  • Vous utilisiez l'ancien programme d'installation ? Désinstallez-le dans Paramètres Windows › Applications (Applications installées sous Windows 11, Applications et fonctionnalités sous Windows 10), puis installez depuis le Microsoft Store. Votre coffre reste où il est, et l'app du Store l'ouvre avec le même mot de passe maître.

Obtenir depuis le Microsoft Store Autres téléchargements

2 Créer votre coffre-fort

  1. Ouvrez LocalGateKeys. Au premier démarrage, l’app vous demande de créer un coffre-fort, puis un court guide de configuration propose Windows Hello, l’import, une phrase de récupération et l’extension de navigateur. Ignorez une étape et terminez-la plus tard depuis la carte Terminer la configuration.
  2. Choisissez un mot de passe principal d’au moins 12 caractères. Notez-le et conservez-le dans un endroit sûr. Nous ne l’avons jamais, donc personne ne peut le réinitialiser pour vous.
  3. Ouvrez le Centre de sécurité dans la barre latérale et configurez une phrase de récupération. Conservez-la hors ligne, par exemple sur papier. Elle ouvre le coffre-fort si vous oubliez le mot de passe principal.
  4. Au même endroit, activez Windows Hello si votre PC dispose d’un lecteur d’empreintes, d’une caméra Hello ou d’un code PIN, pour déverrouiller rapidement au quotidien.
  5. Activez les sauvegardes planifiées dans les Paramètres et choisissez où vont les fichiers de sauvegarde chiffrés, par exemple une clé USB ou un dossier que vous sauvegardez déjà.

3 Ajouter l’extension de navigateur

L’extension remplit les connexions dans votre navigateur. Elle ne communique qu’avec l’app LocalGateKeys du même PC ; installez donc d’abord l’app.

  1. Ajoutez l’extension :
    • Microsoft Edge : ouvrez-la dans Modules complémentaires Edge et choisissez Obtenir.
    • Google Chrome : ouvrez-la dans le Chrome Web Store et choisissez Ajouter à Chrome.
    • Mozilla Firefox (Windows) : ouvrez-la dans Modules complémentaires Firefox et choisissez Ajouter à Firefox.
  2. Épinglez-la : ouvrez le menu des extensions du navigateur (l’icône en forme de pièce de puzzle) et épinglez LocalGateKeys à la barre d’outils.
  3. Laissez l’app ouverte et déverrouillée. Allez sur une page de connexion pour laquelle vous avez un identifiant enregistré : l’extension ne propose que les identifiants enregistrés pour ce site précis. Rien n’est rempli tant que vous ne cliquez pas.
  4. Connectez-vous quelque part de nouveau et l’extension propose d’enregistrer l’identifiant.

L’extension indique qu’elle ne peut pas joindre l’app ? Dans l’app, ouvrez Appareils et connexions et choisissez Réparer la liaison, puis redémarrez le navigateur.

4 Importer vos mots de passe

Choisissez Importer et exporter dans la barre latérale et sélectionnez un fichier d’export de 1Password, Bitwarden, LastPass, Dashlane, Proton Pass, KeePass ou KeePassXC, Chrome, Edge, Brave, Firefox ou Safari, ou n’importe quel CSV. Vous examinez chaque élément avant qu’il soit enregistré, et rien ne passe par Internet. Supprimez ensuite le fichier d’export, car la plupart des exports contiennent les mots de passe en clair.

L’offre gratuite contient jusqu’à 7 éléments. Pro supprime la limite.

5 Remplir les apps Windows

Pour des programmes comme les lanceurs de jeux, ouvrez un identifiant de bureau dans l’app et choisissez Liaison d’application… pour l’associer une seule fois à la fenêtre de connexion du programme. Ensuite, un bouton de remplissage apparaît à côté du champ de mot de passe, ou vous pouvez appuyer sur Ctrl+Maj+Espace. LocalGateKeys refuse de remplir si le programme ou la fenêtre a changé depuis l’association.

6 Activer Pro

Pro est un paiement unique qui ajoute les éléments illimités, la synchronisation entre vos appareils, les codes à deux facteurs et les documents. Après l’achat, choisissez Installer dans LocalGateKeys sur votre page de licence, ou collez votre clé de licence dans Paramètres › Offre et synchronisation › Licence. Voir votre licence Pro.

7 Ajouter votre iPhone

L’app iPhone conserve son propre coffre-fort chiffré et se synchronise avec votre PC. La synchronisation fait partie de Pro.

  1. Installez LocalGateKeys depuis l’App Store et ouvrez-le.
  2. Touchez Déverrouiller. Le coffre-fort s’ouvre avec Face ID, Touch ID ou le code de votre iPhone, donc aucun mot de passe à créer. Une courte configuration propose l’import, un mot de passe d’app facultatif et le remplissage automatique.
  3. Activez le remplissage automatique : dans LocalGateKeys, choisissez Réglages › Remplissage automatique › Ouvrir les réglages de remplissage automatique, puis activez LocalGateKeys sous Général › Remplissage automatique et mots de passe.
  4. Associez-le à votre PC : sur le PC, ouvrez Synchronisation et appareils, activez la synchronisation Wi-Fi et choisissez Afficher le code QR. Sur l’iPhone, ouvrez l’onglet Synchronisation et touchez Scanner le code QR. Vérifiez que les deux écrans affichent le même code, puis choisissez Accepter sur le PC.
  5. Apple Watch (Pro) : installez LocalGateKeys depuis l’app Watch de l’iPhone, puis ouvrez un identifiant avec un code à deux facteurs et touchez Afficher sur l’Apple Watch.

Vous avez acheté Pro sur l’iPhone ? Une fois l’association faite, un PC gratuit reprend la licence par la synchronisation et passe en Pro. L’aide pour chaque écran de l’iPhone se trouve dans le guide d’utilisation.

Mac : téléchargez l'app dans le Mac App Store. Android : l'app arrive. Elle n'est pas encore disponible.

Un blocage ? Consultez l’assistance et la FAQ ou écrivez à support@localgatekeys.app.
