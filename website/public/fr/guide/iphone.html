À savoir sur tous les appareils

  • Votre coffre-fort reste sur vos appareils. Il n’y a aucun compte et aucun serveur LocalGateKeys qui détienne vos mots de passe.
  • Personne ne peut réinitialiser votre mot de passe principal ni votre mot de passe d’app. Configurez une phrase de récupération et conservez-la sur papier.
  • L’offre gratuite contient jusqu’à 7 éléments. Pro (US$29.99, payé une seule fois) ajoute les éléments illimités, les codes à deux facteurs, les fichiers et la synchronisation. Modifier, supprimer et remplir des éléments que vous avez déjà n’est jamais bloqué.

Premier démarrage et déverrouillage

Il n’y a aucun mot de passe à créer. Votre coffre-fort s’ouvre avec Face ID, Touch ID ou le code de votre iPhone, comme votre téléphone. (L’iPhone doit avoir un code défini.)

  1. Ouvrez l’app et touchez Déverrouiller.
  2. Une courte configuration suit : Déverrouiller avec Face ID, Importer vos mots de passe, Ajouter un mot de passe d’app (facultatif) et Activer le remplissage automatique.
  3. Ignorez ce que vous voulez. Une carte Terminer la configuration en haut du coffre-fort vous y ramène ; Réglages › Afficher de nouveau la configuration aussi.

Mot de passe d’app et phrase de récupération

Un mot de passe supplémentaire facultatif qui, à la place du code de votre iPhone, ouvre LocalGateKeys. Utile si d’autres personnes connaissent votre code.

  1. Réglages › Mot de passe d’app › activez Utiliser un mot de passe d’app.
  2. Choisissez un mot de passe robuste (au moins 12 caractères) et laissez Déverrouiller avec Face ID activé si vous voulez ce raccourci.
  3. Notez la phrase de récupération de 24 mots, touchez Je les ai notés et saisissez les trois mots demandés.

Oublié ? Touchez Mot de passe d’app oublié ? sur l’écran de déverrouillage, saisissez les 24 mots et choisissez un nouveau mot de passe d’app.

Si vous ajoutez un nouveau visage ou une nouvelle empreinte sur l’iPhone, le raccourci Face ID se désactive par sécurité : saisissez une fois le mot de passe d’app et réactivez-le.

Éléments : ajouter, modifier, supprimer

  1. Dans l’onglet Coffre-fort, touchez + et choisissez un type : identifiant web, note sécurisée, carte, identité, compte bancaire, achat, abonnement, garantie, Wi-Fi, licence de logiciel, clé d’API, clé SSH ou favori.
  2. Renseignez les champs et touchez Enregistrer. Si vous partez en cours de route, l’app vous propose de Continuer plus tard votre élément non enregistré.
  • Touchez longuement un élément du coffre-fort pour Copier le nom d’utilisateur, Copier le mot de passe, Copier le code 2FA, Ouvrir le site web ou le marquer comme Favori. Ouvrez-le pour copier n’importe quel champ, lui ajouter une étoile ou le Partager. Le texte copié est effacé du presse-papiers au bout d’un moment et n’est jamais envoyé à vos autres appareils Apple.
  • L’Historique des mots de passe d’un identifiant conserve les anciens mots de passe : copiez-en un ou restaurez-le (demande Face ID).
  • Tout élément sauf un identifiant (une carte, un abonnement, une garantie, une licence…) peut recevoir un rappel avant son échéance ; pour une carte, sa date d’expiration est proposée.
  • Joindre un fichier (Pro, jusqu’à 25 Mo, stocké chiffré) depuis +.
  • Supprimer : l’élément va dans Supprimés récemment, avec Annuler pendant quelques secondes. Réglages › Données › Supprimés récemment vous permet de Restaurer ou de Supprimer définitivement.
  • Trier par nom ou par date, favoris en premier, ou regroupés par type.

Recherche et actions rapides

Touchez le bouton de recherche (la loupe) en haut du coffre-fort et saisissez ; tirer le coffre-fort vers le bas lance une synchronisation. Saisissez d’abord > pour voir les Actions : Nouvel élément, Générer un mot de passe, Scanner un code QR, Verrouiller maintenant, Synchroniser maintenant, Contrôle de sécurité, Supprimés récemment, Importer et exporter, et plus encore.

Générateur de mots de passe

Depuis > Générer un mot de passe, ou pendant la modification du mot de passe d’un identifiant. Choisissez un mot de passe avec une Longueur, ou une phrase secrète avec un nombre de Mots et un Séparateur. Touchez le bouton d’actualisation pour en générer un autre, puis Utiliser. L’app se souvient des dernières options utilisées ; Réglages › Générateur de mots de passe › Rétablir les valeurs par défaut rétablit les valeurs par défaut.

Codes à deux facteurs Pro

  1. Sur le site web, activez la 2FA par app d’authentification pour qu’il affiche un code QR.
  2. Dans LocalGateKeys, choisissez Scanner un code QR (depuis > ou le champ 2FA de l’identifiant). Touchez Utiliser l’appareil photo ou Choisir dans Photos (pour une capture d’écran).
  3. Le code va à l’identifiant correspondant, ou un nouvel identifiant s’ouvre, prêt à être enregistré.

Les codes apparaissent dans l’élément et dans la ligne Codes du coffre-fort. Vous pouvez aussi coller une clé de configuration dans le champ Secret 2FA de l’identifiant. Les exports de Google Authenticator (Transférer des comptes) fonctionnent aussi, y compris ceux en plusieurs parties.

Vous voulez les codes à votre poignet ? Voir Apple Watch.

Remplissage automatique dans les apps et Safari

  1. Dans LocalGateKeys, allez dans Réglages › Remplissage automatique › Ouvrir les réglages de remplissage automatique.
  2. Dans les Réglages de l’iPhone, sous Général › Remplissage automatique et mots de passe, activez LocalGateKeys.
  3. Touchez maintenant un champ de nom d’utilisateur ou de mot de passe dans n’importe quelle app ou n’importe quel site web : votre identifiant apparaît au-dessus du clavier, ou touchez l’icône en forme de clé pour en choisir un.

Options dans Réglages › Remplissage automatique :

  • Afficher les identifiants dans la barre QuickType : suggestions au-dessus du clavier.
  • Copier le code 2FA lors du remplissage : pour pouvoir coller le code sur l’écran suivant. Il est effacé après le délai de Effacer le presse-papiers après (60 secondes par défaut).
  • Proposer LocalGateKeys pour les clés d’accès.

Sous iOS 18 et ultérieur, les cartes et les coordonnées se remplissent aussi : touchez un champ de texte, choisissez Remplissage automatique › Mots de passe et choisissez le champ. Un identifiant enregistré pour un site https n’est pas proposé sur une page http simple.

Clés d’accès

Avec le remplissage automatique activé, lorsqu’un site web propose de créer une clé d’accès, choisissez LocalGateKeys. La clé d’accès est enregistrée dans votre coffre-fort et se synchronise avec votre PC. Se connecter à un ordinateur en scannant son code QR avec l’iPhone fonctionne aussi. La page de détails d’une clé d’accès indique le site et le compte ; la clé elle-même n’est jamais affichée. Vous pouvez la renommer ou la supprimer.

Enregistrer des identifiants depuis Safari

  1. Réglages de l’iPhone › Apps › Safari › Extensions › LocalGateKeys : activez-la et autorisez-la sur tous les sites web.
  2. Connectez-vous à un site dans Safari et touchez Enregistrer dans l’invite.
  3. Au prochain déverrouillage de LocalGateKeys, Enregistrer depuis Safari ? liste ce qui a été capturé, marqué Nouvel identifiant ou Met à jour le mot de passe enregistré. Choisissez ce que vous conservez, ou Décider plus tard.

Choisissez Jamais sur ce site pour arrêter l’invite sur un site.

Onglet Sécurité

Un score et des listes d’identifiants Compromis, Réutilisés, Faibles, Anciens, ou qui pourraient avoir la 2FA. Balayez un identifiant vers la gauche pour Changer le mot de passe ou Ignorer. Les vérifications des fuites sont désactivées tant que vous ne désactivez pas Réglages › Mode hors ligne strict (activé par défaut) et n’activez pas Autoriser les vérifications des fuites.

Importer et exporter

Depuis Mots de passe d’Apple (iOS 26)

  1. Ouvrez l’app Mots de passe, touchez le menu et choisissez Exporter les données vers une autre app.
  2. Choisissez LocalGateKeys. Les identifiants, codes 2FA et clés d’identification sont transférés. Recommencer n’ajoute rien en double.

Depuis un fichier

Réglages › Importer et exporter › Importer depuis un fichier : exports de Mots de passe d’Apple, Safari, Chrome, Edge, Brave, Firefox, Bitwarden (y compris protégé par mot de passe), 1Password (.1pux), LastPass, KeePass (.kdbx), Proton Pass, Dashlane, ou tout CSV. Vous examinez chaque élément avant de toucher Importer. Supprimez ensuite le fichier d’export.

Sauvegarde et export

  • Exporter la sauvegarde chiffrée : un fichier .lgkm avec un mot de passe de 12 caractères ou plus. Restaurez-la sous Windows.
  • Exporter en CSV : non chiffré, pour passer à une autre app. On vous demande de confirmer.
  • Exporter vers un fichier CXF… écrit les identifiants, notes et clés d’accès choisis dans un fichier Credential Exchange que d’autres gestionnaires peuvent importer. Le fichier n’est pas chiffré.

Synchroniser avec votre PC Pro

Par Wi-Fi

  1. Sur le PC, ouvrez Synchronisation et appareils et choisissez Afficher le code QR.
  2. Sur l’iPhone, ouvrez l’onglet Synchronisation et touchez Scanner le code QR dans les 120 secondes. (Autorisez l’accès au réseau local la première fois.) Pas d’appareil photo ? Touchez Coller le texte du code et collez le texte issu de Copier le texte du code sur l’ordinateur.
  3. Vérifiez que les deux écrans affichent le même code, puis choisissez Accepter sur l’ordinateur.

La synchronisation a lieu lorsque les deux appareils sont sur le même Wi-Fi et déverrouillés. Synchroniser maintenant la force ; Rechercher à nouveau aide si l’adresse de l’ordinateur a changé.

Par un dossier cloud

Touchez Rejoindre un dossier…, choisissez le dossier LocalGateKeys Sync dans iCloud Drive ou Dropbox, et saisissez le mot de passe de synchronisation du groupe.

OneDrive et Google Drive ne sont pas disponibles pour la synchronisation pour le moment, le temps de résoudre un problème avec Apple. Utilisez plutôt Dropbox, iCloud Drive ou la synchronisation Wi-Fi.

Arrêter

Quitter la synchronisation… ou Réinitialiser la synchronisation sur cet iPhone… (chacun demande deux fois). Vos éléments restent sur le téléphone.

Partager un élément

  1. Ouvrez l’élément et touchez Partager.
  2. L’app affiche six mots. Envoyez le fichier avec AirDrop ou partager le fichier…, ou Afficher le code sous forme de QR.
  3. Communiquez les six mots séparément à l’autre personne, jamais avec le fichier.

Réception : ouvrez le fichier .lgkshare depuis AirDrop ou Fichiers (ou Recevoir un élément partagé), et saisissez les six mots. Les clés d’accès et les éléments avec un fichier joint ne peuvent pas être partagés.

Paramètres

Confidentialité

Données

Effacer
Effacer le coffre-fort de cet iPhone supprime le coffre-fort sur cet iPhone uniquement (demande deux fois). Votre PC et votre dossier de synchronisation ne sont pas modifiés.

Mot de passe de contrainte et plus

  • Mot de passe de contrainte (Pro) : un second mot de passe d’app pour le cas où quelqu’un vous force à déverrouiller. Il ouvre un coffre séparé avec seulement les éléments choisis, et votre coffre refuse ensuite son mot de passe d’app pendant le nombre d’heures fixé. Activez d’abord le mot de passe d’app, puis configurez-le dans Réglages, sous Mot de passe de contrainte.
  • Héberger la synchronisation Wi-Fi sur ce téléphone (Pro), dans l’onglet Sync, permet à vos autres appareils de s’associer directement à l’iPhone, sans PC.
  • Un plan d’accès d’urgence créé sur le PC arrive sur l’iPhone par la synchronisation : vous pouvez aussi refuser ou accorder les demandes ici. Créer la note du dossier de succession ajoute la note pour vos héritiers.

Pro

Réglages › Pro › Mettre à niveau, puis achetez : un seul paiement, sans abonnement, sans compte. Sur un nouvel iPhone, utilisez Restaurer les achats avec le même compte Apple.

Votre achat déverrouille aussi Windows. Associez votre PC à l’iPhone dans l’onglet Synchronisation, et un PC gratuit reprend la licence par la synchronisation et passe en Pro. Ou choisissez Copier la clé et installez cette clé sur le PC (Paramètres › Offre et synchronisation › Licence).
