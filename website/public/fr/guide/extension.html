Extension de navigateur pour Edge, Chrome et Firefox

Une aide pas à pas pour chaque écran et chaque fonction sur cet appareil. Chaque titre est un lien que vous pouvez partager.

  • Windows
  • Mac
  • iPhone et iPad
  • Android
  • Extension de navigateur

À savoir sur tous les appareils

  • Votre coffre-fort reste sur vos appareils. Il n’y a aucun compte et aucun serveur LocalGateKeys qui détienne vos mots de passe.
  • Personne ne peut réinitialiser votre mot de passe principal ni votre mot de passe d’app. Configurez une phrase de récupération et conservez-la sur papier.
  • L’offre gratuite contient jusqu’à 7 éléments. Pro (US$29.99, payé une seule fois) ajoute les éléments illimités, les codes à deux facteurs, les fichiers et la synchronisation. Modifier, supprimer et remplir des éléments que vous avez déjà n’est jamais bloqué.

Sujets de l’extension

Remplit et enregistre les connexions sur les sites web. Elle ne communique qu’avec l’app LocalGateKeys du même PC ; installez donc d’abord l’app Windows. Vous utilisez Safari ? Rien à télécharger ici : les apps Mac et iPhone remplissent dans Safari grâce au remplissage automatique et incluent une extension Safari. Installer et connecter

  1. Installez et configurez l’app Windows.
  2. Ajoutez l’extension : Edge depuis Modules complémentaires Edge (choisissez Obtenir). Chrome depuis le Chrome Web Store (choisissez Ajouter à Chrome). Firefox depuis Modules complémentaires Firefox (choisissez Ajouter à Firefox).
  3. Cliquez sur l’icône en forme de pièce de puzzle de la barre d’outils et épinglez LocalGateKeys.
  4. Cliquez sur l’icône LocalGateKeys. La carte de connexion doit indiquer Connecté ou Verrouillé.

Il n’y a rien à associer : l’extension trouve l’app toute seule. Le guide de configuration de l’app comporte une étape Tester la connexion pour le vérifier.

La fenêtre de l’extension

Connexion
Connecté (prêt), Verrouillé (l’app vous demande de déverrouiller quand vous choisissez une action), Configuration requise ou Hors ligne. ↻ l’actualise sans rien déverrouiller.
Site actuel
Le site sur lequel vous êtes. Seuls les identifiants enregistrés pour ce site précis sont proposés.
Actions rapides
Remplir l’identifiant, Remplir l’identité, Remplir la carte…, Enregistrer l’identifiant, Générer un mot de passe.
Invites d’enregistrement
Un interrupteur pour désactiver ou activer les invites d’enregistrement pour ce site.

Par conception, rien ne se remplit tout seul. Chaque remplissage commence par votre clic, et l’extension ne demande jamais votre mot de passe principal : le déverrouillage se fait toujours dans la fenêtre LocalGateKeys.

Remplir un identifiant

  1. Ouvrez la page de connexion du site.
  2. Cliquez sur l’icône LocalGateKeys dans le champ du nom d’utilisateur ou du mot de passe (Remplir avec LocalGateKeys), ou ouvrez l’extension et choisissez Remplir l’identifiant.
  3. Si vous avez plusieurs comptes pour le site, choisissez-en un sous Choisir un compte.
  4. Si le coffre-fort est verrouillé, déverrouillez-le dans la fenêtre LocalGateKeys lorsqu’elle apparaît.

Si l’option Se connecter après le remplissage est activée pour l’identifiant, le formulaire est envoyé pour vous. Sur les formulaires inhabituels, vous verrez La connexion automatique a été ignorée : cliquez simplement sur le bouton de connexion du site.

Enregistrer un identifiant nouveau ou modifié

  1. Connectez-vous sur un site web comme d’habitude.
  2. L’extension demande Enregistrer cet identifiant ? (ou propose de mettre à jour un mot de passe modifié).
  3. Choisissez Enregistrer dans le coffre-fort et confirmez dans la fenêtre LocalGateKeys. Ou Pas maintenant, ou Jamais sur ce site.

Pour enregistrer à la main, renseignez le formulaire et choisissez Enregistrer l’identifiant dans la fenêtre de l’extension. Pour réactiver les invites sur un site, utilisez l’interrupteur de la fenêtre de l’extension.

Remplir les codes 2FA

Lorsqu’un site demande un code à 6 chiffres, cliquez sur l’icône LocalGateKeys dans le champ du code (Remplir le code 2FA avec LocalGateKeys). Seul le code actuel parvient à la page, jamais la clé de configuration. Si le code est sur le point d’expirer, l’extension attend un instant qu’un nouveau soit disponible.

L’identifiant doit avoir une clé de configuration 2FA enregistrée dans l’app (voir Codes à deux facteurs). Si Paramètres › Verrouillage › Demander avant de transmettre les codes 2FA est activé, confirmez dans l’app à chaque fois.

Cartes et identités

  1. Sur un formulaire de paiement ou d’adresse, cliquez sur l’icône dans un champ ou choisissez Remplir la carte… / Remplir l’identité.
  2. Choisissez la carte ou l’identité.
  3. Cochez les champs à remplir. Le code de sécurité (CVV) est décoché par défaut : ne le cochez que si nécessaire.
  4. Choisissez Vérifier et approuver, puis approuvez dans la fenêtre LocalGateKeys.

Créer un mot de passe sur une page d’inscription

Sur un formulaire d’inscription ou de changement de mot de passe, choisissez Générer un mot de passe. Le nouveau mot de passe est placé dans les champs de nouveau mot de passe. Enregistrez-le (l’invite d’enregistrement ou Enregistrer l’identifiant) avant de quitter la page.

Clés d’accès

Lorsqu’un site propose de créer ou d’utiliser une clé d’accès, LocalGateKeys peut s’en charger et conserver la clé d’accès dans votre coffre-fort. Activez ou désactivez cette option dans l’app : Paramètres › Remplissage automatique › Proposer LocalGateKeys pour les clés d’accès. Quand il ne peut pas aider, la fenêtre de clés d’accès du navigateur prend le relais.

Dépannage

Ce que vous voyezQue faire
Hors ligne / impossible de joindre l’appOuvrez LocalGateKeys. Dans Appareils et connexions, choisissez Réparer la liaison, puis redémarrez le navigateur.
Configuration requiseTerminez le choix d’un profil dans l’app, puis appuyez sur ↻.
L’intégration au navigateur est suspendueRéactivez le remplissage automatique du navigateur dans Paramètres › Remplissage automatique de l’app.
Versions incompatiblesMettez à jour l’extension et l’app, puis redémarrez-les toutes les deux.
La liaison a mis trop de tempsFermez toute invite LocalGateKeys ouverte et réessayez.
Aucun identifiant enregistré pour ce siteLe Site web de l’identifiant doit correspondre à ce site. Modifiez-le dans l’app.
Le remplissage est désactivé pour cet identifiantDans l’app, modifiez l’identifiant › Règles de remplissage automatique › Remplissage.
Cette page n’est pas disponibleLes extensions ne peuvent pas fonctionner sur les pages du navigateur (paramètres, nouvel onglet). Ouvrez une page http/https normale.

Toujours bloqué ? Appareils et connexions › Exporter le rapport et envoyez-le par e-mail à support@localgatekeys.app. Il ne contient aucun mot de passe.
