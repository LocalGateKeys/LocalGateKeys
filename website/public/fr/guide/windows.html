LocalGateKeys pour Windows

Une aide pas à pas pour chaque écran et chaque fonction sur cet appareil. Chaque titre est un lien que vous pouvez partager.

  • Windows
  • Mac
  • iPhone et iPad
  • Android
  • Extension de navigateur

À savoir sur tous les appareils

  • Votre coffre-fort reste sur vos appareils. Il n’y a aucun compte et aucun serveur LocalGateKeys qui détienne vos mots de passe.
  • Personne ne peut réinitialiser votre mot de passe principal ni votre mot de passe d’app. Configurez une phrase de récupération et conservez-la sur papier.
  • L’offre gratuite contient jusqu’à 7 éléments. Pro (US$29.99, payé une seule fois) ajoute les éléments illimités, les codes à deux facteurs, les fichiers et la synchronisation. Modifier, supprimer et remplir des éléments que vous avez déjà n’est jamais bloqué.

Sujets Windows

Windows 10 (version 2004 ou ultérieure) et Windows 11, 64 bits. Installez-le depuis le Microsoft Store ou la page de téléchargement.

Premier démarrage et profils

  1. Ouvrez LocalGateKeys. Saisissez un Mot de passe principal d’au moins 12 caractères, saisissez-le de nouveau dans Confirmer le mot de passe, puis choisissez Créer le coffre-fort.
  2. Le guide Configurer LocalGateKeys suit, en cinq étapes : créer le coffre-fort, Configurer Windows Hello, Importer vos mots de passe, Ouvrir la phrase de récupération (vous ressaisissez trois de ses mots pour prouver que vous l’avez conservée) et Tester la connexion pour l’extension de navigateur.
  3. Vous pouvez Ignorer n’importe quelle étape. Les étapes ignorées attendent sur une carte Terminer la configuration dans le coffre-fort, avec Poursuivre la configuration et Masquer.

Astuce. Pour revoir le guide : Paramètres › Aide et diagnostics › Afficher de nouveau la configuration.

Profils

Chaque profil est un coffre-fort distinct avec son propre mot de passe principal, par exemple un pour le travail et un pour la maison.

  • Sur l’écran de déverrouillage, choisissez Utiliser un autre profil, puis Créer un profil et saisissez un Nom du profil.
  • Pour modifier un profil, appuyez sur Ctrl+K et exécutez Changer de profil. Vous pouvez y Ajouter un profil, Modifier, définir une Photo… et une Couleur d’accent, ou le Supprimer.
  • Le Verrouiller et changer de personne du menu de la barre d’état verrouille et ouvre directement le sélecteur de profil.

Déverrouiller et verrouiller

Façons de déverrouiller

  • Mot de passe principal, puis Déverrouiller. Fonctionne toujours.
  • Déverrouiller avec Windows Hello : empreinte, visage ou code PIN. Configurez-le dans Paramètres › Déverrouillage › Windows Hello › Configurer. Démarrer Windows Hello automatiquement (activé par défaut) affiche l’invite dès l’ouverture de la fenêtre.
  • Utiliser la caméra à la place : reconnaissance du visage avec une webcam ordinaire, effectuée sur le PC. C’est moins sûr que Windows Hello. Configurez-la avec Configurer la vérification par caméra.

Mot de passe principal oublié ?

  1. Sur l’écran de déverrouillage, choisissez Oublié ? Utiliser la phrase de récupération.
  2. Saisissez les 24 mots, séparés par des espaces.
  3. Choisissez un nouveau mot de passe principal (12 caractères ou plus), saisissez-le deux fois et choisissez Récupérer le coffre-fort.

Ensuite, configurez de nouveau Windows Hello et la vérification par caméra. La phrase de récupération continue de fonctionner.

Changer le mot de passe principal

Paramètres › Déverrouillage › Mot de passe principal › Modifier…. Saisissez l’actuel, puis le nouveau deux fois. Pour que votre phrase de récupération reste valable, saisissez aussi ses 24 mots ; sinon, créez une nouvelle phrase ensuite. Les sauvegardes déjà faites conservent le mot de passe avec lequel elles ont été créées.

Verrouillage

  • Bouton Verrouiller de la barre supérieure, ou Ctrl+L.
  • Verrouillage d’urgence : Ctrl+Alt+L partout dans Windows. Il verrouille aussitôt et annule tout remplissage en cours.
  • Paramètres › Verrouillage :
    • Verrouiller après inactivité : Jamais, ou de 1 minute à 24 heures.
    • Verrouiller quand Windows se verrouille (Win+L, changement d’utilisateur, déconnexion) et Verrouiller à la mise en veille (capot fermé, veille, hibernation).
    • Ne jamais rester déverrouillé plus de : une limite stricte, quoi que vous fassiez.
    • Compter l’activité de : Activité de l’ordinateur ou Activité du coffre-fort.
    • Demander avant de transmettre les codes 2FA à l’extension de navigateur.

Le menu de l’icône de la barre d’état contient Ouvrir LocalGateKeys, Déverrouiller le coffre-fort, Verrouiller le coffre-fort, Verrouiller et changer d’utilisateur, Accès rapide, Rechercher des mises à jour, des interrupteurs pour Intégration au navigateur et Icônes de remplissage du bureau, et Quitter.

La liste des éléments

  • Filtres : Tous, À examiner, Sans 2FA, Expire bientôt.
  • Tri : Titre A–Z, Titre Z–A, Date de modification, Date de création.
  • Les indicateurs sur une ligne signalent un mot de passe compromis, faible ou réutilisé.
  • Faites un clic droit sur une ligne (ou Maj+F10) pour Modifier, Copier le nom d’utilisateur, Copier le mot de passe, Copier le code 2FA, Ouvrir le site web, Partager…, Ajouter aux favoris et Mettre à la corbeille….

Le volet de détails

Affiche les champs de l’élément sélectionné. Les mots de passe restent masqués tant que vous ne cliquez pas dessus. Des boutons copient le nom d’utilisateur, le mot de passe ou le code 2FA, ouvrent le site web, Modifier, Partager ou Mettre à la corbeille. Les documents ajoutent Ouvrir le fichier, Aperçu sécurisé, Enregistrer une copie… et Remplacer le fichier….

Ajouter et modifier des éléments

  1. Choisissez Nouvel élément ou appuyez sur Ctrl+N.
  2. Choisissez un type (cliquez dessus, appuyez sur son numéro ou commencez à saisir son nom) :
    • Connexions : Identifiant de site web, Identifiant d’app de bureau, Clé d’accès
    • Argent : Carte de paiement, Compte bancaire · Personnel : Identité, Note sécurisée, Document
    • Technique : Clé SSH, Clé API, Réseau Wi-Fi, Signet · Ce que vous possédez : Licence, Abonnement, Garantie, Achat
  3. Renseignez les champs et choisissez Enregistrer. Si vous quittez avec des modifications non enregistrées, on vous demande Abandonner vos modifications ?

Les identifiants en détail

  • Titre, Site web, Nom d’utilisateur, Mot de passe et Notes.
  • Modifier à côté du mot de passe vous permet d’en saisir un nouveau ; ou choisissez Phrase secrète, Aléatoire ou Code PIN pour en créer un. Changez-le aussi sur le site web, puis enregistrez.
  • Deux facteurs : collez ici la clé de configuration du site (Pro). Voir Codes à deux facteurs.
  • Champs personnalisés : Ajouter un champ pour tout le reste. Marquez un champ comme Masqué pour le traiter comme un mot de passe.
  • Historique des mots de passe : jusqu’à 5 anciens mots de passe sont conservés, chiffrés, pendant un an. Copier le mot de passe précédent ou Restaurer ce mot de passe.
  • Codes de récupération : un par ligne. Copier et utiliser le code suivant en copie un et le retire de la liste.
  • Règles de remplissage automatique : Remplissage (Au clic ou Désactivé), Se connecter après le remplissage (Par défaut, Jamais ou Toujours), Toujours demander le mot de passe principal, et Proposer d’enregistrer les modifications depuis le navigateur.

Autres types

Chaque type a ses propres champs. Les dates s’écrivent AAAA-MM-JJ. Chaque élément peut être un Favori et porter des Étiquettes (séparez-les par des virgules). Les documents utilisent Choisir un fichier et enregistrer (Pro).

Collections et rappels

  • Les collections regroupent les éléments à votre façon : Ajouter une collection, Renommer, Archiver. Elles se synchronisent avec vos autres appareils, et vous pouvez en partager une avec d’autres personnes (voir Collections partagées).
  • Rappels liste les éléments qui expirent bientôt ou qui sont en retard, avec Terminer et Reporter d’un jour.
  • Activité affiche l’historique de ce qui s’est passé dans le coffre-fort.

Supprimer, corbeille et annulation

  1. Sélectionnez un élément et choisissez Mettre à la corbeille ou appuyez sur Suppr.
  2. Un message apparaît avec Annuler : cliquez dessus pour ramener aussitôt l’élément.
  3. Plus tard, ouvrez Outils › Corbeille et utilisez Restaurer la sélection, Supprimer la sélection ou Vider la corbeille. Une suppression depuis la corbeille est irréversible.

Paramètres › Confidentialité › Conserver les éléments supprimés pendant règle la durée sur 7, 14, 30 ou 90 jours, et Vider la corbeille automatiquement la vide pour vous.

Recherche, palette de commandes et Accès rapide

  • Recherche : Ctrl+F, saisissez, puis appuyez sur Entrée pour ouvrir le premier résultat ou sur ↓ pour passer dans la liste.
  • Palette de commandes : Ctrl+K trouve des éléments et des actions. Commencez par > pour les actions seulement (Sauvegarder maintenant, Générer un mot de passe, Verrouiller maintenant, État de la synchronisation…), par # pour les étiquettes et par @ pour les collections.
  • Accès rapide : Ctrl+Alt+K partout dans Windows ouvre LocalGateKeys sur la page Accès rapide, pour trouver un identifiant, une note ou un favori. Modifiez le raccourci dans Paramètres › Remplissage automatique › Accès rapide.

Générateur de mots de passe

Ouvrez-le depuis la carte Générateur de l’Accueil ou avec Ctrl+K › Générer un mot de passe.

  • Aléatoire : choisissez la longueur et les caractères à utiliser : A–Z, a–z, 0–9 et symboles.
  • Phrase secrète : choisissez le nombre de mots. Plus facile à saisir, tout aussi robuste si elle est assez longue.
  • Générer à nouveau pour en obtenir un nouveau, Copier pour le copier.

Centre de sécurité et santé des mots de passe

Outils › Centre de sécurité liste ce qu’il faut corriger en premier : mots de passe faibles, réutilisés, anciens et compromis, et identifiants qui pourraient avoir la 2FA.

  • Vérifier toutes les fuites compare vos mots de passe à la liste de Have I Been Pwned. Seuls les 5 premiers caractères d’une empreinte quittent votre PC, jamais le mot de passe.
  • Les vérifications des fuites demandent deux changements dans Paramètres › Confidentialité : désactivez le mode hors ligne strict (activé par défaut) et activez Vérification des fuites. Le mode hors ligne strict bloque les vérifications des fuites, les icônes de sites et toute autre requête réseau.
  • Dans Santé des mots de passe, utilisez Ouvrir l’entrée ou Changer le mot de passe pour corriger un élément.

Activité réseau, en bas du Centre de sécurité, liste chaque connexion de LocalGateKeys et sa raison : recherche de mises à jour, vérifications de fuites, icônes de sites et synchronisation avec vos propres appareils.

Codes à deux facteurs et scan de QR Pro

LocalGateKeys peut afficher les codes à 6 chiffres qu’un site demande après le mot de passe, de sorte que vous n’avez pas besoin d’une app d’authentification distincte.

  1. Sur le site web, activez la connexion à deux facteurs / par app d’authentification pour qu’il affiche un code QR.
  2. Dans LocalGateKeys, choisissez Ctrl+K › Scanner un code QR. Importez l’image de l’une des trois façons suivantes :
    • Coller une capture d’écran : appuyez sur Win+Maj+S, sélectionnez le code QR, puis Ctrl+V.
    • Choisir une image… (PNG, JPEG, BMP) ou faites glisser l’image.
    • Utiliser la webcam et présentez devant elle l’écran d’un téléphone affichant le code.
  3. Choisissez l’identifiant auquel il appartient, ou Nouvel identifiant, puis Ouvrir dans l’éditeur et Enregistrer.
  4. Saisissez le code actuel sur le site web pour finir d’y activer la 2FA.

Vous pouvez aussi coller la clé de configuration ou un lien otpauth:// directement dans la section Deux facteurs de l’identifiant.

Passer de Google Authenticator

  1. Dans Google Authenticator, choisissez Transférer des comptes › Exporter.
  2. Scannez le code QR affiché (pour plusieurs codes, scannez chacun d’eux : « Code 1 sur 3 scanné »).
  3. Cochez les comptes, choisissez Ajouter à l’identifiant existant ou Nouvel identifiant, puis Ajouter. Les doublons sont ignorés.

Les nouveaux identifiants créés ainsi reçoivent l’étiquette needs-password : saisissez le vrai mot de passe plus tard. Les images sont lues en mémoire et jamais enregistrées. Dans l’offre gratuite, les codes que vous avez déjà continuent de fonctionner ; en ajouter ou les modifier nécessite Pro.

Importer depuis un autre gestionnaire de mots de passe

  1. Exportez vos mots de passe depuis l’ancienne app (voir la liste ci-dessous).
  2. Dans LocalGateKeys, ouvrez Outils › Importer et exporter › Importer des mots de passe et des éléments… et choisissez le fichier. Le format est reconnu automatiquement. Les fichiers chiffrés demandent leur Mot de passe d’import.
  3. Un CSV simple provenant d’une app inconnue affiche Choisir les colonnes : indiquez quelle colonne est le titre, le nom d’utilisateur, le mot de passe, etc.
  4. Examinez chaque ligne : Ajouter, Ignorer, Remplacer, Fusionner ou Conserver les deux. Utilisez Ajouter tous les nouveaux, Remplacer tous les conflits ou Tout ignorer pour tout traiter d’un coup.
  5. Choisissez Importer. Tout est importé d’un seul bloc ; si quelque chose échoue, rien n’est écrit.
  6. Supprimez le fichier d’export : il contient vos mots de passe non chiffrés.

Export et transfert chiffré

Outils › Importer et exporter › Exporter… propose :

  • KeePass KDBX 4 : chiffré avec un mot de passe de votre choix (12 caractères ou plus). Le choix le plus sûr.
  • CSV compatible Bitwarden, JSON Bitwarden, XML KeePass 2 : non chiffrés. Supprimez-les après usage.
  • Credential Exchange (CXF) JSON : les identifiants, notes et clés d’accès choisis, pour un autre gestionnaire de mots de passe. Non chiffré ; les clés privées des clés d’accès ne sont incluses qu’avec votre accord.
  • Cochez Inclure les secrets de mot de passe à usage unique (2FA) pour emporter vos codes 2FA.

Transfert chiffré… déplace des éléments choisis (par favoris, types, étiquettes) vers un autre profil ou PC dans un paquet protégé par mot de passe. De l’autre côté, choisissez Importer un paquet, Inspecter, Aperçu, puis importez.

Sauvegardes et restauration

Sauvegardes planifiées (recommandé)

  1. Paramètres › Sauvegardes › Mot de passe de sauvegarde › Définir…. Utilisez 12 caractères ou plus et notez-le.
  2. Sauvegardes planifiées : Chaque jour ou Chaque semaine, avec Heure et Jour de la semaine.
  3. Copie cloud › Choisir… un dossier, comme une clé USB ou un second disque, pour une seconde copie.
  4. Anciennes sauvegardes planifiées : ne conserver que la dernière, ou la dernière et la précédente.
  5. Test de restauration hebdomadaire : chaque semaine, LocalGateKeys vérifie qu’une sauvegarde planifiée se restaure. Rien n’est conservé. Sauvegardes automatiques à conserver fixe combien de sauvegardes automatiques sont gardées.

Les sauvegardes ne s’exécutent que lorsque le coffre-fort est déverrouillé. Une sauvegarde manquée pendant que l’app était fermée s’exécute au prochain déverrouillage.

Page Sauvegarde et restauration

Ouvrez-la depuis la carte Sauvegarde et récupération, avec Ctrl+K, ou depuis Sauvegarde et restauration sur l’écran de déverrouillage.

  • Créer une sauvegarde : un fichier .lgk chiffré avec son propre mot de passe.
  • Vérifier une sauvegarde : vérifie qu’un fichier s’ouvre, sans toucher à votre coffre-fort.
  • Restaurer la sauvegarde : nécessite le mot de passe de sauvegarde et le mot de passe principal d’alors. Vous pouvez la restaurer comme nouveau profil.
  • Tester une restauration : ouvre une copie temporaire pour prouver que votre sauvegarde fonctionne, puis Abandonner la copie de test.
  • Phrase de récupération (Configurer / Remplacer…) et Écrire le kit de récupération, une feuille imprimable.

Restaurer une sauvegarde de téléphone

Importer et exporter › Restaurer une sauvegarde de téléphone…, choisissez le fichier .lgkm de l’app iPhone, saisissez son mot de passe, Aperçu, puis Restaurer. Les éléments sont ajoutés à votre coffre-fort ; rien n’est effacé.

Synchronisation entre appareils Pro

La synchronisation ne s’exécute que lorsque le coffre-fort est déverrouillé : au déverrouillage, toutes les 5 minutes, et quelques secondes après une modification. Il y a deux méthodes, et vous pouvez utiliser les deux :

Wi-Fi (téléphone ou autre PC sur le même réseau)

  1. Synchronisation et appareils › Activer la synchronisation Wi-Fi…. Conservez l’adresse et le port suggérés (47821), et choisissez Autoriser dans le Pare-feu Windows si on vous le demande.
  2. Choisissez Afficher le code QR…. Le code ne fonctionne qu’une fois, pendant 120 secondes.
  3. Scannez-le avec l’onglet Synchronisation de l’app du téléphone. Pour un autre PC, choisissez Copier le texte du code et utilisez-y Rejoindre par texte du code QR….
  4. Les deux appareils affichent un code à 6 chiffres. Choisissez Accepter uniquement s’ils sont identiques, sinon Refuser.
  5. Juste après l’association, Annuler retire le nouvel appareil en cas d’erreur.

Si l’adresse du PC change, choisissez Rechercher à nouveau sur le téléphone.

Dossier cloud (Dropbox, iCloud Drive…)

  1. Sur le premier appareil : Créer un groupe de synchronisation…, choisissez un dossier que votre app cloud synchronise, et définissez un mot de passe de synchronisation robuste (12 caractères ou plus).
  2. Sur chacun des autres appareils : Rejoindre un dossier…, choisissez le dossier contenant LocalGateKeys Sync, saisissez le mot de passe de synchronisation.

Le cloud ne voit jamais que des fichiers chiffrés.

OneDrive et Google Drive ne sont pas disponibles pour la synchronisation pour le moment, le temps de résoudre un problème avec Apple. Utilisez plutôt Dropbox, iCloud Drive ou la synchronisation Wi-Fi.

Gérer la synchronisation

  • Synchroniser maintenant sur la page d’état de la synchronisation (cliquez sur la pastille de synchronisation dans la barre latérale).
  • Retirer un appareil… (définit un nouveau mot de passe de synchronisation), Changer le mot de passe de synchronisation….
  • Quitter la synchronisation… conserve vos éléments et oublie le groupe. Réinitialiser la synchronisation sur ce PC… oublie aussi ses clés (demande deux fois).
  • Si un élément a été modifié sur deux appareils en même temps, la copie supplémentaire reçoit (conflit de synchronisation) dans son titre.

Chaque appareil du groupe a besoin de Pro. Un PC gratuit associé à un iPhone doté de Pro reprend la licence par la synchronisation et passe en Pro (voir Licence Pro). Jusqu’à 16 appareils par groupe.

Partager un élément avec quelqu’un

  1. Sélectionnez l’élément, choisissez Partager, puis Créer un partage.
  2. LocalGateKeys affiche un Code de partage de six mots. Choisissez Enregistrer sous forme de fichier… (un .lgkshare) ou Afficher le code QR.
  3. Envoyez le fichier, puis communiquez les six mots à la personne par un autre moyen, par exemple par téléphone ou en personne.

Réception : double-cliquez sur le fichier .lgkshare, ou Ctrl+K › Éléments partagés entrants › Ouvrir un élément partagé…. Saisissez les six mots, vérifiez l’Aperçu, puis Enregistrer dans le coffre-fort, Conserver les deux ou Rejeter. Les clés d’accès, les documents et les éléments avec un fichier joint ne peuvent pas être partagés.

Remplir les apps Windows

LocalGateKeys peut remplir les fenêtres de connexion de programmes Windows ordinaires, pas seulement les sites web.

  1. Ouvrez la fenêtre de connexion du programme.
  2. Appuyez sur Ctrl+N, choisissez Identifiant d’app de bureau, puis Inspecter l’application….
  3. Associer les champs de connexion : pointez les champs du nom d’utilisateur et du mot de passe. Vous pouvez aussi Associer le bouton de connexion….
  4. Enregistrer l’identifiant.
  5. La fois suivante, appuyez sur Ctrl+Maj+Espace dans ce programme ou cliquez sur le bouton de remplissage à côté de son champ de mot de passe.

Si le programme change après une mise à jour, ouvrez l’identifiant et choisissez Liaison d’application… › Actualiser la liaison…. LocalGateKeys ne lit que la disposition de la fenêtre, jamais ce que vous saisissez.

Collections partagées Pro

Partagez une collection avec votre famille ou une équipe via un dossier accessible à tous, par exemple un dossier OneDrive partagé. Ouvrez la collection, choisissez Partager la collection, le dossier, si les membres peuvent modifier ou seulement consulter, et un mot de passe de partage.

Les autres choisissent Rejoindre une collection partagée, le dossier et saisissent le mot de passe de partage ; vous choisissez ensuite Les laisser entrer. Seule cette collection passe par le dossier : vos autres éléments restent privés. Vous pouvez retirer quelqu’un, Arrêter le partage ou quitter à tout moment.

Accès d’urgence et mot de passe de contrainte Pro

  • Accès d’urgence (Pro) : sur la page Sauvegarde et restauration, choisissez Configurer l’accès d’urgence. Votre phrase de récupération est divisée en fragments pour des personnes de confiance ; vous choisissez combien de fragments sont nécessaires et un délai d’attente. Remettez à chacun sa feuille ou son fichier de fragment.
  • Quand assez de détenteurs demandent l’accès via le dossier partagé, vos appareils affichent la demande et vous pouvez Refuser jusqu’à la fin du délai. Un détenteur choisit On m’a donné l’accès, ajoute les fragments puis Demander l’accès ; une fois l’accès accordé, le coffre s’ouvre comme nouveau profil.
  • Dossier de succession, sur la même page, crée une note pour vos héritiers (où est le testament, comptes à fermer, appareils et qui détient un fragment), puis le Kit d’urgence à imprimer.
  • Mot de passe de contrainte (Pro) : Paramètres › Déverrouillage › Mot de passe de contrainte › Configurer. C’est un second mot de passe maître pour le cas où quelqu’un vous force à déverrouiller. Il ouvre un coffre séparé avec seulement les éléments choisis, et votre vrai coffre refuse ensuite son mot de passe maître pendant le nombre d’heures fixé. Il existe sous Windows, sur Mac, iPhone et Android.

Outils de développement et agents IA

Paramètres › Développeur propose les clés SSH de votre coffre à ssh et Git sur ce PC, pour la connexion et la signature des commits. Chaque signature demande votre accord. Générer crée une nouvelle clé Ed25519 dans le coffre.

Autoriser les agents IA à utiliser LocalGateKeys permet à des agents comme Claude Code de se connecter via MCP. Vous approuvez chaque connexion ou lecture ; l’agent ne voit jamais de mot de passe et chaque demande est journalisée. Dans la version Microsoft Store, ajoutez-le avec claude mcp add localgatekeys -- LocalGateKeysNativeHost.exe mcp.

Mises à jour

LocalGateKeys du Microsoft Store se met à jour via le Store. Vous utilisez encore la version de l'ancien programme d'installation ? Sa dernière mise à jour est la 0.4.12 : désinstallez-la dans Paramètres Windows › Applications › Applications installées, puis installez LocalGateKeys depuis le Microsoft Store. Votre coffre reste où il est et s'ouvre avec le même mot de passe maître.
