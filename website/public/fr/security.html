Le modèle de sécurité, en termes simples

Ce que LocalGateKeys est conçu pour protéger, et ce qu’il ne peut pas protéger.

Comment votre coffre-fort est chiffré

Une clé aléatoire de 256 bits chiffre le coffre-fort. Cette clé n’est jamais stockée telle quelle ; elle est enveloppée (chiffrée) séparément par chaque moyen de déverrouillage, de sorte que changer de mot de passe n’oblige pas à tout rechiffrer, et qu’une enveloppe copiée depuis un autre coffre-fort est rejetée.

Chiffrement du coffre-fort
AES-256-GCM avec un nonce aléatoire neuf à chaque enregistrement
Mot de passe principal
Argon2id, 3 passes, parallélisme 4, sel aléatoire par enveloppe ; 256 Mio de mémoire dans l’app Windows (64 Mio sur un PC qui a moins de 4 Go de mémoire) et 64 Mio dans les apps Mac, iPhone et Android
Phrase de récupération
Phrase BIP39 facultative de 24 mots (256 bits), étendue avec HKDF-SHA256
Windows Hello, Touch ID, Face ID et empreinte digitale
Libèrent la clé du coffre-fort depuis un stockage que l’appareil protège ; le mot de passe principal n’est jamais enregistré
Sauvegardes et transferts
Argon2id et AES-256-GCM, avec les paramètres stockés dans l’en-tête authentifié
Synchronisation des appareils
Une clé de groupe aléatoire, transmise à chaque appareil avec X25519 et HKDF-SHA256 et, pour un dossier cloud, également enveloppée par votre mot de passe de synchronisation avec Argon2id ; chaque enregistrement scellé avec AES-256-GCM et lié à son élément, sa version et son époque de clé ; chaque fichier d’appareil lié à l’appareil qui l’a écrit
Clés d’accès
Clés ES256 (P-256) conservées dans le coffre-fort chiffré ; l’app construit les données signées à partir de l’origine signalée par le navigateur, jamais à partir de la page. L’app du Microsoft Store peut aussi être le fournisseur de clés d’accès de Windows 11 (désactivé par défaut) ; Windows garde alors dans sa propre liste les noms de vos sites et comptes à clé d’accès, jamais les clés
Écritures sur le disque
Fichier temporaire, vidage, puis remplacement atomique, de sorte qu’un plantage ne peut pas laisser un coffre-fort à moitié écrit
Agents d’IA
Désactivé par défaut (Pro). Un agent n’atteint l’app que par lgk mcp sur votre propre appareil et ne voit que les identifiants et éléments que vous avez autorisés. Vous approuvez chaque demande ; l’app remplit elle-même la connexion, et aucune réponse à l’agent ne contient de mot de passe. Chaque demande est inscrite dans un journal d’accès dont les entrées sont chaînées par des hachages SHA-256, et la vérification de sécurité indique si cette chaîne est intacte

Conçu pour protéger contre

  • Une personne qui copie votre fichier de coffre-fort ou une sauvegarde sans connaître votre mot de passe principal
  • Un site web qui obtient des identifiants ou des clés d’accès enregistrés pour un autre site web
  • Un autre programme de votre PC qui communique avec LocalGateKeys sans le secret de session qu’il remet à son propre assistant de navigateur
  • Le remplissage d’une app de bureau qui a été remplacée, mise à jour ou modifiée depuis son association
  • Des mots de passe laissés non chiffrés sur le disque
  • Des formulaires envoyés sans vous
  • Votre fournisseur cloud qui lit les données synchronisées : il ne stocke que du texte chiffré
  • Une page web qui lirait les comptes que LocalGateKeys vous propose : dans Chrome, Edge et Firefox, la liste est dessinée dans un cadre distinct de l’extension que la page ne peut pas lire
  • Un agent d’IA qui obtiendrait un mot de passe de LocalGateKeys : aucune réponse à l’agent n’en contient, et il ne voit que les identifiants que vous avez autorisés

Ne peut pas protéger contre

  • Un logiciel malveillant, ou toute personne disposant d’un contrôle administrateur, déjà présent sur votre PC
  • Un navigateur, une installation de Windows ou une dépendance compromis
  • Un site web dans lequel vous saisissez volontairement un mot de passe
  • Une personne qui utilise votre PC pendant que le coffre-fort est déverrouillé
  • L’hameçonnage dans une app authentique qui affiche un contenu contrôlé par un attaquant
  • La perte de votre coffre-fort, de vos sauvegardes et de votre mot de passe principal sans phrase de récupération : personne, nous compris, ne peut l’ouvrir
  • Un agent d’IA qui pilote votre navigateur et lit un mot de passe une fois que LocalGateKeys l’a rempli dans la page, ou une commande que vous avez approuvée et qui transmet les secrets qu’elle a reçus

Ce que LocalGateKeys ne fait jamais

Certaines façons de remplir des mots de passe sont impossibles à distinguer d’un logiciel espion ; elles sont donc exclues dès la conception. LocalGateKeys ne contient aucun de ces éléments :

  • crochets clavier ou enregistrement des frappes
  • surveillance du presse-papiers
  • lecture de l’écran ou OCR pour trouver des identifiants
  • analyse de la mémoire d’autres programmes
  • déchiffrement de la base de mots de passe enregistrés de votre navigateur
  • injection de code dans d’autres programmes ou jeux
  • envoi d’une connexion que vous n’avez pas lancée

Le réseau, en toute franchise

Il n’y a ni compte LocalGateKeys ni serveur qui détienne des coffres-forts. L’app se connecte à Internet uniquement dans les cas suivants :

  • Mises à jour. Le Microsoft Store met à jour l’app Windows et l’App Store les apps Mac et iPhone ; LocalGateKeys ne télécharge ni n’exécute jamais d’installateur elle-même. Les anciennes versions Windows avec installateur (jusqu’à la 0.4.12, la dernière) téléchargent un petit fichier depuis notre serveur quand vous choisissez Rechercher des mises à jour et vérifient sa signature avec une clé intégrée à l’app.
  • Liste de révocation des licences. À chaque vérification des mises à jour dans les versions avec installateur, et quand vous choisissez Rechercher des mises à jour dans l’app du Microsoft Store avec le mode hors ligne strict désactivé, l’app télécharge une liste signée des licences remboursées et y compare votre licence sur votre PC. Elle n’envoie rien sur votre licence.
  • Icônes de sites. Pour afficher l’icône d’un site, l’app la télécharge depuis l’adresse propre à ce site. Aucun nom d’utilisateur, mot de passe ou donnée du coffre-fort n’est envoyé, mais chaque téléchargement indique à ce site, et à quiconque observe le réseau, que votre coffre-fort contient un compte chez lui. Cette option est désactivée par défaut et n’a lieu que si vous activez « Afficher les icônes des sites » dans les Paramètres ; le mode hors ligne strict la bloque.
  • Vérifications des fuites, si vous les activez. Quand vous lancez une vérification, l’app envoie à Have I Been Pwned les cinq premiers caractères de l’empreinte SHA-1 de chaque mot de passe. Le service voit votre adresse IP, jamais le mot de passe, l’empreinte complète, le nom d’utilisateur ni le site web.
  • Synchronisation, si vous la configurez. Sur votre réseau domestique, les appareils communiquent directement entre eux. Par un dossier cloud, c’est votre app de stockage cloud qui fait le téléversement.
  • Achat de Pro dans l’app Mac, iPhone ou Android. L’app envoie le justificatif d’achat signé de la boutique à notre serveur de licences, qui répond avec votre clé de licence. Aucune adresse e-mail ni donnée de l’appareil n’est envoyée.
  • Site vérifié. La détection des adresses trompeuses s'exécute sur votre appareil. Vos sites enregistrés ne quittent jamais l'app et rien n'est envoyé à un serveur.

Dans l’app Windows, Centre de sécurité › Activité réseau liste chacune de ces connexions avec l’heure, l’hôte et le résultat. Les noms des sites que vous avez enregistrés ne s’affichent que pendant que l’app tourne et ne sont jamais écrits sur le disque, et les appareils de votre propre réseau apparaissent comme « Réseau local ».

Le mode hors ligne strict est activé par défaut. Il bloque les requêtes Internet en arrière-plan, les icônes de sites et les vérifications des fuites, et une vérification des mises à jour vous demande d’abord votre accord. La politique de confidentialité liste exactement ce que nos serveurs voient lorsque vous recherchez des mises à jour.

Limites connues

  • Le mot de passe principal est placé dans un tampon effaçable dès qu’il arrive dans l’app et est effacé lorsque l’opération qui en avait besoin se termine. La page dans laquelle vous le saisissez s’exécute dans Microsoft Edge WebView2. La page vide son champ et l’app libère la copie faite lors du transfert avant que votre clé ne soit calculée, mais aucune de ces deux copies ne peut être écrasée en mémoire, des traces peuvent donc y rester pendant un court moment.
  • Le déverrouillage par caméra demande un mouvement de tête aléatoire, de sorte qu’une photo tenue à plat devant la caméra ou une image fixe sur un écran ne passe pas. Cela reste une vérification de commodité, pas une protection certifiée : une photo pliée ou courbée, une vidéo qui suit les consignes ou un masque peuvent passer. Windows Hello est le choix le plus sûr.
  • Le remplissage des apps Windows ne fonctionne pas avec les programmes exécutés en tant qu’administrateur, les interfaces de jeux dessinées sur mesure ou les vues web intégrées qu’il ne peut pas vérifier.
  • Le coffre-fort détecte qu’il a été ramené à une copie plus ancienne. Si vous utilisez la synchronisation, vos autres appareils se souviennent de l’état le plus récent de votre coffre-fort, de sorte qu’une copie plus ancienne remise sur un appareil est signalée à la prochaine synchronisation, dans chaque app. Sans synchronisation, un PC Windows conserve un second enregistrement en dehors du dossier du coffre-fort, de sorte qu’un ancien coffre-fort remis en place avec son fichier d’ancrage est refusé ; une personne qui peut modifier les paramètres de votre compte Windows peut aussi supprimer cet enregistrement. Les apps iPhone, Mac et Android gardent leurs fichiers fermés aux autres apps, mais sans synchronisation elles ne remarquent pas une copie plus ancienne mise à leur place.
  • Les clés d’accès fonctionnent dans Chrome, Edge et Firefox. La connexion avec une clé d’accès dans le cadre d’un autre site fonctionne dans Chrome et Edge lorsque le site qui l’entoure l’autorise ; dans Firefox, et lorsque vous créez une clé d’accès dans le cadre d’un autre site, la boîte de dialogue des clés d’accès du navigateur est utilisée. Si un site annule l’opération après que vous avez approuvé une nouvelle clé d’accès, l’app la supprime de nouveau ; lorsque l’app ne peut pas savoir si le site l’a conservée, la clé d’accès reste dans votre coffre-fort et vous pouvez la supprimer dans l’app.
  • L'avertissement d'adresse trompeuse est un indice, pas un mur : le script propre d'une page peut le contourner, par exemple en envoyant un mot de passe sans soumettre de formulaire. Vérifiez l'adresse vous-même.
  • L'accès d'urgence n'a pas de serveur : seules les apps imposent le délai et votre veto. Quiconque détient assez de fragments peut récupérer votre sauvegarde aussitôt, sans attendre. Choisissez des détenteurs qui n'agiraient pas ensemble et gardez les fragments séparés.
  • Le mot de passe de contrainte protège contre l'obligation de déverrouiller l'app. Il ne protège pas contre quelqu'un qui examine les fichiers de votre disque, et une personne attentive peut découvrir qu'un second coffre existe. Il existe sur Windows, Mac, iPhone et Android.

Code source pour les audits de sécurité

LocalGateKeys est en source disponible : tout le code source est publié sur GitHub pour que chacun puisse vérifier comment il protège votre coffre. La licence (PolyForm Strict, avec une autorisation de recherche en sécurité) permet de lire, compiler et tester le code en privé pour trouver et signaler des vulnérabilités. Ce n'est pas de l'open source : le copier, le redistribuer ou le vendre n'est pas autorisé.

Signaler une vulnérabilité

Écrivez à security@localgatekeys.app. La politique de divulgation des vulnérabilités explique ce qui est dans le périmètre, dans quel délai nous répondons et comment nous citons les chercheurs.

LocalGateKeys

Un gestionnaire de mots de passe pour Windows, Mac et iPhone qui garde votre coffre-fort sur vos propres appareils.
