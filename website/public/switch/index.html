Switch to LocalGateKeys

Pick the password manager you use now. Each guide shows how to export from it, how to import into LocalGateKeys, and what does not transfer.

  • 1Password
  • Bitwarden
  • LastPass
  • Dashlane
  • Enpass
  • KeePass
  • Proton Pass
  • NordPass
  • Apple Passwords
  • Google Password Manager
  • Microsoft Authenticator

Passkeys do not transfer in a CSV export; LocalGateKeys imports them from CXF files (Apple Passwords and other apps that export CXF) on PC, Android, iPhone and Mac.
