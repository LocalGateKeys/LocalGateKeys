Usava o instalador antigo?

Desinstale-o em Configurações do Windows › Aplicativos › Aplicativos instalados e depois instale o LocalGateKeys pela Microsoft Store. Seu cofre continua onde está: o app da Store o abre com a mesma senha mestra.

O que você precisa

  • Windows 10 ou Windows 11, 64 bits
  • Uma versão atual do Google Chrome ou do Microsoft Edge para o preenchimento no navegador
  • Hardware do Windows Hello (leitor de digitais, câmera Hello ou PIN) para desbloquear com o Windows Hello
  • Para sincronização: Pro, e dois ou mais dispositivos na mesma rede ou um app de nuvem em cada um
  • Para códigos no Apple Watch: Pro e um Apple Watch emparelhado com o iPhone

Depois de instalar

O guia Primeiros passos explica cada etapa, com capturas de tela.

  1. Abra o LocalGateKeys e escolha uma senha mestra com pelo menos 12 caracteres. Anote-a em um lugar seguro; não podemos redefini-la.
  2. Crie uma frase de recuperação quando o guia de configuração oferecer e guarde-a offline.
  3. Ative os backups agendados em Configurações.
  4. Adicione a extensão de navegador para o Edge, Firefox ou para o Chrome e fixe-a na barra de ferramentas. A extensão só funciona com o app instalado.
  5. Comprou o Pro? Digite sua chave de licença em Ferramentas > Licença. Veja sua licença Pro.
