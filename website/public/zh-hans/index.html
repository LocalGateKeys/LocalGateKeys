如何开始

加密副本去哪里，由您决定

每台设备都保存自己的加密保管库。除非您设置，否则任何内容都不会离开设备。电脑之间的同步属于 Pro。

哪里都不去

默认设置，所有版本均如此

保管库留在这台电脑上。定时备份是加密文件，由您随意存放，包括 U 盘或同步文件夹。

您的家庭 Wi-Fi

Pro

用一次性配对码为您的电脑配对一次。当它们处于同一网络且已解锁时，会通过加密连接直接相互同步。不涉及互联网连接。

您自己的云文件夹

Pro，需要您开启

将同步指向您已在使用的 OneDrive、Dropbox、Google Drive 或 iCloud Drive 文件夹，并由同步密码保护。您的云服务商存储的是它无法读取的加密文件。我们完全不参与。

在 Chrome 和 Edge 中填充登录信息

浏览器扩展通过一个小型本地辅助程序与您电脑上的 LocalGateKeys 应用通信。它只提供为您当前所在网站保存的登录项。它还会填充双重验证码、地址和支付卡，并在您登录后提示保存新的登录项。

通行密钥同样可用：网站可以将通行密钥保存到您的保管库并用它登录，每一个都需要您在桌面应用中批准。

扩展绝不会收到您的整个保管库，也没有任何请求离开您的电脑。

也适用于 Windows 应用

桌面应用填充适用于游戏启动器等 Windows 程序的登录窗口。您只需绑定一次窗口；此后，密码框旁边的填充按钮或快捷键就会填充已保存的字段。

它只读取 Windows 公开的窗口辅助功能信息。它绝不记录您的键盘输入，绝不向其他程序注入代码，并且在应用或窗口发生变化时拒绝填充。

内置双重验证码

将网站的双重验证设置密钥与其登录项一起保存，LocalGateKeys 就会在登录项顶部显示当前验证码。主页上的“一次性验证码”卡片会列出全部验证码。添加密钥的方式：粘贴网站二维码的截图、将二维码对准摄像头，或从 Google Authenticator 导出文件导入。

验证码在您的电脑上计算。双重验证码属于 Pro。

检查您的密码

生成器可生成强密码或密码短语。密码健康会显示哪些已保存的密码较弱、重复使用、陈旧或缺少双重验证码。如果您开启，由您发起的泄露检查会将它们与已知泄露进行比对，只发送哈希的五个字符。
