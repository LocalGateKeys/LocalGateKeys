如何开始

加密副本去哪里，由您决定

每台设备都保存自己的加密保管库。除非您设置，否则任何内容都不会离开设备。电脑与 iPhone 之间的同步属于 Pro。

  • 哪里都不去

    默认设置，所有版本均如此

    保管库留在您的设备上。定时备份是加密文件，可保存在您喜欢的任何位置，包括 U 盘或同步文件夹。

  • 您的家庭 Wi-Fi

    Pro

    用一次性二维码为您的电脑和 iPhone 配对一次。当它们处于同一网络且已解锁时，会通过加密连接直接相互同步。不涉及互联网连接。

  • 您自己的云文件夹

    Pro，需要您开启

    将同步指向您已在使用的云文件夹（例如 Dropbox 或 iCloud Drive），并由同步密码保护。您的云服务商存储的是它无法读取的加密文件。我们完全不参与。

它每天为您做的事

  • 在 Chrome 和 Edge 中填充登录信息

    浏览器扩展通过一个小型本地辅助程序与您电脑上的 LocalGateKeys 应用通信。它只提供为您当前所在网站保存的登录项。它还会填充双重验证码、地址和支付卡，并在您登录后提示保存新的登录项。

    通行密钥同样可用：网站可以将通行密钥保存到您的保管库并用它登录，每一个都需要您在桌面应用中批准。

    扩展绝不会收到您的整个保管库，也没有任何请求离开您的电脑。

  • 也适用于 Windows 应用

    桌面应用填充适用于游戏启动器等 Windows 程序的登录窗口。您只需绑定一次窗口；此后，密码框旁边的填充按钮或快捷键就会填充已保存的字段。

    它只读取 Windows 公开的窗口辅助功能信息。它绝不记录您的键盘输入，绝不向其他程序注入代码，并且在应用或窗口发生变化时拒绝填充。

  • 内置双重验证码 Pro

    将网站的双重验证设置密钥与其登录信息一起保存，当前验证码就会显示在登录信息顶部和主页的一次性验证码卡片中。可以通过截图或摄像头扫描网站的二维码，也可以从 Google Authenticator 迁移验证码。在 iPhone 上，您可以将选择的验证码显示在 Apple Watch 上。

    验证码在您自己的设备上计算。双重验证码属于 Pro。

  • 检查您的密码

    生成器可创建高强度密码或口令短语。密码健康会显示哪些已保存的密码较弱、重复使用、过旧或缺少双重验证码，iPhone 应用则会为同一项检查打分。如果您开启，由您发起的泄露检查会将它们与已知泄露进行比对，只发送哈希值的五个字符。

  • iPhone 上也有

    iPhone 应用可在 Safari 和其他应用中填充登录信息，在 iOS 18 及更高版本中还可在任何文本字段中填充银行卡和身份信息。它提供安全检查、密码历史、到期提醒，以及带“撤销”的“最近删除”，并可用 Face ID、Touch ID 或可选的应用密码打开。

    它与您的电脑同步，在 iPhone 上购买 Pro 也会解锁 Windows。

  • 安全共享单个项目

    将登录信息或笔记以文件或二维码发送，并用六个单词的代码锁定，您需要通过其他方式（例如电话）告诉对方这个代码。

    它只能打开一次，输错三次代码就会销毁。
