安全模型，通俗讲解

LocalGateKeys 旨在保护什么，以及它无法保护什么。

保管库如何加密

一个随机的 256 位密钥用来加密保管库。该密钥从不按原样存储；每种解锁方式都会各自将其包裹（加密），因此更改密码不需要重新加密所有内容，从其他保管库复制来的包裹会被拒绝。

保管库加密
AES-256-GCM，每次保存都使用全新的随机 nonce
主密码
Argon2id，64 MiB 内存，3 轮，并行度 4，每个包裹使用随机盐值
恢复短语
可选的 24 词 BIP39 短语（256 位），通过 HKDF-SHA256 扩展
Windows Hello
包裹保管库密钥，绝不包裹主密码
备份和传输
Argon2id 和 AES-256-GCM，参数存储在经过认证的头部中
设备同步
一个随机的群组密钥，通过 X25519 和 HKDF-SHA256 交给每台设备；对于云文件夹，还会由您的同步密码通过 Argon2id 再次包裹；每条记录都用 AES-256-GCM 密封，并绑定到其项目、版本和密钥纪元；每个设备文件都绑定到写入它的设备
通行密钥
ES256 (P-256) 密钥保存在加密的保管库中；应用根据浏览器报告的来源构造签名数据，绝不根据页面构造
写入磁盘
先写临时文件，刷新，再原子替换，因此崩溃不会留下写了一半的保管库

设计用于防范

  • 复制了您的保管库文件或备份，但不知道主密码的人
  • 网站获取为另一个网站保存的登录项或通行密钥
  • 您电脑上的其他程序在没有会话密钥的情况下与 LocalGateKeys 通信，而该密钥只交给它自己的浏览器辅助程序
  • 填充在绑定之后被替换、更新或更改的桌面应用
  • 密码以未加密形式存放在磁盘上
  • 表单在没有您参与的情况下被提交
  • 您的云服务商读取已同步的数据：它只存储密文

无法防范

  • 已经在您电脑上运行的恶意软件，或任何拥有管理员控制权的人
  • 被入侵的浏览器、Windows 系统或依赖项
  • 您有意向其填入密码的网站
  • 在保管库解锁期间使用您电脑的人
  • 在显示攻击者控制内容的正规应用内部进行的网络钓鱼
  • 在没有恢复短语的情况下，丢失了保管库、备份和主密码：任何人，包括我们，都无法打开它

LocalGateKeys 绝不会做的事

有些填充密码的方式与间谍软件无法区分，因此在设计上就被排除。LocalGateKeys 不包含：

  • 键盘钩子或按键记录
  • 剪贴板监视
  • 通过读取屏幕或 OCR 来查找凭据
  • 扫描其他程序的内存
  • 解密您浏览器中保存的密码数据库
  • 向其他程序或游戏注入代码
  • 提交并非由您发起的登录

坦诚谈网络

没有 LocalGateKeys 账户，也没有保存保管库的服务器。应用只在以下情况下连接互联网：

  • 更新检查。当您选择“检查更新”时，应用会下载一个小文件，并用内置于应用的密钥验证其签名。它绝不会自行下载或运行安装程序。
  • 许可证吊销列表。每次检查更新时，应用还会下载一份已退款许可证的签名列表，并在您的电脑上用它核对您的许可证。它不会发送任何有关您许可证的信息。
  • 网站图标。为了显示网站图标，应用会从该网站自己的地址下载。不会发送用户名、密码或保管库数据，但每次下载都会让该网站以及任何监视网络的人知道，您的保管库在那里有账户。此项默认关闭，只有在您于“设置”中开启“显示网站图标”时才会发生；严格离线模式会阻止它。
  • 泄露检查（如果您开启）。当您启动检查时，应用会把每个密码 SHA-1 哈希的前五个字符发送给 Have I Been Pwned。该服务能看到您的 IP 地址，但绝不会看到密码、完整哈希、用户名或网站。
  • 同步（如果您设置）。在家庭网络中，设备之间直接通信。通过云文件夹时，由您的云盘应用负责上传。

严格离线模式默认开启。它会阻止后台互联网请求、网站图标和泄露检查，检查更新前会先询问您。隐私政策准确列出了您检查更新时我们的服务器能看到什么。

已知限制

  • 主密码一进入应用就会被放入可擦除的缓冲区，并在需要它的操作结束时被擦除。您输入密码的页面运行在 Microsoft Edge WebView2 中，从该页面到应用的传递会产生一份短暂存在的副本；应用无法擦除这两份副本。
  • 摄像头解锁只是便利性检查，并非经过认证的、能防范照片或面具的保护。Windows Hello 是更强的选择。
  • Windows 应用填充不适用于以管理员身份运行的程序、自绘的游戏界面，或无法验证的嵌入式网页视图。
  • 保管库能检测到被回滚到较旧的副本。如果您使用同步，您的其他设备也会记住保管库有多新，因此同时删除保管库及其锚点文件会在下次同步时被发现（目前适用于 Windows 电脑；iPhone、Mac 和 Android 应用随后跟进）。没有同步时，能同时替换这两个文件的人仍可绕过这项检查。
  • 通行密钥只在 Chrome 和 Edge 中可用，并且只针对页面本身：在另一网站框架内的登录使用浏览器自带的通行密钥对话框。如果您批准新通行密钥后网站取消了操作，该通行密钥可能仍留在您的保管库中；请在应用中删除它。
