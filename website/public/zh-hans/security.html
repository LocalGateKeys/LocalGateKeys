安全模型，通俗讲解

LocalGateKeys 旨在保护什么，以及它无法保护什么。

保管库如何加密

一个随机的 256 位密钥用来加密保管库。该密钥从不按原样存储；每种解锁方式都会各自将其包裹（加密），因此更改密码不需要重新加密所有内容，从其他保管库复制来的包裹会被拒绝。

保管库加密
AES-256-GCM，每次保存都使用全新的随机 nonce
主密码
Argon2id，3 轮，并行度 4，每个包裹使用随机盐值；Windows 应用使用 256 MiB 内存（内存少于 4 GB 的电脑使用 64 MiB），Mac、iPhone 和 Android 应用使用 64 MiB
恢复短语
可选的 24 词 BIP39 短语（256 位），通过 HKDF-SHA256 扩展
Windows Hello、Touch ID、Face ID 和指纹
从设备保护的存储中取出保管库密钥；绝不保存主密码
备份和传输
Argon2id 和 AES-256-GCM，参数存储在经过认证的头部中
设备同步
一个随机的群组密钥，通过 X25519 和 HKDF-SHA256 交给每台设备；对于云文件夹，还会由您的同步密码通过 Argon2id 再次包裹；每条记录都用 AES-256-GCM 密封，并绑定到其项目、版本和密钥纪元；每个设备文件都绑定到写入它的设备
通行密钥
ES256（P-256）密钥保存在加密的保管库中；应用根据浏览器报告的来源构建签名数据，绝不根据页面。Microsoft Store 版应用还可以作为 Windows 11 的通行密钥提供程序（默认关闭）；此时 Windows 会在自己的列表中保存您的通行密钥网站和账户名称，但绝不保存密钥
写入磁盘
先写临时文件，刷新，再原子替换，因此崩溃不会留下写了一半的保管库
AI 代理
默认关闭（Pro）。代理只能通过您自己设备上的 lgk mcp 访问应用，并且只能看到您允许的登录信息和项目。每个请求都由您批准；登录由应用自己填写，发给代理的任何回复都不包含密码。每个请求都会写入访问日志，日志条目用 SHA-256 哈希串成链，安全检查会显示这条链是否完好

设计用于防范

  • 复制了您的保管库文件或备份，但不知道主密码的人
  • 网站获取为另一个网站保存的登录项或通行密钥
  • 您电脑上的其他程序在没有会话密钥的情况下与 LocalGateKeys 通信，而该密钥只交给它自己的浏览器辅助程序
  • 填充在绑定之后被替换、更新或更改的桌面应用
  • 密码以未加密形式存放在磁盘上
  • 表单在没有您参与的情况下被提交
  • 您的云服务商读取已同步的数据：它只存储密文
  • 网页读取 LocalGateKeys 为您提供的账户：在 Chrome、Edge 和 Firefox 中，该列表绘制在页面无法读取的独立扩展框架中
  • AI 代理从 LocalGateKeys 获取密码：发给代理的回复都不包含密码，代理也只能看到您允许的登录信息

无法防范

  • 已经在您电脑上运行的恶意软件，或任何拥有管理员控制权的人
  • 被入侵的浏览器、Windows 系统或依赖项
  • 您有意向其填入密码的网站
  • 在保管库解锁期间使用您电脑的人
  • 在显示攻击者控制内容的正规应用内部进行的网络钓鱼
  • 在没有恢复短语的情况下，丢失了保管库、备份和主密码：任何人，包括我们，都无法打开它
  • 控制您浏览器的 AI 代理在 LocalGateKeys 把密码填入页面后读取它，或您批准的命令把收到的机密转交出去

LocalGateKeys 绝不会做的事

有些填充密码的方式与间谍软件无法区分，因此在设计上就被排除。LocalGateKeys 不包含：

  • 键盘钩子或按键记录
  • 剪贴板监视
  • 通过读取屏幕或 OCR 来查找凭据
  • 扫描其他程序的内存
  • 解密您浏览器中保存的密码数据库
  • 向其他程序或游戏注入代码
  • 提交并非由您发起的登录

坦诚谈网络

没有 LocalGateKeys 账户，也没有保存保管库的服务器。应用只在以下情况下连接互联网：

  • 更新。Windows 应用由 Microsoft Store 更新，Mac 和 iPhone 应用由 App Store 更新；LocalGateKeys 本身绝不会下载或运行安装程序。已停用的 Windows 安装程序版本（直到最后一版 0.4.12）在您选择“检查更新”时从我们的服务器下载一个小文件，并用内置于应用的密钥验证其签名。
  • 许可证吊销列表。安装程序版本每次检查更新时，以及在关闭严格离线模式的情况下于 Microsoft Store 版应用中选择“检查更新”时，应用会下载一份已签名的已退款许可证列表，并在您的电脑上核对您的许可证。它不会发送任何关于您许可证的信息。
  • 网站图标。为了显示网站图标，应用会从该网站自己的地址下载。不会发送用户名、密码或保管库数据，但每次下载都会让该网站以及任何监视网络的人知道，您的保管库在那里有账户。此项默认关闭，只有在您于“设置”中开启“显示网站图标”时才会发生；严格离线模式会阻止它。
  • 泄露检查（如果您开启）。当您启动检查时，应用会把每个密码 SHA-1 哈希的前五个字符发送给 Have I Been Pwned。该服务能看到您的 IP 地址，但绝不会看到密码、完整哈希、用户名或网站。
  • 同步（如果您设置）。在家庭网络中，设备之间直接通信。通过云文件夹时，由您的云盘应用负责上传。
  • 在 Mac、iPhone 或 Android 应用中购买 Pro。应用会把商店签名的购买记录发送到我们的许可证服务器，服务器返回您的许可证密钥。不会发送电子邮件地址或设备数据。
  • 已验证的网站。相似地址检查在您的设备上进行。已保存的网站绝不会离开应用，也不会向任何服务器发送内容。

在 Windows 应用中，“安全中心 › 网络活动”会列出每一次这类连接及其时间、主机和结果。您保存的网站名称只在应用运行期间显示，绝不写入磁盘；您自己网络中的设备显示为“本地网络”。

严格离线模式默认开启。它会阻止后台互联网请求、网站图标和泄露检查，检查更新前会先询问您。隐私政策准确列出了您检查更新时我们的服务器能看到什么。

已知限制

  • 主密码一进入应用就会被放入可擦除的缓冲区，并在需要它的操作结束时被擦除。您输入密码的页面运行在 Microsoft Edge WebView2 中。在计算您的密钥之前，页面会清空输入框，应用也会释放传递过程中产生的副本；但这两份副本都无法在内存中被覆盖，因此短时间内内存里可能残留痕迹。
  • 摄像头解锁会要求您随机转动头部，因此平举在摄像头前的照片或屏幕上的静态图片无法通过。但它仍然只是便利性检查，而非经过认证的保护：弯折或对折的照片、按提示动作的视频或面具可能会通过。Windows Hello 是更强的选择。
  • Windows 应用填充不适用于以管理员身份运行的程序、自绘的游戏界面，或无法验证的嵌入式网页视图。
  • 保管库能检测到被回滚到较旧的副本。如果您使用同步，您的其他设备会记住保管库有多新，因此在某台设备上放回较旧的副本时，下次同步会在每个应用中提示。没有同步时，Windows 电脑会在保管库文件夹之外另存一份记录，因此连同锚点文件一起放回的较旧保管库会被拒绝；能更改您 Windows 账户设置的人也可以删除这份记录。iPhone、Mac 和 Android 应用会阻止其他应用访问自己的文件，但没有同步时，不会察觉被换成较旧的副本。
  • 通行密钥可在 Chrome、Edge 和 Firefox 中使用。在另一网站的框架内使用通行密钥登录，在外层网站允许时可在 Chrome 和 Edge 中使用；在 Firefox 中，以及在另一网站的框架内创建通行密钥时，会使用浏览器自带的通行密钥对话框。如果您批准新通行密钥后网站取消了操作，应用会再次将其删除；如果应用无法确定网站是否保留了它，该通行密钥会留在您的保管库中，您可以在应用中删除它。
  • 相似地址警告只是提示，不是屏障：页面自己的脚本可以绕过它，例如不提交表单就发送密码。请自行核对地址。
  • 紧急访问没有服务器,所以只有应用本身会强制执行等待期和您的否决。任何持有足够份数的人都可以立刻恢复您的备份,无需等待。请选择不会联手的持有人,并把各份分开保管。
  • 胁迫密码用来应对被迫解锁应用的情形。它不能防范检查您磁盘文件的人,细心的人可以发现存在第二个保管库。适用于 Windows、Mac、iPhone 和 Android。
