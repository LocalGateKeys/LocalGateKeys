全部功能，以及在哪里使用

这一切都在您自己的设备上运行：Windows 应用、浏览器扩展和 iPhone 应用。免费版最多可保存 7 个项目；Pro 取消限制，并增加同步、双重验证码和文档。

保管库

在您的磁盘上加密
您保存的一切都使用由主密码保护的密钥加密，采用 Argon2id 和 AES-256-GCM。名称、用户名和网站同样会被加密，而不只是密码。
不只是密码
网站和桌面应用登录、通行密钥、支付卡、银行账户、身份信息、安全笔记、文档、SSH 密钥、API 密钥、Wi-Fi 网络、书签、软件许可证、订阅、保修和购买记录，每种都有各自的字段。
文档（Pro）
将扫描件等文件保存在保管库中，每个最大 25 MB。每个文件都用各自的密钥加密。您可以预览文档、另存副本，或用其他应用打开。启用同步后，文件会以加密状态传送到您的其他设备。
双重验证码（Pro）
保存网站的设置密钥后，LocalGateKeys 会在登录项顶部显示当前验证码，并在主页的“一次性验证码”卡片中显示。验证码遵循 TOTP 标准（RFC 6238）：6 至 8 位，15 至 120 秒，SHA-1、SHA-256 或 SHA-512。
Apple Watch 上的验证码（Pro）
在 Apple Watch 上显示您选择的双重验证码，最多 10 个。手表只显示验证码，绝不显示密码，即使 iPhone 不在附近也能继续使用。
扫描二维码
选择“扫描二维码”，然后粘贴用 Win+Shift+S 截取的网站双重验证二维码，或拖入图像，或将其对准您的摄像头。Google Authenticator 导出的二维码同样适用。图像只在您的电脑上读取，绝不保存。
密码生成器
8 至 256 个字符的随机密码，或 3 至 16 个单词的密码短语。
密码健康
查看哪些已保存的密码较弱、重复使用、已超过一年，或缺少双重验证码。对照 Have I Been Pwned 的泄露检查默认关闭，需要您开启，只在您启动时运行，并且只发送哈希的五个字符，绝不发送密码。
网站徽标和类型图标
每个项目都会显示网站图标、知名网站的内置徽标，或其类型的图标，让您一眼就能认出。
搜索、排序和集合
通过命令面板（Ctrl+K）、筛选标签、收藏和您自己的集合查找项目。可按标题、修改日期或创建日期排序，收藏项目排在最前。在搜索框中即可直接使用列表的方向键、Enter 和 Ctrl+C。
回收站和撤销
删除的项目会进入回收站，确认删除的消息带有“撤销”按钮。回收站会在 30 天后自动清空，也可以保留全部内容，直到您手动清空。
密码历史
登录的密码更改后，最多 10 个旧密码会在其加密历史中保留一年。您可以复制其中一个，或将其恢复。
已验证的网站
浏览器扩展会把已保存的网站标记为“已验证的网站”，并在您于相似地址（例如字母被调换的地址）登录或保存之前发出警告。检查在您的设备上进行，已保存的网站绝不会离开应用。Safari 只保存一份仅含网站名称的密封列表。在 Android 上，自动填充的保存提示也会显示同样的判断，并在保存到相似地址之前先询问您。

导入和导出

从其他密码管理器导入
可导入来自 1Password、Bitwarden、LastPass、Dashlane、Proton Pass、KeePass 和 KeePassXC（包括 .kdbx 文件）、Chrome、Edge、Brave、Firefox 和 Safari 的导出文件，或任何其他 CSV 文件。写入之前，您可以逐项检查，导入过程绝不联网。在 iPhone 上，可直接从 Apple 密码导入登录信息、双重验证码和通行密钥（iOS 26 及更高版本），也可导入许多密码管理器和验证器应用的文件。
导出
可导出为加密的 KeePass KDBX 4 文件、兼容 Bitwarden 的 CSV 或 JSON，或 KeePass XML。每次导出都会先要求输入您的主密码。
安全共享单个项目
将登录信息或笔记以 .lgkshare 文件或二维码发送，并用六个单词的代码锁定，您需要通过其他方式告诉对方这个代码。它只能打开一次，输错三次代码就会销毁。通行密钥、文档和带有附件的项目无法共享。

填充登录信息

Chrome 和 Edge 扩展
在网站上填充并保存登录信息，包括在不同页面分别要求输入用户名和密码的登录。扩展通过本地辅助程序向您电脑上的应用请求与当前网站完全匹配的登录项。它还会填充双重验证码、地址和支付卡。
由您掌控的保存提示
登录之后，扩展会提示保存新的登录项，或更新已更改的密码。您可以通过工具栏按钮为任何网站关闭该提示。
每次填充都由您发起
在您选择账户之前不会填充任何内容。表单不会替您提交，除非您在“设置”中开启“填充后登录”，并且也只会在您发起的填充之后提交。
通行密钥
当 Chrome 或 Edge 中的网站提供通行密钥时，LocalGateKeys 可以将其保存到您的保管库并用它登录。每个通行密钥都需要您在桌面应用中通过 Windows Hello 或主密码批准，并且浏览器自带的通行密钥对话框始终只需点击一次即可使用。私钥绝不会离开应用。
Windows 应用填充
通过密码框旁边的填充按钮或快捷键（Ctrl+Shift+Space），填充 Windows 程序的登录窗口。每个应用只需绑定一次，如果此后程序、窗口或其字段发生了变化，就会拒绝填充。
快速访问
通过快捷键（默认为 Ctrl+Alt+K）随时随地搜索保管库并复制。Ctrl+Alt+L 可立即锁定保管库。
绝不记录键盘输入
LocalGateKeys 不安装键盘钩子，不读取屏幕内容来查找密码，也不向其他程序注入任何内容。如果某个应用没有提供规范的登录字段，就不会被填充。

解锁

主密码
至少 12 个字符，绝不写入磁盘。它是打开您保管库的唯一凭据，我们无法重置它。
Windows Hello
在 LocalGateKeys 中设置后，可通过 Windows Hello 用指纹、面部或 PIN 解锁。
摄像头检查
为没有 Windows Hello 的电脑提供的可选摄像头面部检查。它只是为了方便，并非经过认证的防欺骗措施；如有条件，请优先使用 Windows Hello。
恢复短语
可选的 24 词短语，忘记主密码时可用它打开保管库。它只显示一次，应用绝不保存。
自动锁定和清除剪贴板
保管库会在您选择的时间后锁定，复制的密码会从剪贴板中清除。只会清除 LocalGateKeys 复制的内容。

备份

定时加密备份
每天或每周，在您设定的时间进行。每份备份都是完整的加密文件，写入后会校验，并包含附件。
额外副本保存到您选择的文件夹
让每份备份复制到 OneDrive、Google Drive、Dropbox 或 Proton Drive 文件夹，或任何其他位置。只会复制加密的备份文件，绝不复制正在使用的保管库。
加密传输包
将选定的项目移到另一个保管库，使用由独立密码保护的加密文件。
手机备份
iPhone 和 Android 应用会用你选择的密码保存加密的 .lgkm 备份。可在任何 iPhone、Android 手机、Mac 或 PC 上恢复：它像同步一样合并，绝不会清空你的保险库。

紧急访问与胁迫密码(Pro)

紧急访问
把恢复短语拆成最多五份,交给您信任的人。您设定的份数(两到五份)凑齐即可恢复。每个人会收到一个签名文件、一个二维码或一张打印页。没有账户,也没有服务器:您与他们共享一个文件夹,例如云文件夹或U盘。
等待期与否决
需要访问的人在自己的 LocalGateKeys 中提出申请。过了您设定的等待期(1 到 30 天),应用会打开您最新加密备份的副本。在此之前,您的任何一台设备都可以说“不”。您也可以立刻批准。在手机上,流程以显示您的恢复短语结束;请在电脑上打开备份。
局限
应用之外没有任何东西能强制执行等待期或您的“不”。任何持有足够份数的人只要联手,就能立刻打开您的备份。请选择不会联手的人,并把各份分开保管。更换恢复短语后,旧的份数就失效了。
胁迫密码
第二个密码会打开一个带示例条目的逼真保管库,不会泄露真实保管库的任何信息。它打开期间,真实保管库会按您设定的小时数保持锁定,且不进行任何同步。它能让您的保管库不被从背后窥视的人或强迫您打开应用的人发现。但它无法对检查您文件的人隐瞒该功能的存在。适用于 Windows、Mac、iPhone 和 Android。

高级用户工具

备份还原测试
每周一次，LocalGateKeys 会把最新的备份还原到临时文件夹，检查它能否打开，然后删除该副本。如果备份使用的是旧密码，它会告诉你。
更改密码助手
打开更改网站密码的页面：来自精选列表、标准的 /.well-known/change-password 地址，或登录页面。它从不在第三方网站上填写内容。
多个保管库（Pro）
可以分开保管，例如“工作”和“个人”。免费版包含一个保管库。免费的 7 个项目上限按所有保管库合计计算。
可打印的保管库健康报告
一页可打印的报告，不包含密码，也不包含项目名称。
会过期且可撤销的共享
共享可设为 1 小时或 1 天后过期、仅可使用一次，并且可以撤销。这是尽力而为。
遗产包模板
面向遗嘱执行人的模板，位于紧急访问旁边。

面向开发者和 AI 智能体

AI 智能体可以登录，密码留在你的电脑上 (Pro)
Claude Code 等 MCP 智能体可以请求 LocalGateKeys 登录某个网站。每个请求都由你批准，浏览器扩展填写表单，智能体永远看不到密码。适在 Windows 上：使用 claude mcp add localgatekeys -- LocalGateKeysNativeHost.exe mcp；Store 版以 LocalGateKeysNativeHost.exe lgk 运行 lgk 命令行。 AI 智能体可以登录，密码留在你的电脑上
防篡改的访问日志
每条活动记录都通过哈希与上一条相连，因此日志被修改、截断或清空时，安全检查会显示出来。

设备间同步（Pro）

通过您的家庭 Wi-Fi
用一次性二维码为电脑或 iPhone 配对一次（电脑之间则粘贴其文本）。当两台设备在同一网络中且都已解锁时，会通过经过认证的加密连接直接交换更改。不经过互联网。如果电脑的地址发生变化，点击“重新查找”即可重新连接，每台设备都会显示上次同步的时间。
通过您自己的云文件夹
如果您的设备很少处于同一网络中，可以通过您已在使用的云文件夹（例如 Dropbox 或 iCloud Drive）同步，并由同步密码保护。服务商只会存储加密文件。两种方式可以同时使用。
同步的内容
登录、笔记、银行卡等其他项目，以及附有文件的文档。集合保留在各台设备上。在两台设备上同时进行的编辑会保留两个版本，删除操作会让项目在其他设备上移入回收站。如果某台设备带回了保管库的旧副本，Windows 应用会向您发出警告，而不是接受它。
iPhone
iPhone 应用可与您的 Windows 电脑和 Mac同步。已购买 Pro 的 iPhone 与免费版电脑配对后，电脑会通过同步接管许可证并升级为 Pro。在 App Store 获取。

在 iPhone 上

Safari 和应用中的 AutoFill
在 Safari 和其他应用中填充登录信息，建议显示在 QuickType 栏中，并可将 LocalGateKeys 用于通行密钥。在 iOS 18 及更高版本中，它还会在任何文本字段中填充银行卡、地址和其他信息。登录后，Safari 扩展会提议保存新的登录信息。
Face ID、Touch ID 或应用密码
保管库可用 Face ID、Touch ID 或 iPhone 密码打开，无需创建密码。如果别人知道您的密码，可以另外添加由 24 个单词的恢复短语支持的应用密码（可选）。
安全检查
“安全”标签页会为您的保管库打分，并列出弱密码、重复使用的密码、旧密码，以及可以使用双重验证码的登录。泄露检查在您开启之前保持关闭。
最近删除、历史记录和提醒
删除的项目会在“最近删除”中保留 30 天，点击“撤销”即可立即恢复。每个登录都保留密码历史，您还可以在银行卡、护照或证件到期前收到提醒。
附加文件（Pro）
将文档和照片附加到您的保管库，加密存储，并与您的其他设备同步。
十种语言
iPhone 应用支持英语、德语、西班牙语、意大利语、日语、韩语、荷兰语、波兰语、巴西葡萄牙语和简体中文。

隐私

无需账户
您无需注册或登录。Pro 许可证是一个由您自己保管的密钥，在您的设备上验证。在 iPhone 上，Pro 是通过 App Store 购买的，应用只会向我们的许可证服务器发送 App Store 收据。
无遥测
这些应用不发送使用数据、崩溃报告或分析数据。
严格离线模式
默认开启。它会阻止后台的互联网请求和泄露检查，检查更新前会先询问您。
网站图标，由您决定
为了显示网站图标，应用会从该网站下载。这只会让该网站知道您在那里有账户，不会泄露其他信息。默认关闭：请在“设置”中开启“显示网站图标”（必须先关闭严格离线模式）。
由您发起的更新检查
检查更新只会下载一个带签名的小文件。应用绝不会自行下载或安装任何东西。
