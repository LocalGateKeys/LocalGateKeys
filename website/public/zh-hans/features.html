全部功能，以及在哪里使用

这一切都在您自己的设备上运行。免费版最多可保存 4 个项目；Pro 解除限制，并增加同步、双重验证码和文档。

保管库

在您的磁盘上加密
您保存的一切都使用由主密码保护的密钥加密，采用 Argon2id 和 AES-256-GCM。名称、用户名和网站同样会被加密，而不只是密码。
不只是密码
网站和桌面应用登录、通行密钥、支付卡、银行账户、身份信息、安全笔记、文档、SSH 密钥、API 密钥、Wi-Fi 网络、书签、软件许可证、订阅、保修和购买记录，每种都有各自的字段。
文档（Pro）
将扫描件等文件保存在保管库中，每个最大 25 MB。每个文件都用各自的密钥加密。您可以预览文档、另存副本，或用其他应用打开。
双重验证码（Pro）
保存网站的设置密钥后，LocalGateKeys 会在登录项顶部显示当前验证码，并在主页的“一次性验证码”卡片中显示。验证码遵循 TOTP 标准（RFC 6238）：6 至 8 位，15 至 120 秒，SHA-1、SHA-256 或 SHA-512。
通过二维码添加验证码
用 Win+Shift+S 截取网站双重验证设置页上的二维码并粘贴，或将其对准您的摄像头。Google Authenticator 导出的二维码同样适用。图像只在您的电脑上读取，绝不保存。
密码生成器
8 至 256 个字符的随机密码，或 3 至 16 个单词的密码短语。
密码健康
查看哪些已保存的密码较弱、重复使用、已超过一年，或缺少双重验证码。对照 Have I Been Pwned 的泄露检查默认关闭，需要您开启，只在您启动时运行，并且只发送哈希的五个字符，绝不发送密码。
网站徽标和类型图标
每个项目都会显示网站图标、知名网站的内置徽标，或其类型的图标，让您一眼就能认出。
搜索和集合
通过命令面板（Ctrl+K）、筛选标签、收藏和您自己的集合查找项目。在搜索框中即可使用方向键、Enter 和 Ctrl+C 操作项目列表。
回收站和撤销
删除的项目会进入回收站，确认删除的消息带有“撤销”按钮。回收站会在 30 天后自动清空，也可以保留全部内容，直到您手动清空。
密码历史
登录项的密码更改时，最近五个旧密码会保存在其加密历史中。

导入和导出

从其他密码管理器导入
可导入 1Password、Bitwarden、LastPass、Dashlane、Proton Pass、KeePass 和 KeePassXC（包括 .kdbx 文件）、Chrome、Edge、Brave、Firefox 和 Safari 的导出文件，或任何其他 CSV 文件。写入任何内容之前，您会先检查每个项目，导入过程也绝不联网。
导出
可导出为加密的 KeePass KDBX 4 文件、兼容 Bitwarden 的 CSV 或 JSON，或 KeePass XML。每次导出都会先要求输入您的主密码。

填充登录信息

Chrome 和 Edge 扩展
在网站上填充并保存登录信息，包括在不同页面分别要求输入用户名和密码的登录。扩展通过本地辅助程序向您电脑上的应用请求与当前网站完全匹配的登录项。它还会填充双重验证码、地址和支付卡。
由您掌控的保存提示
登录之后，扩展会提示保存新的登录项，或更新已更改的密码。您可以通过工具栏按钮为任何网站关闭该提示。
每次填充都由您发起
在您选择账户之前不会填充任何内容。表单不会替您提交，除非您在“设置”中开启“填充后登录”，并且也只会在您发起的填充之后提交。
通行密钥
当 Chrome 或 Edge 中的网站提供通行密钥时，LocalGateKeys 可以将其保存到您的保管库并用它登录。每个通行密钥都需要您在桌面应用中通过 Windows Hello 或主密码批准，并且浏览器自带的通行密钥对话框始终只需点击一次即可使用。私钥绝不会离开应用。
Windows 应用填充
通过密码框旁边的填充按钮或快捷键（Ctrl+Shift+Space），填充 Windows 程序的登录窗口。每个应用只需绑定一次，如果此后程序、窗口或其字段发生了变化，就会拒绝填充。
快速访问
通过快捷键（默认为 Ctrl+Alt+K）随时随地搜索保管库并复制。Ctrl+Alt+L 可立即锁定保管库。
绝不记录键盘输入
LocalGateKeys 不安装键盘钩子，不读取屏幕内容来查找密码，也不向其他程序注入任何内容。如果某个应用没有提供规范的登录字段，就不会被填充。

解锁

主密码
至少 12 个字符，绝不写入磁盘。它是打开您保管库的唯一凭据，我们无法重置它。
Windows Hello
在 LocalGateKeys 中设置后，可通过 Windows Hello 用指纹、面部或 PIN 解锁。
摄像头检查
为没有 Windows Hello 的电脑提供的可选摄像头面部检查。它只是为了方便，并非经过认证的防欺骗措施；如有条件，请优先使用 Windows Hello。
恢复短语
可选的 24 词短语，忘记主密码时可用它打开保管库。它只显示一次，应用绝不保存。
自动锁定和清除剪贴板
保管库会在您选择的时间后锁定，复制的密码会从剪贴板中清除。只会清除 LocalGateKeys 复制的内容。

备份

定时加密备份
每天或每周，在您设定的时间进行。每份备份都是完整的加密文件，写入后会校验，并包含附件。
额外副本保存到您选择的文件夹
让每份备份复制到 OneDrive、Google Drive、Dropbox 或 Proton Drive 文件夹，或任何其他位置。只会复制加密的备份文件，绝不复制正在使用的保管库。
加密传输包
将选定的项目移到另一个保管库，使用由独立密码保护的加密文件。

设备间同步（Pro）

通过您的家庭 Wi-Fi
用一次性二维码配对一次电脑（电脑之间则粘贴其文本）。当两台电脑在同一网络中且都已解锁时，会通过经过认证的加密连接直接交换更改。不经过互联网。
通过您自己的云文件夹
如果您的电脑很少处于同一网络中，可以通过您已在使用的 OneDrive、Dropbox、Google Drive 或 iCloud Drive 文件夹同步，并由同步密码保护。服务商只会存储加密文件。两种方式可以同时使用。
同步的内容
网站和桌面应用登录，以及笔记和书签等其他项目。集合、文档和附件目前尚不同步。在两台电脑上同时进行的编辑会保留两个版本，删除操作会让项目在其他电脑上移入回收站。
iPhone
iPhone 应用可与您的 Windows 电脑同步。在 App Store 获取。

隐私

无需账户
您无需注册或登录。Pro 许可证是一个由您自己保管的密钥，在您的电脑上验证。
无遥测
应用不发送使用数据、崩溃报告或统计分析数据。
严格离线模式
默认开启。它会阻止后台的互联网请求和泄露检查，检查更新前会先询问您。
网站图标，由您决定
为了显示网站图标，应用会从该网站下载。这只会让该网站知道您在那里有账户，不会泄露其他信息。默认关闭：请在“设置”中开启“显示网站图标”（必须先关闭严格离线模式）。
由您发起的更新检查
检查更新只会下载一个带签名的小文件。应用绝不会自行下载或安装任何东西。
