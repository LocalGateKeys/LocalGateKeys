入门

安装 Windows 应用，创建保管库，然后添加浏览器扩展。大约五分钟，并且无需账户。

1. 安装应用 2. 创建保管库 3. 添加浏览器扩展 4. 带入您的密码 5. 填充 Windows 应用 6. 开启 Pro iPhone 和 Android

1 安装 Windows 应用

LocalGateKeys 可在 64 位 Windows 10 和 Windows 11 上运行。任选一种方式安装：

  • Microsoft Store（推荐）。由 Store 安装并保持更新。在 Microsoft Store 中打开 LocalGateKeys，选择获取，然后选择打开。
  • 安装程序。从下载页面下载，按那里的说明核对其 SHA-256，然后运行。由于安装程序尚未进行代码签名，Windows SmartScreen 可能会发出警告：如果指纹一致，请选择更多信息，然后选择仍要运行。

同一台电脑上只使用两种方式中的一种。

从 Microsoft Store 获取 其他下载

2 创建保管库

  1. 打开 LocalGateKeys。首次启动时会要求您创建保管库。
  2. 设置一个至少 12 个字符的主密码。请把它记下来并保存在安全的地方。我们从未持有它，因此没有人能为您重置。
  3. 在侧边栏中打开安全中心，设置恢复短语。请离线保管，例如写在纸上。忘记主密码时，可用它打开保管库。
  4. 在同一位置，如果您的电脑有指纹读取器、Hello 摄像头或 PIN，请开启 Windows Hello，让日常解锁更快捷。
  5. 在“设置”中开启定时备份，并选择加密备份文件的保存位置，例如 U 盘或您已在备份的文件夹。

3 添加浏览器扩展

扩展用于在浏览器中填充登录信息。它只与同一台电脑上的 LocalGateKeys 应用通信，因此请先安装应用。

  1. 添加扩展：
    • Microsoft Edge：在 Edge 加载项中打开，并选择获取。
    • Google Chrome：即将登陆 Chrome 应用商店。
  2. 固定它：打开浏览器的扩展菜单（拼图图标），将 LocalGateKeys 固定到工具栏。
  3. 保持应用运行并处于解锁状态。打开一个您已保存登录项的登录页面：扩展只提供为该网站保存的登录项。在您点击之前不会填充任何内容。
  4. 在新的网站登录后，扩展会提示保存该登录项。

扩展提示无法连接应用？在应用中打开设备与连接，选择修复桥接，然后重启浏览器。

4 带入您的密码

在侧边栏中选择导入和导出，然后选择 1Password、Bitwarden、LastPass、Dashlane、Proton Pass、KeePass 或 KeePassXC、Chrome、Edge、Brave、Firefox 或 Safari 的导出文件，或任何 CSV。保存任何内容之前，您会先检查每个项目，并且不会联网。之后请删除导出文件，因为大多数导出文件以明文保存密码。

免费版最多可保存 4 个项目。Pro 解除限制。

5 填充 Windows 应用

对于游戏启动器等程序，请在应用中打开一个桌面登录项，选择应用绑定…，将其一次性绑定到该程序的登录窗口。此后，密码框旁边会出现填充按钮，您也可以使用快捷键。如果程序或窗口在您绑定之后发生了变化，LocalGateKeys 会拒绝填充。

6 开启 Pro

Pro 是一次性付款，可增加无限项目、设备间同步、双重验证码和文档。购买后，在应用的工具 > 许可证中粘贴您的许可证密钥。请参阅您的 Pro 许可证。

iPhone 和 Android

iPhone：安装 App Store 上的 LocalGateKeys。它可与您的 Windows 电脑同步。

Android：Android 应用已在计划中，目前尚不可用。

Android的设置步骤会在该应用发布时出现在本页。在此之前，您的保管库保留在您的电脑上，并且您可以通过 Pro 在 Windows 电脑之间同步。

遇到困难？请参阅支持与常见问题，或发邮件到 support@localgatekeys.app。
