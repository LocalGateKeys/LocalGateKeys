入门

安装 Windows 应用，创建保管库，然后添加浏览器扩展。大约五分钟，并且无需账户。iPhone 应用可随时添加。

  1. 1. 安装应用
  2. 2. 创建保管库
  3. 3. 添加浏览器扩展
  4. 4. 带入您的密码
  5. 5. 填充 Windows 应用
  6. 6. 开启 Pro
  7. 7. 添加 iPhone

1 安装 Windows 应用

LocalGateKeys 可在 64 位 Windows 10（版本 2004 或更高）和 Windows 11 上运行，通过 Microsoft Store 获取：

  • Microsoft Store。由 Store 安装并保持更新。在 Microsoft Store 中打开 LocalGateKeys，选择获取，然后选择打开。
  • 用过旧版安装程序？请在 Windows 设置 › 应用（Windows 11 中为已安装的应用，Windows 10 中为应用和功能）中将其卸载，然后从 Microsoft Store 安装。你的保险库保持原位，Store 版应用会用同一个主密码打开它。

从 Microsoft Store 获取 其他下载

2 创建保管库

  1. 打开 LocalGateKeys。首次启动时会提示您创建保管库，随后简短的设置向导会提供 Windows Hello、导入、恢复短语和浏览器扩展。任何步骤都可以跳过，之后再通过完成设置卡片完成。
  2. 设置一个至少 12 个字符的主密码。请把它记下来并保存在安全的地方。我们从未持有它，因此没有人能为您重置。
  3. 在侧边栏中打开安全中心，设置恢复短语。请离线保管，例如写在纸上。忘记主密码时，可用它打开保管库。
  4. 在同一位置，如果您的电脑有指纹读取器、Hello 摄像头或 PIN，请开启 Windows Hello，让日常解锁更快捷。
  5. 在“设置”中开启定时备份，并选择加密备份文件的保存位置，例如 U 盘或您已在备份的文件夹。

3 添加浏览器扩展

扩展用于在浏览器中填充登录信息。它只与同一台电脑上的 LocalGateKeys 应用通信，因此请先安装应用。

  1. 添加扩展：
    • Microsoft Edge：在 Edge 加载项中打开，并选择获取。
    • Google Chrome：在 Chrome 应用商店中打开，并选择添加至 Chrome。
    • Mozilla Firefox（Windows）：在 Firefox 附加组件中打开，然后选择添加到 Firefox。
  2. 固定它：打开浏览器的扩展菜单（拼图图标），将 LocalGateKeys 固定到工具栏。
  3. 保持应用运行并处于解锁状态。打开一个您已保存登录项的登录页面：扩展只提供为该网站保存的登录项。在您点击之前不会填充任何内容。
  4. 在新的网站登录后，扩展会提示保存该登录项。

扩展提示无法连接应用？在应用中打开设备与连接，选择修复桥接，然后重启浏览器。

4 带入您的密码

在侧边栏中选择导入和导出，然后选择 1Password、Bitwarden、LastPass、Dashlane、Proton Pass、KeePass 或 KeePassXC、Chrome、Edge、Brave、Firefox 或 Safari 的导出文件，或任何 CSV。保存任何内容之前，您会先检查每个项目，并且不会联网。之后请删除导出文件，因为大多数导出文件以明文保存密码。

免费版最多可保存 7 个项目。Pro 解除限制。

5 填充 Windows 应用

对于游戏启动器等程序，请在应用中打开一个桌面登录项，选择应用绑定…，将其一次性绑定到该程序的登录窗口。此后，密码框旁边会出现填充按钮，您也可以按 Ctrl+Shift+Space。如果程序或窗口在您绑定之后发生了变化，LocalGateKeys 会拒绝填充。

6 开启 Pro

Pro 一次付款即可增加无限项目、设备间同步、双重验证码和文档。购买后，在许可证页面选择在 LocalGateKeys 中安装，或将许可证密钥粘贴到设置 › 方案与同步 › 许可证。参见您的 Pro 许可证。

7 添加 iPhone

iPhone 应用保有自己的加密保管库，并与您的电脑同步。同步属于 Pro。

  1. 安装并打开App Store 上的 LocalGateKeys。
  2. 点击解锁。保管库可用 Face ID、Touch ID 或 iPhone 密码打开，因此无需创建密码。随后简短的设置会提供导入、可选的应用密码和 AutoFill。
  3. 开启 AutoFill：在 LocalGateKeys 中选择“设置 › AutoFill › 打开 AutoFill 设置”，然后在通用 › 自动填充与密码下开启 LocalGateKeys。
  4. 与电脑配对：在电脑上打开“同步与设备”，开启 Wi-Fi 同步并选择显示二维码。在 iPhone 上打开同步标签页并点击扫描二维码。确认两个屏幕显示相同的代码，然后在电脑上选择接受。
  5. Apple Watch（Pro）：在 iPhone 的 Watch 应用中安装 LocalGateKeys，然后打开带有双重验证码的登录，点击在 Apple Watch 上显示。

在 iPhone 上购买了 Pro？配对后，免费版电脑会通过同步接管许可证并升级为 Pro。每个 iPhone 屏幕的帮助都在用户指南中。

Mac：从 Mac App Store 获取 App。Android：App 即将推出，目前还不可用。
