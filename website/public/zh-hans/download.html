运行前检查安装程序

将安装程序的指纹与上方的 SHA-256 值进行比对。在 PowerShell 中，进入下载文件所在的文件夹后运行：

Get-FileHash .\LocalGateKeys-Setup-Personal.exe -Algorithm SHA256

如果两个值不一致，请不要运行该文件。请从本页重新下载，并通过 security@localgatekeys.app 告知我们。

系统要求

  • 64 位 Windows 10 或 Windows 11
  • 使用浏览器填充需要较新版本的 Google Chrome 或 Microsoft Edge
  • 使用 Windows Hello 解锁需要 Windows Hello 硬件（指纹读取器、Hello 摄像头或 PIN）
  • 同步需要：Pro，以及同一网络中的两台或更多电脑，或每台电脑上都安装了云盘应用

安装之后

入门指南附有截图，带您走完每一步。

  1. 打开 LocalGateKeys，设置一个至少 12 个字符的主密码。请把它记在安全的地方；我们无法重置它。
  2. 在“设置”中创建恢复短语，并离线保管。
  3. 在“设置”中开启定时备份。
  4. 添加浏览器扩展（Edge），并将其固定到工具栏。扩展只有在安装了应用时才能使用。
  5. 已购买 Pro？在“工具 > 许可证”中输入您的许可证密钥。请参阅您的 Pro 许可证。
