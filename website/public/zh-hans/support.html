支持与问题

大多数答案都在下面。如有其他问题，请发邮件到 support@localgatekeys.app。请勿向我们发送您的主密码、恢复短语或保管库文件；我们绝不会索要。

您的保管库

我忘记了主密码。你们能重置吗？

不能。我们从未持有您的主密码或保管库，所以没有任何可以重置的东西。如果您创建了恢复短语，请在解锁界面使用它打开保管库并设置新密码。

没有密码或恢复短语，任何人都无法打开保管库。备份使用各自的备份密码加密，因此仍能打开的备份是另一条回到保管库的路。

你们会保留我的保管库副本吗？

不会。没有存储保管库的 LocalGateKeys 账户或服务器。您的保管库只存在于您的设备上，以及您自己设置的备份或云文件夹中。

保管库存放在我电脑上的什么位置？

在您的 Windows 用户配置文件中，位于 %LOCALAPPDATA%\LocalGateKeys。把该文件复制到别处是安全的，因为它是加密的，但请使用定时备份，而不要复制正在使用的文件。

我可以从其他密码管理器导入吗？

可以。在应用中选择“导入和导出”，然后选取 1Password、Bitwarden、LastPass、Dashlane、Proton Pass、KeePass 或 KeePassXC（.kdbx 文件可直接打开）、Chrome、Edge、Brave、Firefox 或 Safari 的导出文件。任何其他 CSV 文件也可以：由您告诉应用哪一列是什么。写入任何内容之前，您会先检查每个项目，导入过程也绝不联网。之后请删除导出文件，因为大多数导出文件以明文保存您的密码。

没有网络连接也能用吗？

能，完全可以。应用只在以下情况使用网络：检查更新（同时获取许可证吊销列表）、您发起的泄露检查、您开启后的网站图标，以及您设置后的同步。默认开启的严格离线模式会阻止后台请求、网站图标和泄露检查，并在检查更新前先询问。请参阅安全页面。

填充登录信息

为什么浏览器扩展需要桌面应用？

保管库保存在桌面应用中，而不是浏览器中。扩展通过一个小型本地辅助程序，向应用请求与您当前网站匹配的登录项。这样浏览器就不会持有您的整个保管库。请先安装应用，再从下载页面添加扩展。

LocalGateKeys 支持通行密钥吗？

支持，在 Windows 上的 Chrome 和 Edge 中。当网站提供通行密钥时，扩展会询问是否保存到 LocalGateKeys，您在桌面应用中批准即可。用它登录的方式相同。您始终可以改用浏览器自带的通行密钥对话框，或在应用的自动填充设置中关闭通行密钥。通行密钥计入免费版 4 个项目的限制。

某个 Windows 应用无法填充，为什么？

只有当应用向 Windows 公开了真正的登录字段时，Windows 应用填充才能工作。以下情况会被拒绝：

  • 应用在您绑定之后已更新，其指纹发生了变化；请重新绑定
  • 应用以管理员身份运行，而 LocalGateKeys 不是
  • 登录界面由游戏引擎或无法验证的嵌入式网页绘制

这些拒绝是有意为之。LocalGateKeys 不会退而盲目地记录或模拟按键。

LocalGateKeys 会记录我的键盘输入吗？

不会。它不安装键盘钩子，也绝不监视您的输入。请参阅 LocalGateKeys 绝不会做的事。

Pro、许可证和付款

Pro 增加了什么？

无限项目、设备同步、双重验证码和文档。免费版最多可保存 4 个项目：登录、笔记、支付卡、身份信息和其他各种类型都计入，回收站中的项目不计入。请参阅价格。

没有 Pro 却有超过 4 个项目会怎样？

不会拿走任何东西。从旧版本升级后或移除许可证后可能出现这种情况。每个项目仍然可以使用、编辑和填充；只是在您购买 Pro 或回到 4 个以内之前，无法添加新项目。

更新还需要再付费吗？

不需要。Pro 是一次性付款，包含今后所有更新。无订阅，无需续费。

Pro 可以在几台电脑上使用？

您本人使用的所有电脑。许可证供一个人使用；请为您家庭或团队的每位成员各购买一个。

如何开启 Pro？丢失密钥怎么办？

付款后您会立即看到许可证密钥，并附有可下载的文件。在“工具 > 许可证”中粘贴密钥。密钥也会保存在您的加密保管库中，因此恢复备份就会恢复 Pro。请参阅您的 Pro 许可证。

可以退款吗？

可以，购买后 30 天内全额退款，无需任何理由。已退款的许可证会被吊销，因此 4 个项目的限制会再次生效；所有现有项目仍然可以使用。请参阅退款政策。

谁处理付款？可以开发票吗？

Paddle 作为商户记录方代我们销售 Pro。由它收款、适用相应的增值税或销售税，并开具收据和发票，包括带有贵公司增值税号的发票。

同步和 iPhone

Wi-Fi 同步会经过互联网吗？

不会。同一网络中已配对的电脑通过经过认证的加密连接直接相互连接。两者都需要处于解锁状态。同步属于 Pro。

如果通过云文件夹同步，我的云服务商能看到什么？

加密文件、文件数量、大小和更改时间，以及您设备的随机 ID 和公钥列表。看不到名称、用户名、密码或保管库内的任何其他内容。您存放在服务商处的文件适用服务商自己的条款。

有 iPhone 应用吗？

有。在 App Store 获取 LocalGateKeys。它可与您的 Windows 电脑同步，并且和 Windows 应用一样，不收集任何数据。
